## 1. 결론

"우리만의 것"은 가능하지만 새 알고리즘이 아니다. **대조쌍 구성이나 게이트의 학습 목표를 바꾼 작은 변형 하나 + 그것을 같은 게이트·같은 층에서 입증하는 사전 등록 ablation**이 현실적 상한이다. 논문의 본체는 여전히 선택적 개입의 적용과 게이트 × 개입 요인 분해이고, 방법 변형은 그 위에 얹는다. 교수님께 드릴 문장:

> 기존 조건부 steering을 의료 배경 전제에 적용하고 선택과 개입을 요인 분해하는 것이 본체이고, 방법 변형은 참 전제 쌍둥이로 과교정 방향을 추정해 교정 방향에서 제거하는 것 하나를 사전 등록 ablation과 함께 시험한다.

## 5. selective steering 분야의 빈 자리

기존 논문이 공유하는 뼈대 h' = h + g(x)·α·v 안에서 문서 범위(07 B3, 11, 12 §11)에 비어 있는 자리. "새로 만든다"고 부를 수 있는 건 앞의 둘이고, 둘 다 선행 레시피가 있어 기여는 통제 실험이다. 나머지는 분석·평가 기여인데 이 분야에 실제로 없는 결과이며 우리 표 설계로 나온다.

| 빈 자리 | 왜 비었나 | 성격 | 우리 표 | 리스크 |
|---|---|---|---|---|
| 게이트가 배우는 것(조건 있음)과 맞혀야 하는 것(개입하면 좋아짐)이 다르다 | CAST 조건 벡터·Two Axes probe·Tripathi gate 모두 입력 속성 학습. harm을 학습 신호로 쓴 게이트 없음(HACK은 rescue 쪽만) | 방법 변형 | Table 3 조건 행 | 라우팅 문헌, rescue 표본 |
| 방향이 하나이고 무엇을 담는지 분해된 적 없음 | 모든 교정 대조가 2-class. Dual-Stance Evaluation: centroid 차이 steering은 동조·사실 동의를 둘 다 깎음 = NFP/TPQ 문제의 일반 버전 | 방법 변형 | Table 3 C 열 | 거짓 거부 문헌과 같은 레시피 |
| harm이 게이트 탓인지 방향 탓인지 귀속 안 함 | Tripathi Rescue/Harm은 합산 | 분석 | Table 3 보조 | 없음 |
| 통제군이 약해 게이트의 텍스트 지름길을 못 잡음 | E1: 질문 전체 TF-IDF 0.77 > probe. 최소 쌍으로 게이트를 검증한 논문 없음 | 평가 | Table 1 쌍둥이 열 | probe가 못 이기면 RH1 기각 |
| 같은 게이트에서 프롬프트 개입 vs 활성값 개입 정면 비교 없음 | Two Axes는 라우팅만, Tripathi는 steering만 | 분석 | Table 3 가로축 | 없음 |
| 강도 근거가 게이트 확신도뿐 | Tripathi 점수 비례. "스스로 고칠 성향"으로 강도 정한 것 없음 | 방법 | 부록 | 하이퍼파라미터로 보임 |

## 6. 10월 ARR (main 목표)

ARR은 제출 후 commit 단계에서 main/Findings가 갈리므로 원고는 하나다. 차별점은 "방법이 다르다"가 아니라 "이 문제에서 아무도 못 낸 결과를 통제된 설계로 냈다"로 세운다. 리뷰어는 "probe gate + steering은 Tripathi가 했다"고 한 줄로 쓸 것이므로 다음 넷이 표에 있어야 한다.

1. **문제가 다르고 더 어렵다는 수치.** Tripathi는 다중 턴 압력·EHR 근거·표면 단서 있음. 우리는 단일 질문 속 배경 전제·근거 없음·표면 단서 없음. Table 1 쌍둥이 열에서 텍스트 분류기가 무너지고 probe가 버티면 증명된다.
2. **기존 방법을 같은 데이터에서 돌린 행.** Tripathi 공개 artifacts 전이(11의 수준 1), 우리 데이터로 학습한 CAST, Two Axes식 probe→프롬프트 라우팅, Well 프롬프트 최소 3개, GEPA.
3. **요인 분해와 harm 귀속.** §5의 셋째·다섯째 줄.
4. **방법 변형 하나와 ablation.** §4의 1순위. 실패하면 부록.

**리스크의 뜻.** E1의 두 숫자가 둘 다 불리하다. Plain PCR 3–9%는 모델별 +1 응답이 20–55개라 자연 응답으로 만든 C가 불안정하다는 뜻이고(그래서 c_pair), C가 약하면 개입해도 PCR이 안 올라 RH2가 안 나온다. TF-IDF 0.77 > probe 0.70–0.74는 FPQ와 NFP의 출처가 달라 문체만으로 갈린다는 뜻이고, 분류기가 "전제가 틀렸다"가 아니라 "이 문체는 FPQ"를 배운 것이라 RH1에 불리하다. 둘 다 아직 개입 전 진단이라 진짜 판정은 2주차 27B 격자에서 나온다. 거기서 RH2가 안 보이면 5주 안에 못 고치므로 억지로 내지 않고 12월 ARR로 미룬다. 억지로 내면 리뷰가 남아 재제출이 어려워진다.

교수님께: "10월 ARR을 목표로 준비하되, 2주 뒤 27B 격자 결과를 보고 main 도전인지 Findings인지, 아니면 12월로 미룰지를 정하겠다."

추가 GPU 불필요. 병목은 VRAM이 아니라 27B 생성 시간과 GPT-4o 판정 비용이다.
