# 22. 방법 변형 후보, 모의 ARR 패널, 10월 12일 제출 판단 — 2026-09-11 전면 개정

**개정 사유.** 이 문서의 초판(2026-09-10, 당시 번호 17)은 병렬 세션이 09·13을 고쳐 쓰기 **전** 버전을 보고 작성됐다. 이후 09·13이 재작성되고 [17](17_manuscript_storyline.md)–[21](21_well_rag_reproducibility.md)이 추가됐으며, [23](23_gemma_steering_pilot.md)이 실행 우선순위를 Gemma 한 모델 파일럿으로 바꾸면서 "22의 27B·직교화 확정안과 이전 E2 격자를 실행 지시로 사용하지 않는다"고 명시했다. 초판의 상호참조는 전부 바뀐 텍스트를 가리켰다. 이 개정판은 **실행 지시가 아니라 판단 근거 문서**다. 실행 지시는 23, 실행 명세는 [19](19_method_protocol.md), 원고는 [17](17_manuscript_storyline.md)이 우선한다.

**새로 들어간 것.** 2026-09-11 모의 ARR 리뷰어 패널(§2–3), ARR 사이클 확인(§8), 10월 12일 PDF 최소 구성(§9), 정상 질문 검정력 계산과 의사 검증 교정문 확인(§6).

## 1. 결론

1. **방법 신규성으로는 main에 못 간다.** 모의 패널 12개 리뷰에서 두 가설이 모두 성립하는 최선의 시나리오조차 평균 soundness 3.33, excitement 3.00, 판정 Findings였다. **12개 전부 champion하지 않겠다고 했다.**
2. **점수를 움직이는 것은 측정 타당성이다.** 세 리뷰어가 각자 꼽은 최대 레버리지가 교정 내용의 의학적 정확성 검증, 게이트 타당성, 동일 효과 크기에서의 paired 검정 셋으로 수렴했다. 셋 다 새 알고리즘이 아니다.
3. **10월 12일에 낸다.** 2026년 ARR의 마지막 사이클이고, 건너뛰면 NAACL 2027은 사라진다. ARR은 학회를 지정하지 않고 제출하므로 commit하지 않는 비용이 거의 0이다. 비대칭이 분명하다.
4. 09 §9의 기여 세 항목과 "적용·정책 구성"이라는 지위는 유지한다. 방법 변형은 사전 등록한 부록 ablation으로 남기고, 본문 기여는 요인 분해와 측정 타당성 쪽에 둔다.

## 2. 모의 ARR 패널 (2026-09-11)

네 가지 결과 시나리오를 각각 세 관점에서 채점했다. 관점은 해석·표상공학 리뷰어, 의료 NLP 리뷰어, 메타리뷰를 쓰는 Action Editor다. 시나리오는 이 저장소 문서를 읽고 채점하게 했으며, 결과 숫자는 가정이고 실측이 아니다.

| 시나리오 | 내용 | Soundness | Excitement | 판정 |
|---|---|---|---|---|
| S1 | RH1·RH2 모두 성립, 모델 3개, CREPE 보조, 직교화 C ablation 양성 | 3.33 | 3.00 | Findings 2, borderline-findings 1 |
| S2 | RH2만 성립, 쌍둥이에서 probe가 텍스트를 못 이김 | 2.83 | 2.50 | Findings 3 |
| S3 | 둘 다 실패, 단 교정 방향과 과교정 방향이 공선(cos ≥ 0.9)임을 확립 | 2.50 | 2.50 | Findings 2, borderline-findings 1 |
| S4 | 27B만 완성, CREPE 없음, 최강 프롬프트 대비 CI 겹침 | 2.50 | 2.50 | Findings 2, borderline-findings 1 |

**표에 없는 숫자가 가장 중요하다. 12개 리뷰 전부 `would_champion = false`다.** 최선의 경우에도 토론에서 밀어줄 리뷰어가 없다.

시나리오 간 차이(3.33 대 2.50)보다 **모든 시나리오가 같은 천장에 걸린다는 사실**이 결론이다. 결과가 양성이냐 음성이냐로는 Findings를 벗어나지 못한다.

## 3. 반복된 반론 다섯

시나리오와 리뷰어를 가로질러 반복된 것만 적는다. 앞의 셋은 뿌리가 같다.

| 반론 | 리뷰어가 짚는 근거 | 대응 |
|---|---|---|
| **PCR의 +1이 의학적으로 맞는 교정인지 미검증이다** | 루브릭의 +1 정의는 "accurately addresses"로 정확성을 요구하고 0은 "correct information으로 충분히 다루지 못함"이다(정정 2026-09-14, 12 §15). 다만 "or question the presuppositions" 꼬리 때문에 판정기가 실제로 어느 쪽으로 읽는지는 확인된 바 없다. 판정 프롬프트에 gold 거짓 전제가 들어간다. C 자체가 판정 라벨의 +1/−1 차이이므로 **학습 신호와 평가 신호가 같은 함수**다. 자체 판정기 보정에서 3자 일치 58.2%, 카파 0.28 | §9의 2번. 585개 전부에 있는 의사 검증 교정문 대비 채점 |
| **게이트가 전제의 거짓을 읽는지 생성 파이프라인 흔적을 읽는지 불명** | 배포 위치 probe 0.70–0.74 대 질문 전체 TF-IDF 0.771. 0.80–0.82는 gold 구간이 필요한 비배포 readout이고 구간 정렬은 294/585만 성공. 쌍둥이는 LLM이 쓰고 LLM이 검수 | §9의 5번. control task selectivity와 자연↔쌍둥이 교차 전이 |
| **단일 작동점 비교다** | 프롬프트 arm은 자기 문턱을 못 받고, 무조건 C는 α 하나, 게이트는 문턱과 α를 함께 튜닝. 게이트 mask를 공유하는 설계인데 paired 검정 대신 겹치는 주변 CI를 본다 | §9의 3번 |
| 정상 질문이 150개뿐이고 ε가 숫자로 없다 | NFP와 Well TPQ는 같은 150문항([21](21_well_rag_reproducibility.md) 감사). harm을 세기만 하고 임상적 등급이 없다 | §6, §9의 1번 |
| 신규성이 Two Axes + Tripathi + CAST다 | S2·S3·S4에서 반복 | 09 §9의 지위 유지. 방법으로 반박하지 않는다 |

**AE의 지적 하나를 따로 적는다.** 결과가 음성이면 제목을 음성 결과로 바꾸고 oracle 행(선택이 완벽할 때 남는 피해)을 헤드라인으로 올리면 +1.0이라고 평가했다. 이 숫자는 선행 연구에 없다. 현재 17·18은 harm 귀속을 부록에 두고 있는데 본문으로 올릴 근거다.

## 5. selective steering 분야의 빈 자리

뼈대 h' = h + g(x)·α·v 안에서 문서 범위([07](07_related_work_2026.md) B3, [11](11_tripathi_review.md), [12](12_discussion_decisions.md) §11)에 비어 있는 자리.

| 빈 자리 | 왜 비었나 | 성격 | 우리 표 |
|---|---|---|---|
| 게이트가 배우는 것(조건 있음)과 맞혀야 하는 것(개입하면 좋아짐)이 다르다 | CAST 조건 벡터·Two Axes probe·Tripathi gate 모두 입력 속성 학습 | 방법 | 부록 A1 조건 행 |
| 방향이 하나이고 무엇을 담는지 분해된 적 없다 | 모든 교정 대조가 2-class. Dual-Stance Evaluation이 일반 도메인 증거 | 방법 | 부록 A1 개입 열 |
| **harm이 게이트 탓인지 방향 탓인지 귀속 안 한다** | Tripathi의 Rescue 551 / Harm 12는 합산 | 분석 | **본문 승격 권고** |
| 통제군이 약해 게이트의 텍스트 지름길을 못 잡는다 | E1의 TF-IDF 0.771 | 평가 | Table 1 쌍둥이 열 |
| 같은 게이트에서 프롬프트 개입 대 활성값 개입 정면 비교가 없다 | Two Axes는 라우팅만, Tripathi는 steering만 | 분석 | Table 2 두 행의 paired 대비 |
| **교정의 의학적 정확성을 잰 적이 없다** | Well의 표상 수준 행(FAITH)은 S5가 0–2%. 정확성 분해 없음 | 평가 | **§2가 지목한 최대 레버리지** |

마지막 줄은 초판에 없었다. 패널이 추가했다.

## 6. 데이터로 확인한 것

**Cancer-Myth `all_data.json` 집계** (585문항 × 프론티어 8모델, 2026-09-10 확인)

| 항목 | 개수 |
|---|---|
| +1 참조 답변 | 558 |
| 0 참조 답변 | 1480 |
| −1 참조 답변 | 2642 |
| +1과 0을 둘 다 가진 질문 | 200 |
| +1과 −1을 둘 다 가진 질문 (현재 `c_pair`) | 232 |
| 셋 다 가진 질문 | 193 |

"+1 − 0" 대조는 셀 수는 있으나 취지와 다르다. 193개 3중 질문에서 반박 형태의 0점 답변은 7개뿐이고, 0점은 "틀린 사실로 반박"이 아니라 "전제 주변을 돌며 얼버무림"이다.

**그러나 막힌 것은 벡터 구성 경로 하나뿐이었다.** 패널이 막히지 않은 두 경로를 제시했다.

| 확인 항목 | 값 |
|---|---|
| 의사 검증 교정문(`example_assumption`)이 있는 질문 | 585 / 585 |
| 길이 중앙값 | 303자 |
| 실질적 `source_info.fact`가 있는 질문 | 583 |

- **평가 경로.** +1로 판정된 응답을 이 교정문과 entailment로 대조해 반박률과 반박 시 정확도로 분해한다. 새 주석이 필요 없다.
- **합성 경로.** 이 교정문의 의학적 주장만 오염시켜 자신 있게 틀린 반박을 만든다. 자유 텍스트 답변에 구간 치환 도구가 없다는 초판의 판단은 **참조 교정문을 쓰면 우회된다.**

**정상 질문 검정력.** NFP 150과 Well TPQ 148은 같은 질문이다(few-shot 2개 차이, [21](21_well_rag_reproducibility.md)에서 SHA256까지 확인). 정상 질문은 300개가 아니라 150개다. 같은 150문항의 짝지은 비교에서 신뢰구간 반폭은 다음과 같다.

| 판정이 바뀐 문항 수 | 95% CI 반폭 |
|---|---|
| 10 | ±4.1%p |
| 20 | ±5.8%p |
| 30 | ±7.2%p |

**ε를 5%p보다 좁게 잡으면 150개로는 검정이 성립하지 않는다.** 참 전제 쌍둥이를 FPQ마다 만들면 최대 585개가 되어 과교정 쪽 반폭이 약 절반으로 줄어든다. 쌍둥이는 교란 통제 선택지가 아니라 **보존 주장을 통계적으로 성립시키는 수단**이다. 19가 주 방법에서 합성 쌍둥이를 제외한 결정은 이 계산과 함께 재검토해야 한다(§10).

## 8. ARR 10월 사이클 (2026-09-11 확인)

| 항목 | 값 |
|---|---|
| 2026년 ARR 사이클 | 1월 5일, 3월 16일, 5월 25일, 8월 3일, **10월 12일** |
| 10월 12일의 지위 | **2026년 마지막 사이클.** 다음은 2027년 |
| NAACL 2027 commit 마감 | 12월 20–23일 |
| NAACL 2027 본회의 | 2027년 6월 1–5일, 샌프란시스코 |
| 공유 사이클 | COLING 2027. commit 때 한 곳만 고른다 |

**절차.** ARR에는 학회를 지정하지 않고 제출한다. 리뷰와 Action Editor 메타리뷰를 받고, NAACL에 commit하고, **NAACL의 SAC·PC가 그 점수로 main / Findings / reject를 정한다.** 우리가 트랙을 고르지 않는다. 초판 §6의 "2주 뒤 main인지 Findings인지 정한다"는 표현은 틀렸으므로 철회한다.

**비대칭.** commit하지 않는 비용은 거의 0이다. 점수가 나쁘면 다음 사이클에 재제출하며 이전 리뷰를 같이 낸다. 반대로 10월 12일을 건너뛰면 다음 사이클 리뷰가 commit 마감 이후에 나오므로 **NAACL 2027은 사라진다.** Limitations 섹션 누락은 desk reject다(기억 기준, 제출 전 ARR 양식으로 재확인).
