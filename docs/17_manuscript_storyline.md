# 17. 논문 구성 — Introduction부터 Conclusion까지

2026-09-09. 교수님께 설명하고 논문을 쓰기 위한 **절별 작성 설계**다. 가설은 [09](09_research_proposal.md), 실행 명세는 [13](13_task_spec.md), 문헌 근거는 [10](10_evidence_and_baselines.md)·[11](11_tripathi_review.md)을 따른다. 아래 예상 결론은 실험 결과가 지지할 때만 사용할 문장이다. 표의 빈칸은 미실행·미확정 결과이며, 이전 대화의 설명용 가상 숫자는 넣지 않는다.

## 0. 논문 전체를 관통하는 주장

**연구 질문:** 의료 질문에서 교정할 대상을 선택하면, 정상 질문과 일반 의료 QA의 손실을 제한하면서 잘못된 전제를 더 잘 교정할 수 있는가? 그 선택에 내부 표상이, 선택 후 개입에 activation steering이 추가로 기여하는가?

**가설이 모두 지지될 때의 한 문장 주장:**

> 의료 질문의 내부 표상으로 교정 대상을 선택하고 교정 개입을 적용하여, 정상 질문과 일반 의료 QA의 성능을 사전 허용폭 내로 유지하면서 거짓 전제 교정 성능을 개선한다.

이 문장의 세 부분을 따로 검증한다. **내부 신호의 추가 가치(RH1)**, **선택적 교정의 효과와 개입 방식의 차이(RH2/RH2b)**, **의료 QA 보존(RH3)**이다. 활성값 개입의 우위가 확인되지 않으면 steering의 우월성을 결론에 넣지 않는다. 내부 신호의 우위가 확인되지 않으면 내부가 필요하다는 주장을 빼고 선택적 개입의 결과와 한계를 보고한다.

**서사 한 줄:** 전제 교정 누락 → 기존 완화책에서 관찰된 성능 상충 → 교정 대상을 선택하자는 가설 → 선택 신호와 교정 연산의 명세 → 최종 효용과 부품별 효과의 검증 → 성립 조건과 한계.

**현재 연구의 지위:** 조건부 개입의 의료 배경 전제 적용·분석이다. CAST의 조건/행동 분리, Two Axes의 probe 기반 프롬프트 라우팅, Tripathi의 의료 내부 gate와 steering이 선행한다. 데이터·목표·평가를 바꾼 것만으로 새로운 알고리즘이라고 부르지 않는다. 추가 알고리즘 기여를 주장하려면 구체적 변경과 그 변경만 제거한 비교가 필요하다.

## 2. Introduction — 다섯 문단으로 작성

### 문단 1: 답변의 사실성과 전제 교정은 다른 평가 대상이다

**할 말:** 환자는 잘못된 믿음을 질문의 전제로 포함할 수 있다. 답변이 표면 질문에만 대응하면 그 믿음을 명시적으로 바로잡지 못할 수 있다. Cancer-Myth는 이 문제를 전문가 검증 질문과 교정 지표로 평가했다.

**문장 초안:**

> 의료 질문에 유용하게 답하려면 요청된 정보뿐 아니라 질문이 전제하는 주장도 검토해야 한다. 잘못된 전제를 그대로 둔 답변은 환자의 오해를 해소하지 못할 수 있다. Cancer-Myth는 이러한 전제 교정 누락을 평가하며, 의료 QA의 정답 정확도와 별도로 측정할 필요를 보여준다.

근거: [Cancer-Myth](https://arxiv.org/html/2504.11373v3), [10 §1](10_evidence_and_baselines.md#1-cancer-myth--문제와-본-평가표의-출발점). 예시는 검증된 benchmark 문항과 반박을 사용한다. 서로 다른 시험의 백분율을 직접 빼서 능력 차이를 추정하지 않는다. 임상적 위해 감소는 이번 benchmark만으로 입증하지 않는다.

### 문단 2: 목표는 높은 FPQ 점수와 정상 질문 보존을 함께 달성하는 것이다

**할 말:** 전제 검사 지시·프롬프트 최적화 등의 방법은 평가된 설정에서 FPQ 교정을 개선했지만, 정상 전제를 부당하게 부정하거나 다른 의료 QA 점수가 하락하는 경우가 있었다.

**문장 초안:**

> 기존 완화책은 전제 교정 성능을 높일 수 있지만, 정상 질문에서도 교정을 시도하는 부작용이 보고되었다. Cancer-Myth와 Well-Actually의 결과는 교정률만으로 방법을 평가하기 어렵다는 점을 보여준다. 우리는 정상 질문의 손실을 사전에 정한 범위로 제한하면서 거짓 전제 교정을 개선하는 문제를 다룬다.

근거: Cancer-Myth Table 1, [Well-Actually](https://arxiv.org/html/2608.06539v1), [10 §1–2](10_evidence_and_baselines.md). 정상 전제 오교정과 의료 QA 하락을 구분해 인용한다. 모든 prompting의 실패나 모든 모델에서의 성능 하락으로 일반화하지 않는다. WildChat의 FPQ 비율을 의료 질문의 발생률로 가정하지 않는다.

### 문단 3: 선택적 개입이라는 가설과 선행 방법의 위치

**할 말:** 개입 대상을 고르는 부품과 실제로 고치는 부품을 나누어 평가하면, 정상 질문의 손실을 줄이는 선택 정책을 검증할 수 있다. 이 구조 자체는 기존 조건부 개입에서 가져온다.

**문장 초안:**

> 이를 위해 교정 대상을 판별하는 단계와 선택된 질문에 교정 연산을 적용하는 단계를 구성한다. 조건부 steering과 probe 기반 라우팅은 이러한 접근의 출발점이다. 의료 질문의 배경 전제와 어려운 정상 질문에서 어떤 선택 신호와 개입이 유용한지는 동일한 평가 조건에서 확인해야 한다.

근거: CAST, Two Axes, Tripathi. Related Work에서 직접 비교한다. CAST가 조건과 행동을 구분하지 못했다거나 Tripathi가 내부 신호를 쓰지 않는다고 쓰지 않는다.

### 문단 4: 왜 내부를 보나 — CoT를 포함한 비교 가설

**할 말:** 내부 readout은 생성 이전 신호를 활용할 수 있는 후보이다. CoT의 불완전한 충실성은 비교의 동기가 되지만 CoT monitor의 무용성을 뜻하지 않는다. 명시적 전제 검사 CoT와 내부 방법을 모두 평가한다.

**문장 초안:**

> 우리는 질문 텍스트와 생성된 전제 검토 설명에 더해, 타깃 모델의 내부 표상이 교정 대상 선택에 추가 정보를 제공하는지 검증한다. CoT prompting은 최종 답변을 개선하는 비교 대상으로, CoT monitoring은 개입 대상을 고르는 비교 대상으로 포함한다. 또한 동일한 선택 결과 아래 프롬프트 개입과 활성값 개입을 비교한다.

근거: [10 §5](10_evidence_and_baselines.md#5-cot로-하면-안-되는가에-대한-근거의-구분). prefill probe의 비용·지연 이점도 실제로 측정해야 한다. 성능이 같다는 이유만으로 내부 방법이 더 싸다고 단정하지 않는다. 모델의 내부 계산 전체나 숨겨진 믿음을 읽는다고 주장하지 않는다.

### 문단 5: 접근 요약, 주 결과 예고, contribution 세 개

**접근 요약:** 질문의 prefill에서 probe 점수를 계산하고, 개발 데이터로 정한 문턱을 넘는 질문에 교정 개입을 적용한다. 방향과 문턱은 학습·개발 데이터에서 정하며 최종 평가에서는 고정한다.

**결과 예고 슬롯:** "[모델·평가 범위]에서 Plain 대비 PCR이 [Δ와 CI] 변했고, NFP 및 [QA 평가]의 손실은 [허용폭·CI]였다." 아직 이 슬롯에 탐색 결과나 가상 숫자를 넣지 않는다. Table 2의 주 결과를 여기서 먼저 소개한다.

**가설이 지지될 때 사용할 contribution 초안:**

1. **내부 신호의 추가 가치:** 의료 질문에서 질문 텍스트와 명시적 전제 검토 CoT에 비해, 내부 표상이 낮은 정상 질문 오탐 조건에서 거짓 전제 질문을 판별하고 유용한 개입 대상을 선택하는 데 추가 가치를 제공함을 보인다.
2. **교정 개입의 추가 가치:** 동일한 질문을 선택한 상태에서, 활성값 개입이 교정 프롬프트보다 정확한 전제 교정을 개선하는 조건과 정상 질문에 미치는 영향을 규명한다.
3. **교정과 성능 보존의 동시 달성:** 선택과 개입을 결합한 시스템이 기존 비교 방법 대비 의료 전제 교정의 성능 상충을 개선하고, 정상 질문과 일반 의료 QA의 손실을 사전 허용폭 안으로 제한함을 보인다.

세 항목은 신호·개입·시스템의 예상 결과를 구분한다. 적용·정책 구성을 새로운 알고리즘 발명으로 포장하지 않는다. 지원하지 않는 결과는 실제 초록·서론에서 삭제하거나 제한한다. 2026-09-10 교수님 발표에서는 [18의 1–8장](18_professor_presentation_script.md)을 Intro 원고로 사용한다.

## 3. Related Work — 네 묶음과 직접 선행연구

논문을 연도순으로 나열하지 않는다. **선행연구가 해결한 부분 → 우리에게 남는 평가 질문 → 대응 baseline** 순서로 쓴다.

**교수님 발표 구성:** [18의 9–10장](18_professor_presentation_script.md)은 Two Axes에, 11–12장은 Gated Activation Steering에 각각 두 장을 할애한다. 각 논문의 첫 장은 문제·방법, 둘째 장은 결과·한계·우리 평가와의 연결을 설명한다. Introduction에서 선행 결과를 상세히 반복하지 않으며, CAST와 직접 비교 조건은 13장에서 정리한다. 장 번호와 우리 논문의 Table 번호는 별개다.

**CAST:** 조건 벡터와 행동 벡터를 구분한 선행 방법이다. FPQ/TPQ로 적용한 CAST를 baseline으로 두고, 원 레시피에서 변경한 부분을 명시한다. CAST의 의료 전제 실패는 사전 사실이 아니다. [원문](https://arxiv.org/abs/2409.05907) · [구현](https://github.com/IBM/activation-steering)

**Two Axes:** 전체 논문은 정답 여부와 답변 가능성의 같은 문항 분석·위험별 정책을 제안한다. 선형 probe 자체의 최초 제안은 아니다. CREPE의 거짓 전제 readout·라우팅은 우리의 탐지 목표와 직접 겹치므로, answerability라는 제목만으로 다른 문제라고 구분하지 않는다. 논문의 일반 도메인 결과를 의료에서 재현했다고 미리 가정하지 않는다. 47%·61%는 전체 FPQ에서 NLI가 검증한 교정 비율이므로 gate 성능에 곱할 조건부 성공률로 쓰지 않는다. [원문 §6](https://arxiv.org/html/2607.08456v1#S6)

**Tripathi:** ITI·probe·평균 차를 행동별 gate 및 head ablation과 결합하고 정상 응답 보존을 평가한다. EHR 비지지 주장과 사용자 압력은 의학적 전제 진위와 다르지만 의료 adaptation이 가능하다. MedQuAD 20문항의 강도 선택 중 참조 유사도도 확인했으므로 QA 보존을 전혀 고려하지 않았다고 쓰지 않는다. 우리의 가장 직접적인 중복 후보 중 하나다. 공개 artifacts의 호환 모델 전이와 FPQ/TPQ로 재학습한 adaptation을 구분한다. 비교를 실행하지 않았다면 경험적 우위를 주장하지 않는다. [원문](https://arxiv.org/abs/2608.23666) · [공개 runtime 검토](11_tripathi_review.md)

**CoT 논의의 범위:** 충실성의 한계와 모니터링의 유용성을 함께 소개한다. CoT 연구 전체에 대한 반박을 논문의 동기로 삼지 않는다. [Turpin et al.](https://arxiv.org/abs/2305.04388) · [Monitoring Reasoning Models for Misbehavior](https://arxiv.org/abs/2503.11926)

**AO/NLA:** 현재 주 방법의 필수 부품이 아니다. probe보다 해석 가능한 설명을 얻는 부록 분석 후보로 둔다. 활성값 제거·섞기·텍스트만 입력 통제 없이 자연어 설명을 모델 내부의 진실로 읽지 않는다. AO/NLA 목적식 개선은 아직 이 논문의 확정 기여가 아니다.

## 4. Methodology — 재현 가능한 정책 명세

### 4.1 문제와 목표

입력 q는 환자 질문이다. y_FP는 전문가 검증 거짓 전제 유무이며, 평가·학습용으로만 제공된다. 최종 답변 r의 전제 교정(PCR/PCS), 공식 NFP 지표와 부록의 Well FPQ/TPQ 원 점수, 별도 의료 QA 정확도를 구분한다. NFP/TPQ가 같은 원 질문에서 나오면 두 배의 독립 표본으로 세지 않는다.

**전제 진위는 개입 이득의 대리 지표다.** FPQ라도 Plain이 이미 잘 고치면 추가 개입이 불필요할 수 있고, 개입이 답을 악화시킬 수도 있다. gate가 FPQ를 맞혔다고 교정 성공이나 인과적 이득이 보장되지는 않는다.

구체적 학습·추론 명세는 [19 — Method 실행안](19_method_protocol.md)에 둔다. 주 방법은 마지막 프롬프트 토큰의 표준화+L2 logistic probe와, fit 질문의 교정/비교정 참조 응답 첫 32토큰 평균 차 방향이다. 발표에서는 이를 14–17장의 네 단계로 설명한다.

### 4.2 교정 대상 선택: gate

기본 내부 점수는 마지막 프롬프트 토큰의 고정 층 hidden state에 학습한 선형 probe를 적용해 얻는다.

```text
z(q) = (h_k(q) − μ_fit) / σ_fit
s(q) = wᵀz(q) + b  # logit
g(q) = 1[s(q) ≥ τ_policy]
```

주 위치는 마지막 프롬프트 토큰으로 고정한다. scaler와 probe는 fit에서 학습하고, 층·L2 규제는 dev AUROC로 고른다. Table 1 탐지용 τ_det와 Table 2 응답 성능으로 고르는 τ_policy를 구분하고 모두 dev에서 고정한다. 두 문턱은 logit 단위다. 원 질문에서 산출한 문항별 점수·mask를 저장한다. 전제 구간 readout을 비교할 때는 gold 전제 주석을 배포 입력으로 쓰지 않는다. 자동 추출을 사용하면 추출 비용·실패율을 포함하고, gold 구간 분석은 별도 진단으로 표시한다.

텍스트·CoT gate도 같은 목표 라벨을 예측한다. CoT monitor는 생성한 검토 텍스트를 읽어 gate를 정하고, 최종 답변은 별도 생성한다. 그 CoT를 최종 답변 입력에도 넣는다면 추가 개입이므로 별도 조건으로 구분한다. gate가 닫혀도 CoT 생성 비용은 발생한다.

### 4.3 선택된 질문에 적용할 교정 연산

주 방법은 마지막 프롬프트 위치부터 이후 decode까지 decoder block 출력 residual에 C 방향을 더한다. gate는 별도의 개입 없는 prefill에서 먼저 읽는다. final norm 이전/이후 혼용을 피하도록 마지막 hidden state는 주 후보에서 제외한다.

```text
답변 pass의 선택 층·적용 위치에서: h' = h + g(q) · α · ρ_fit · c
g(q) = 0이면 기준 생성 정책
```

C는 fit FPQ의 +1/−1 참조 응답을 같은 타깃 모델에 teacher-forcing하고 첫 32토큰 평균 활성값의 짝 차이를 질문별로 평균·정규화하여 만든다. 원 참조 응답의 출처 균형도 fit에서만 정한다. 첫 5토큰·자연 응답 비짝 대조·시스템 지시 대조는 부록 후보로 둔다. 짝 대조는 질문 차이로 인한 교란을 줄이지만 내용·문체·질문과 응답의 상호작용을 정확히 제거하지 않는다. 학습에 쓰는 참조 답변·judge 라벨은 평가 fold에서 가져오지 않는다.

방향의 AUROC나 cos(A,C)만으로 교정 능력을 선택하지 않는다. 교정 층은 깊이의 1/4·1/2·3/4, α는 {0, 0.02, 0.05, 0.1, 0.2, 0.5}를 후보로 **내부 개발 문항에서 실제 응답을 생성하고**, 정상 질문 손실 제약 아래 교정 효과로 선택한다. cos(A,C)는 진단이며, 작다고 독립 회로가 증명되거나 크다고 분리가 실패하는 것은 아니다.

ρ_fit은 fit 질문의 residual norm 중앙값으로 고정하며 test나 resume batch에서 재추정하지 않는다. 주 생성은 greedy·최대 새 토큰 512·감쇠 없는 steering이다. 프롬프트 개입은 같은 gate가 선택한 질문에 교정 지시만 추가하며 탐지를 다시 하지 않는 비교 조건이다. Gated 의료 head 재학습은 본 Table 2의 직접 baseline이다. 추가 head 변형·A∧C·직교화 C는 사전 명세한 부록 ablation이다.

### 4.4 개발 목표와 최종 정책 고정

```text
개발에서 최대화: FPQ 교정 성능
제약: NFP 점수 손실 ≤ ε_NFP
```

일차 지표, 동률 처리, 후보 예산, ε_NFP를 명시한다. QA는 [13](13_task_spec.md)의 규칙으로 정한 최종 시스템을 재조정 없이 적용하는 보존 평가다. 허용폭은 허용 가능한 손실에 근거해 정하며 표본 수만으로 정당화하지 않는다. 표본이 부족하면 CI가 결론을 내리지 못할 수 있다.

**보존은 경험적·통계적 평가다.** gate 오탐률만으로 보장되지 않는다. test 성능 차이의 신뢰구간과 사전 비열등성 기준으로 판정한다. 평균 차이가 작거나 유의하지 않다는 것만으로 보존을 선언하지 않는다.

## 5. Experimental Setup — 기존 표를 계승하는 방식

1. **데이터·중복:** Cancer-Myth 585 FPQ와 150 NFP/TPQ의 유효 ID·라벨 대응을 확인한다. 같은 myth, 의역, NFP–TPQ, 합성 참·거짓 쌍을 같은 그룹으로 묶는다. 합성 쌍은 원래 정상 질문 평가를 대체하지 않는다.
2. **평가 분할:** nested grouped 5-fold cross-fitting을 사용한다. probe·C·GEPA·CAST 등 모든 학습 부품은 outer train에서, 종류·층·문턱·강도 선택은 inner dev에서만 정한다. outer 평가 결과로 gate 우승자를 고른 뒤 같은 결과를 다시 확증 자료로 쓰지 않는다.
3. **모델·baseline:** 모델 revision·chat template·생성 설정·추가 데이터·탐색 예산을 보고한다. Table 2는 완성 방법을 공통 규칙 아래 조정한다. 두 Hidden 행은 같은 gate를 공유한다. Table 3는 주석 전제 사실 확인 조건, 부록 Table A1은 같은 C·K의 선택 비교다.
4. **판정:** 본 표의 PCR/PCS·공식 NFP는 Cancer-Myth 판정 절차다. Table 3는 Well 사실 확인 정확도, 최종 응답 S5·분포는 부록으로 두고 judge 등이 다르면 adaptation으로 표시한다. 미확정 TPQ 이산화 지표는 주 제약에 쓰지 않는다. parse 실패를 정답으로 세지 않고, 미판정률·재시도 및 분모 처리 규칙을 공개한다.
5. **통계:** 주 지표·비열등성 허용폭·신뢰수준·다중 비교 처리를 고정한다. 같은 문항의 방법 간 차이를 짝지어 추정하고, myth·짝 문항의 의존성을 반영한다. 고정된 OOF 예측을 재표집한 CI는 학습/모델 선택의 전체 불확실성을 포함하지 않음을 명시한다. 방법별 CI의 겹침만으로 우열을 판정하지 않는다.
6. **QA:** MedQA·PubMedQA·Medbullets에 사전에 지정한 최종 정책을 적용한다. benchmark 이름으로 gate를 끄지 않는다. fold별 정책으로 낸 FPQ OOF 성능과 사전 지정한 최종 train/calibration 규칙으로 재적합한 QA 정책의 관계를 설명한다. 개별 QA의 CI와 발화율을 보고한다.
7. **원 표 재사용:** 데이터 수와 열이 같아도 cross-fitting·판정기·모델이 다르면 원본과 동일 실험이 아니다. Well의 실제 split ID를 확보하기 전에는 Table 8–10에 직접 비교 가능한 행을 붙였다고 쓰지 않는다. 출판 수치는 참고 행으로 분리하고 재실행 수치로 비교한다.

**현재 단계의 공개:** E1 중간 결과를 본 뒤 이 계획을 정교화했다. 따라서 모든 가설·선택이 어떤 데이터도 보기 전에 사전 등록됐다고 쓰지 않는다. 탐색에 사용한 데이터·설정과 이후 고정한 평가를 구분한다. 기존 탐색 데이터의 cross-fitting은 학습 누수를 줄이지만 이전 연구자 선택의 영향을 지우지 않는다. 완전히 새 held-out 검증을 추가할 경우 그 역할과 분할을 별도로 명시한다.

**보고 규칙.** 모델마다 동일한 행 블록을 반복하고, 세 QA 열을 모든 주 비교 방법에 채운다. 정상 지표·QA의 보존 여부는 Plain 대비 paired 차이의 CI와 사전 허용폭으로 판정하며, 해당 차이와 판정은 표 주석 또는 동반 부록 표에 제시한다. NFP와 Well TPQ는 같은 정상 질문이다. 본 표는 공식 NFP 하나를 주 지표로 쓰고, Table 3는 주석 전제의 참·거짓 정확도이며 Well 최종 응답 S5와 0–5 분포는 부록에 둔다. 미확정 TPQ 이산화 지표는 주 평가에서 제외한다. 정확한 답 추출·무효 출력 처리 규칙도 QA별로 잠근다. 데이터셋별 개입률·harm/rescue·비용은 부록에 보고하여 QA를 하나의 불명확한 발화율로 합치지 않는다.

**결과 문단에 쓸 순서:** Plain 대비 FPQ 변화 → NFP 비열등성 → 기존 방법 대비 같은 허용폭에서의 차이 → QA 보존 → 비용·실패 사례. 먼저 주 결과를 답하고 모델별 경향은 뒤에 설명한다. 다른 baseline이 같은 목표를 달성하면 그것도 보고한다.

**추가 행의 범위.** 내부 행은 주석 전제와 해당 근거를 입력받는 판별기의 진단이다. 원 질문만 읽도록 학습한 현재 A gate를 그대로 옮기거나 C steering의 최종 응답 점수를 붙이는 행이 아니다. 동일한 전제·근거·few-shot 문맥에서 출력 판정과 내부 readout을 비교한다. probe는 전제 단위 fit 자료에서 별도로 학습하고 층·문턱은 dev에서 고정한다. 같은 질문의 여러 전제와 같은 myth는 같은 fold에 묶는다. 추가 CoT 행은 전제를 검토한 뒤 참·거짓을 판정하는 비교이며 별도 모니터가 환자 답변을 채점하는 절차가 아니다. 원 모델이 지원하는 reasoning 설정과 추가 CoT 프롬프트도 구분한다.

## 7. Discussion and Limitations — 해석의 범위

- **표상 해석:** probe의 예측 성공은 정의한 라벨이 읽힌다는 증거다. 모델의 지식·믿음·실제 사고 과정 전체를 증명하지 않는다. A×C 분포에 "알고도 동조" 같은 확정 원인 라벨을 붙이지 않는다.
- **설명 정확성:** PCR/PCS와 NFP는 모든 의학적 설명 단계의 정확성 또는 CoT faithfulness와 다르다. 설명 전체의 정확성을 주장하려면 별도의 내용 평가가 필요하다.
- **데이터와 통계:** 어려운 NFP의 작은 표본, 같은 원 질문의 중복, 문체·주제 shortcut, 합성 쌍의 생성 흔적, 탐색 후 설계 변경을 공개한다. NFP가 어려운 데이터라는 이유로 다른 논문의 정상 질문보다 반드시 어렵다고 정량 단정하지 않는다.
- **judge와 비용:** 자동 판정기의 오류·미판정, 모델과 judge 버전, readout 정보 시점, CoT 생성 및 hidden-state 접근 비용을 보고한다.
- **전이와 임상 적용:** 단일 턴 암 질문에서 나온 결과를 다른 진료 분야·EHR 다중 턴·실제 환자 안전으로 확장하지 않는다. QA 정확도 보존도 임상적 유효성 인증은 아니다.
- **독창성:** 구조의 출처와 적용 변경을 분명히 쓴다. 보존 제약 추가나 AO/NLA 사용만으로 새 방법론을 주장하지 않는다.
