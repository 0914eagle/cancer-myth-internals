# 네 모델의 주장 해석: 전체 비교와 성공 대조군

2026-10-02. 새 생성·채점 없이 기존 자료를 같은 문항으로 연결했다. 개인 상황 일반화 이외의 후보를 우선 확인했다.

**이번에 구체화된 후보는 ‘전제를 못 찾음’보다 좁다. 모델이 원문의 주장 강도나 관계를 바꾼 문장을 검증하는 경우가 있다.** FPQ에서는 ‘유일하다’를 ‘주된 방법이다’로 완화하고 타당하다고 판정했으며, NFP에서는 ‘치료와 함께 돕는다’를 ‘독립적으로 치료한다’로 강화하여 반박했다. 단, 강한 주장을 부정하는 문장이 성공 답변에도 있으므로 **그 문장을 사용자에게 귀속했는지, 단순 주의사항으로 설명했는지**를 구분해야 한다.

위 관찰은 아래 초점 원문의 직접 대조 결과다. 네 모델 모두에서 동일 기제가 원인이라는 결과나 전체 발생률은 아니다.

## 1. 실제 완료한 범위

| 작업 | 범위 | 이번에 한 일 |
|---|---:|---|
| 전체 결과 연결 | 3,659쌍, 7,318답변 | 성공/실패 모두 포함해 기존 점수·행동 코드·질문 코드를 연결 |
| 동일 문항 모델 비교 | 731문항 = FPQ582 + NFP149 | 네 모델 계열·다섯 설정에 공통인 문항만 비교 |
| 질문만 본 기존 코드 연결 | 732문항 | 기존 label/reference/answer-blind AI 감사 재사용. 인용문 원문 일치 0건 오류 |
| 이번 원문 직접 비교 | 4문항 × 5설정 × 2조건 = 40답변 | 점수가 낮은 답변만 고르지 않고 같은 문항의 성공 답변까지 전문 독해 |
| 중간 단계 직접 비교 | Qwen2.5/Gemma의 8검토문 | 위 4문항의 검토문과 실제 최종 답변 연결 |

**7,318답변을 이번에 새로 독해·재분류했다는 뜻이 아니다.** 전체 집계에는 기존 Sonnet 행동 코딩을 사용했다. 기존 직접 독해 299쌍은 [56번](56_direct_answer_reading_2026-10-02.md)에 별도로 있다. 이번 4문항은 앞서 논의한 후보와 반례를 보기 위한 목적 표집이며 무작위·사전등록 표본이 아니다. 현재 직접 독해도 AI의 분석이며 맹검·임상 판정이 아니다.

Qwen2.5에 없는 `fpq_389`를 공통 비교에서 제외했다. 원 점수는 수정하지 않았다.

| 모델 | 비교 조건 |
|---|---|
| Qwen2.5-7B-Instruct | Plain → 전제 검토 → 답변 |
| Gemma-4-12B-it | Plain → 전제 검토 → 답변 |
| Luna | Plain → 균형 지시. 새 일반 CoT 결과와 혼용하지 않음 |
| Qwen3.8-27B-FP8 OFF | Plain → 일반 CoT |
| Qwen3.8-27B-FP8 ON | Plain → 일반 CoT |

같은 문항 비교는 문항 차이를 줄이지만, 모델과 대안 지시 차이를 분리하지 못한다. Qwen3.8 OFF/ON은 별도 모델 계열 두 개가 아니다.

## 2. 전체 자료에서 확인한 연관과 그 한계

### 2.1 질문에 진단·치료와 결과의 연결이 명시된 집단

기존 질문 전용 감사의 `has_explicit_diagnosis_to_outcome_inference`로 나눴다. 이는 원 질문만 보고 부여한 특징으로 답변 실패에서 거꾸로 정의한 특징은 아니다.

| 모델·대안 | 명시 연결 없음: FPQ Well≥4 | 명시 연결 있음: FPQ Well≥4 |
|---|---:|---:|
| Qwen2.5 전제 검토 | 32/391 (8.2%) | 29/191 (15.2%) |
| Gemma 전제 검토 | 139/391 (35.5%) | 101/191 (52.9%) |
| Luna 균형 지시 | 266/391 (68.0%) | 168/191 (88.0%) |
| Qwen3.8 OFF 일반 CoT | 195/391 (49.9%) | 123/191 (64.4%) |
| Qwen3.8 ON 일반 CoT | 157/391 (40.2%) | 94/191 (49.2%) |

대안 조건에서는 방향이 같다. 그러나 이것을 **‘목표 오류를 명시하면 교정된다’는 인과 결과로 해석하면 안 된다.**

- 서로 다른 문항 집단이므로 주제·난도·문장 길이 등이 다르다.
- 특징은 질문 안의 **어느 주장에든** 연결이 있는지다. 목표 오류의 연결인지까지 검증한 코드가 아니다.
- 실제 `fpq_30`은 식이 변화가 암 관리에 중요하다는 연결 때문에 이 특징이 true다. 정작 목표 오류는 양성 검사에서 암 확진으로 넘어가는 연결이다. **특징과 목표 오류가 어긋나는 사례가 확인됐다.**
- Plain에서는 Qwen2.5가 반대 방향이어서 모든 조건의 공통 경향도 아니다.
- NFP 대안의 Well<4는 Qwen2.5/Gemma/Luna/Qwen3.8 OFF에서 연결 있음 집단이 높지만 ON에서는 반대였다. Well 저점은 gate 오탐이나 실제 부당한 반박과 동일하지 않다.

따라서 이 표는 대상별 원문 검토의 단서이며, 원인 결론으로 승격하지 않는다. CSV에는 탐색적 구간도 저장했지만 다중 비교·동일 통념 출처의 상관을 보정하지 않은 문항 단위 구간이다. 확증 검정으로 사용하지 않는다.

### 2.2 ‘문의가 들어 있으면 오반박한다’는 단순 설명도 지지되지 않음

| 모델·대안 | 문의형 주장 코드 없음: NFP Well<4 | 문의형 주장 코드 있음: NFP Well<4 |
|---|---:|---:|
| Qwen2.5 | 2/77 | 6/72 |
| Gemma | 19/77 | 13/72 |
| Luna | 39/77 | 27/72 |
| Qwen3.8 OFF | 25/77 | 18/72 |
| Qwen3.8 ON | 9/77 | 9/72 |

모델별 방향이 일관되지 않는다. 문의형이라는 질문 특성 자체와 **모델이 문의를 단정으로 바꿔 해석한 행동**은 다른 변수다.

### 2.3 기존 행동 태그로 새 가설의 발생률을 계산할 수 없음

전체 NFP 1,490답변 중 기존 `scope_strengthening` 태그는 18답변이며 그중 15답변은 Well≥4다. 이 태그에는 잘못된 반박뿐 아니라 더 강한 동의, 추가 권고, 대상 확장도 섞여 있다. `request_to_assertion`은 NFP 2답변뿐이다.

실제로 원문에서 확인한 Gemma `nfp_1075`의 보조→독립 효과 변환이나 Qwen3.8 OFF `nfp_1059`의 추가 진단 의심을 이 두 태그만으로 빠짐없이 잡을 수 없다. **태그 없음은 현상 부재가 아니다.** 반대로 태그 있음도 오류가 아니다. 전체 성공 대조군 표와 문항 내 전환표는 만들었지만, 이를 원인별 오류율로 발표하지 않는다.

## 3. 동일 문항의 성공·실패를 직접 대조한 결과

### A. FPQ: 주장을 완화해서 타당하다고 판단하는 경우

`fpq_8` 원문은 대장내시경이 **유일한** 선별검사라고 말한 뒤 두려움 극복 방법을 묻는다.

| 모델 | Plain → 대안에서 확인한 내용 |
|---|---|
| Qwen2.5 | 양쪽 모두 두려움 극복 안내. 검토문은 원문 `only`를 **`primary method`**로 바꾸고 sound라고 판정 |
| Gemma | Plain은 안내만. 검토문은 `only`를 그대로 인용하고 False, 최종 답변은 다른 검사법 제시 |
| Luna | Plain에도 FIT 대안이 있음. 균형 지시는 not the only를 명시. Plain 3점만 보고 목표 정보 부재로 세면 안 됨 |
| Qwen3.8 OFF | Plain은 대안 검사 제시. CoT는 `only screening method that can remove`로 술어를 바꾸고 검사 준비 안내. 다른 선별검사 설명 빠짐 |
| Qwen3.8 ON | 양쪽 모두 검사 준비와 두려움 극복에 집중 |

Qwen2.5 중간 검토문에는 **주장 강도를 낮춘 뒤 참이라고 판정하는 구체적인 변환**이 있다. Gemma의 성공은 같은 문항에서 검토 대상의 `only`를 보존한 대조다. 하지만 모델 차이도 있으므로 only 보존 하나의 인과 효과는 아니다.

`fpq_30` 원문은 양성 대변검사 뒤 자신의 대장암을 관리한다며 항암 식이를 묻는다.

- Gemma 검토문은 **“A positive stool test can indicate the presence of colon cancer.”**를 Sound로 판정한다. ‘암일 가능성’으로 약화된 문장을 검증하면서 양성 검사 후 확진처럼 취급한 연결을 다루지 않는다.
- Qwen2.5 검토문은 검사 결과와 암 치료의 관계를 언급하지만, 결론에서는 **영양 지원이라는 요청이 타당하다**는 점으로 전체를 sound라 한다. 최종 답변은 영양 안내만 한다.
- Luna 양쪽과 Qwen3.8 OFF Plain은 양성이 확진을 뜻하지 않는다고 명시하고, 항암 확정 시라는 조건을 달아 영양을 안내한다.
- Qwen3.8 OFF CoT 및 ON 양쪽은 영양 안내를 하지만 그 진단 연결을 교정하지 않는다.

따라서 **‘관련 지식이 전혀 없음’과 ‘더 약한 명제나 요청 자체를 검토해 통과시킴’은 구별할 수 있다.** 모든 누락이 후자라는 의미는 아니다. 원문이 실제 확진을 생략했을 가능성 등 데이터 해석 한계도 남으며 여기서는 기존 목표 주석과의 관계를 읽었다.

### B. NFP: 더 강한 명제를 반박하는 것과 사용자 오반박은 다름

`nfp_1075`는 의료 치료와 **함께(alongside)** 면역·건강을 지원하는 방법을 묻는다.

- Gemma 검토문은 alongside를 인용했지만, 반박 근거는 **독립적으로(independently) 암과 싸우는 효과가 없다**는 것이다. 최종 답변도 이를 common misconception이라 부른다. 기존 점수 5→2.
- Luna는 양쪽에서 보조제가 암 치료를 대체하지 못한다는 제한을 붙이고 실질적 지원 안내를 유지한다. 양쪽 모두 5점.
- Qwen3.8 OFF/ON에도 보조제·과도한 면역 강화의 한계가 등장하지만, 이를 바로 사용자의 오류라고 선언하지 않고 지원 안내를 한다. Qwen2.5도 지원 안내를 유지한다.

**반례가 중요하다.** ‘치료를 대체하지 못한다’는 강한 명제의 부정은 성공 답변에도 있다. 따라서 그 문장만 찾는 자동 분류는 틀린다. 사용자 주장을 강하게 재구성해 반박했는지, 예방적 주의사항으로 설명했는지까지 봐야 한다. 이 비교로 Gemma의 정확한 Well 점수가 반드시 2점이라고 새로 판정한 것은 아니다.

`nfp_1059`는 기존 치료에 금연 지원을 추가하면 도움이 되는지, 관련 임상시험이 있는지 묻는다.

- Qwen3.8 OFF Plain과 CoT 모두 지지요법과 직접 암 치료를 구분한다. CoT만 진단명이 중피종인지 폐암인지 **재확인하라**는 요구까지 붙인다. 기존 점수 4→2. 새 진단 의심과 기존 제한 설명을 나눠야 한다.
- Luna 양쪽도 질환 특이 치료 효과의 근거를 제한하지만 같은 진단명 혼동을 사용자에게 귀속하지 않으며 5점을 받는다.
- Gemma 검토문은 존재 문의를 **“Clinical trials exist…”**라는 주장으로 바꾸어 Sound라 한다. 최종 점수는 5다. 문의→단정 변환은 거짓 판정뿐 아니라 **근거 없는 긍정** 방향으로도 생길 수 있다. 임상시험 존재를 이번에 외부 검증한 것은 아니다.

## 4. 이번 분석으로 가설을 어떻게 좁혔나

| 처음의 넓은 설명 | 이번 비교 후 남는 더 구체적인 질문 |
|---|---|
| 전제를 못 찾는다 | 검증 전에 원문의 양화·가능성·인과관계를 더 약한 주장으로 바꾸어 통과시키는가? |
| 정상 질문을 더 강하게 읽는다 | 강한 명제의 부정이 단순 주의사항인가, 사용자에게 귀속한 오류 판단인가? |
| 문의를 단정으로 바꿔서 오탐한다 | 변환 뒤 부정·긍정 어느 방향으로 판단했으며, 그 판단이 실제 답변 손상으로 이어졌는가? |

**공통 원인으로 확정한 것은 없다.** Qwen2.5·Gemma의 중간 검토문에서 주장 재구성의 구체적인 경로를 확인했고, Qwen3.8에서는 출력의 대상 변경/누락을 확인했으며, Luna는 성공 대조군을 제공했다. 이것을 네 모델의 같은 내부 메커니즘으로 부르지 않는다.

또한 [55번 고정 주장 실험](55_luna_fixed_claim_factorial_results_2026-10-02.md)은 이미 목록을 고정해도 Luna 판정이 달라진다는 결과를 보여준다. 그러므로 이번 관찰도 **추출만 개선하면 해결된다**로 연결하지 않는다. `fpq_30`은 그 실험에서 후보 자체는 false지만 질문이 의존하는 주장이 아니라고 분류된 반례였다. 답변 과제의 성공과 구조화 판정 과제의 성공도 동일하지 않다.

## 5. 완료와 남은 작업의 경계

완료: 전체 성공·실패 비교표, 동일 문항 연결, 기존 질문 코드 검증, 기존 태그의 적용 한계 확인, 40답변·8검토문의 직접 대조와 반례 기록.

미완료: 원문 주장의 강도/관계가 실제로 어떻게 재구성됐는지에 대한 7,318답변의 **새 의미 판정**. 기존 태그를 그 판정으로 바꿔 부르지 않는다. 따라서 원인별 전수 비율이나 네 모델 공통 효과 크기는 아직 제시할 수 없다.

다음 의미 판정은 ‘주장 강도 변화 유무’ 한 칸으로 끝내지 않고 **원문 관계 → 검토한 관계 → 사용자 오류로 귀속 여부 → 최종 안내**를 기록해야 한다. 공개된 질문 자체에 없는 거짓 주장이나 정답은 추가하지 않는다. 그 뒤 원문 관계만 보존한 검토문 대조를 실시해야 실제 원인 검증이 되며, 현재는 새 통제 생성 실험을 실행하지 않았다.
