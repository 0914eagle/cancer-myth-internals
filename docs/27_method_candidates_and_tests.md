# 27. 새 방법론 후보: 어떤 실패를 겨냥하고 무엇을 검증할 것인가

작성: 2026-09-15. 실측·중단·변경 이력은 [26](26_experiment_history_and_decisions.md). 이 문서는 대화에서 나온 후보를 정리한 **설계 기록**이다. 아래 추천 우선순위는 전체 후보 실행 승인이나 실험 완료를 뜻하지 않는다. 현재 baseline을 계속 돌리며, 이후 준비된 독립 실험을 GPU 0·1로 병렬 처리한다.

## 1. 공통 목적과 지금까지 배운 것

목표: 거짓 전제 의료 질문에서는 정확하게 교정하고, 정상 질문에서 부당한 반박을 줄이며, 일반 의료 QA 성능을 유지한다.

현재 실측으로는 이 목표를 달성했다고 주장할 수 없다. 다만 다음 설계를 고를 근거는 있다.

| 관측 | 설계로 이어지는 질문 | 단정하지 않는 것 |
|---|---|---|
| Gemma FP PCR 59.0, NFP v2 60; CoT 34.2/100 | 같은 개입 대상을 골랐을 때 교정 도구 자체가 얼마나 중요한가? | 혼합 지표로 CoT의 안전성이나 최종 우위 입증 |
| Qwen text .756, hidden .638, DiM .731 | 내부의 어떤 정보가 텍스트 이상으로 필요한가? | 텍스트가 높은 이유가 전부 문체라는 설명 |
| 기존 C Quick45 구제 0/26, 피해 1 | 대조쌍·추출·개입 중 무엇이 부족했는가? | C가 순수 문체이거나 steering 전체가 실패 |
| Overnight ΔS 상승과 참조 양쪽 logp 하락, 높은 cap | 확률 proxy와 생성 정확성을 분리할 필요 | ΔS가 실제 교정의 지표라는 가정 |
| 자기 모델 C에 새 성공 판정이 없음 | 지시 차이 대신 확인된 행동 차이가 필요한가? | 모든 지시 답변이 교정 성공 |
| CoT +1 40개 중 18개 귀속 검토 대상 | 환자가 실제로 전제한 것과 모델의 반박 대상을 구분해야 하는가? | 데이터 45%가 잘못됐다는 추정 |

후보들은 “게이트→head→뉴런→다중 방향”이라는 일방향 발전 단계가 아니다. 선택 신호, 개입 목표, 개입 위치, 추론 비용은 별개의 설계 축이다.

## 2. 전체 후보 지도

표의 상태는 이 대화/저장소에서 확인된 범위다. `후보`는 원문 선행의 존재와 별개로 우리 의료 조건에서 미실행이다.

### 2.1 선택: 어떤 질문에서 무엇을 할 것인가

| ID | 후보 | 입력/학습 목표 | 상태·의존성 |
|---|---|---|---|
| S0 | 텍스트 TF-IDF classifier | 질문 → FPQ/NFP | Gemma/Qwen 시험, 반드시 비교할 baseline |
| S1 | hidden logistic probe | prefill block 출력 → FPQ/NFP | 시험, 우위 미확인 |
| S2 | DiM 탐지 | FPQ 평균−정상 평균 투영 | 시험, steering C와 구분 |
| S3 | 층/위치/풀링·text+hidden | 마지막 토큰 외 구간·전체·결합 | 일부 층 시험, 나머지 후보; 단순 탐색 자체를 신규성으로 삼지 않음 |
| S4 | 직접 질문·전제 검토·출력 readout | 질문/생성된 검토문 → FP 판정 | 일부 suite 구현, 모든 output baseline이 실행된 것은 아님 |
| S5 | 독립 명제의 내부 진위 | 추출한 전제의 hidden state → 진위 | 후보. 귀속/추출 오류를 분리해야 함 |
| S6 | 개입 효과 예측 (기존 후보 ②) | 질문 → 특정 개입의 rescue/harm/순이득 | 후보. fit에서 개입 전후 평가 필요 |
| S7 | 전제 귀속 선택 (기존 후보 ③) | 질문이 반박 대상 주장을 실제로 함의하는가 | 후보. 조건부·개별 상황·보편화 구분 주석 필요 |
| S8 | 지식/교정 가능성에 따른 강도 (A) | 질문에서 예측한 가능성 → 강도 | S6의 확장 후보. 가능성과 최적 강도의 관계 미검증 |

명시적 전제 추출·검토 CoT·별도 LLM monitor는 내부 신호를 비교하기 위한 유력 baseline이다. 생성한 CoT를 읽는 방법과 CoT로 최종 답변하는 방법은 같지 않다. 응답을 다 읽고 얻은 신호를 질문 단계 게이트에 사용하면 미래 정보 누출이다.

## 3. 주력 가설: 학습된 C와 틀린 반박/정상 보존

### 왜 이 후보가 나왔나

외부 참조 C에는 다른 저자의 답변 차이가 남고, 자기 모델 지시 C에는 성공 선별이 없었다. 다음 비교는 이를 합쳐 **같은 질문·같은 모델·확인된 행동**으로 대조쌍을 만드는 것이다. 평균 차를 낸다는 연산 자체는 교정의 인과적 효과를 보장하지 않는다.

검증할 가설:

> 교정 성공과 실패만 구분하는 개입은 틀린 반박이나 정상 질문의 부당한 반박도 늘릴 수 있다. 정확 교정·틀린 반박을 구분하고 정상 답변 보존을 함께 학습하면 같은 교정 수준에서 피해가 줄어드는가?

아직 “2-class는 반박 어조를 학습한다”는 실측은 없다. 새 손실을 제안하기 전에 fit 자료에서 해당 실패가 충분히 존재하는지 확인한다. 성공 40개 감사의 재검토 3개를 곧바로 틀린 반박 학습 라벨로 쓰지 않는다.

### 자료와 비교 설계

1. fit 답변에서 전제 수용/불완전 교정/정확 교정/틀린 반박/귀속 보류를 구분한다. 방법 이름으로 라벨을 대신하지 않는다.
2. 같은 질문의 실패−정확 교정 쌍 수, 틀린 반박 수, 정상 질문의 적절한 답변·과교정 수를 집계한다. 보류와 제외 이유도 기록한다.
3. 같은 추출·적용 위치에서 평균 차 C와 학습 C를 비교한다.
4. 틀린 반박 억제와 정상 보존을 각각 추가해 효과를 분리한다. 추가 자료량/업데이트 수 차이를 맞춘 대조를 포함한다.
5. 층·강도·학습 설정은 train/개발 범위에서 정하고 평가 문항에는 고정한다. 오래 본 dev는 탐색으로 남긴다.

| 행 | 답하는 질문 |
|---|---|
| 확인된 쌍의 평균 차 C | 자료 선별만 바꾸면 충분한가? |
| 같은 쌍의 학습 C | 직접 출력 학습의 효과가 있는가? |
| 학습 C + 틀린 반박 억제 | 잘못된 반박을 구분할 필요가 있는가? |
| 학습 C + 정상 보존 | 정상 질문에서 개입을 억제하는 효과가 있는가? |
| 두 항 모두 | 개별 항의 조합이 도움이 되는가? |

이 표는 독립 요인 비교안이다. 자료가 부족하면 행을 줄인다. 반드시 모든 후보를 실행하거나 새 손실을 새 알고리즘으로 선언하는 것은 아니다. 초기에는 같은 gate를 고정하거나 무조건 적용해 개입 효과부터 분리하고, 이후 배포 가능한 gate와 결합한다.

### 가까운 선행과 신규성 범위

- [BiPO](https://arxiv.org/abs/2406.00045): 선호 최적화로 steering 벡터를 학습한다. “C를 학습한다”는 발상은 선행이다.
- [ReFT/LoReFT](https://arxiv.org/abs/2404.03592): 동결 모델의 표상 개입을 학습한다. 저차원 부분공간을 쓰는 것 자체도 선행이다.
- [MAT-Steer](https://arxiv.org/abs/2502.12446): 바람직한 표상으로의 정렬, 희소성과 방향 간 직교성으로 다중 속성 개입을 구성한다.
- [Towards Steering without Sacrifice](https://arxiv.org/abs/2605.05983): 방향·강도의 공동 학습과 소수 prompt 토큰 개입이 핵심이다. 제목만 보고 단순 보존 KL 방법이라고 인용하지 않는다.
- [Steer Like the LLM](https://arxiv.org/html/2605.03907v1): 프롬프트 모방 steering의 가까운 선행. 이번 정리에서는 제목·서지 이상의 세부 손실 비교를 완료했다고 쓰지 않는다.

차별화는 확인된 실패, 그 실패를 겨냥한 자료·목적식, 공정한 구성요소 비교에서 나와야 한다. 작은 표본에서 과적합 위험은 있지만 “차원 3,584이므로 반드시 과적합”은 아니다. cross-fitting은 평가 분리이며 정규화의 대체재가 아니다. 학습하는 저랭크 기저는 벡터 하나보다 파라미터가 많을 수도 있다. 고정 기저의 소수 계수를 학습하는 것과 구분한다. 구현 소요를 “한 주/한 달”로 보장하지 않는다.

## 4. 별도 기전 후보: 최소 쌍의 부호 보존 증폭

### 제안과 정확히 보장되는 것

학습용 최소 쌍에서 `Δ_i=h(q_false_i)−h(q_true_i)`를 모아 직교 기저 U와 학습 중심 μ를 추정한다. 제안 연산은:

```text
h' = h + β U Uᵀ (h − μ)
z = Uᵀ(h − μ)
z' = (1 + β) z,  β > 0
```

수학적으로 해당 층에서 기존 부분공간 좌표를 증폭하고 직교 성분을 유지한다. 그러나 다음은 보장되지 않는다.

- 좌표 부호가 실제 전제 진위와 일치함. 오탐/누락 표상도 증폭한다.
- 참 질문의 답변 보존. 참 질문에도 일반적으로 0이 아닌 개입을 한다.
- 같은 선형 점수의 AUROC 향상. 해당 점수는 양의 상수배라 순위가 그대로다.
- 후속 비선형 층·정규화·생성의 의료적 정확성 보존.

따라서 “게이트 없이 거짓 질문에만 개입” 대신 **명시적 문턱 없이 입력 의존적으로 양방향 증폭**한다고 부른다. μ는 여전히 어디를 중심으로 나눌지 정하는 선택이다. 다차원 U에는 단일한 참/거짓 부호가 자동으로 정의되지 않는다. 검증 가설은 “이미 구분된 정보를 후속 답변이 더 잘 활용하는가”다.

### 최소 쌍의 한계와 선행 정정

같은 문항 대조는 주제·문체 교란을 줄일 수 있지만 “진위만 남는다”는 보장은 없다. 부정어, 항상/일부, 인과·임상 사실 내용, 바뀐 사실과 문맥의 상호작용도 달라진다. 원문과 쌍둥이가 동일한 중심의 양쪽에 모든 문항에서 놓인다는 가정도 확인해야 한다.

- [CAA §3](https://arxiv.org/html/2312.06681)는 이미 같은 질문에 다른 답변 선택지를 붙인 대조쌍을 사용한다. 기존 CAA/c_pair를 전부 비짝지은 집단 비교로 설명하지 않는다.
- [One Concept at a Time, 저자 공개 원고](https://gsood.com/research/papers/steer.pdf), §4–5는 최소 반사실 쌍으로 부분공간을 추정하고 `S(h)=h+UBUᵀ(h−μ)`를 제안한다. **B=βI가 위 연산이다.** 의료 전제 효과의 실증과 동일한 연구는 아니지만 수식·추정 방식 자체의 신규성 주장은 어렵다. 이 링크는 저자 공개 원고이며 peer-reviewed 의료 결과로 소개하지 않는다.
- [Conceptors for Semantic Steering](https://arxiv.org/html/2605.04980v1)는 양극을 함께 반영한 부분공간과 한쪽으로 미는 벡터를 비교한다. 양극을 쓴다는 발상 자체가 처음은 아니다.
- [FalseQA](https://arxiv.org/abs/2307.02394)는 거짓 전제 질문과 수정한 참 전제 질문을 제공한다. 의료 쌍의 가치는 별도로 검증하되 쌍둥이라는 자료 형태가 우리만의 것이라고 하지 않는다.

### 처음 할 수 있는 제한된 실험

검증된 원문·참 수정·진위 유지 의역을 준비하고 같은 원문에서 파생된 모든 버전을 같은 split에 둔다. 원문 dev로 U를 만들고 그 쌍둥이를 test로 부르면 누출이다. U/rank/μ/층/β는 학습·개발 자료에서만 정한다. 구현 시 차이벡터를 평균 중심화하는 PCA는 공통 평균 차를 제거할 수 있으므로 uncentered SVD/평균 차 포함 여부를 명시한다.

| 비교 | 분리하는 요인 |
|---|---|
| Plain·CoT | 기존 출력 기준 |
| 같은 쌍의 고정 방향 더하기 | 자료를 바꾼 효과 |
| 같은 쌍의 부호 보존 증폭 | 연산을 바꾼 효과 |
| 같은 rank·개입 크기의 무작위 부분공간 | 해당 부분공간이 필요한가? |
| 의역 대조 | 진위와 표현 변경의 구분 |

FPQ의 **정확 교정**, 참 쌍둥이·기존 NFP의 **부당한 반박**, 출력 cap/퇴화를 함께 본다. 18개는 구현·퇴화 확인용이며 유의한 우열이나 보존 보장의 표본이 아니다. 실패하면 층/강도/중심/자료 문제도 가능하므로 “축이 반박이었다”를 확정하지 않는다. 성공해도 과거 trade-off 원인이 집단 대조였다는 단일 원인 설명은 별도 통제가 필요하다.

## 5. 대조 디코딩·재순위: 의미와 비용을 먼저 정한다

### Plain/FP 분포 보간 (B)

단순 확률 보간 `p_λ=(1−λ)p_plain+λp_FP`와 contrastive logit 차이 증폭은 다르다. 두 문맥은 매 순간 **동일하게 이미 생성된 답변 prefix**를 조건으로 비교해야 한다. 두 KV cache/forward가 필요하고 저장된 완성 답변만으로 할 수 없다. λ=1에서 직접 FP_CORRECT 조건과 기존 Yes/No 포함 FP Identification 전체 파이프라인이 동일한지도 구분한다. [Context-aware Decoding](https://aclanthology.org/2024.naacl-short.69/).

### 전제 중립화/참 수정 대조 (T4)

`d=z_original−z_neutral`에서 차이를 억제하려면 예컨대 `z'=z_original−αd`처럼 부호를 명시해야 한다. 차이를 그대로 사용하는 것과 그 차이를 억제하는 것은 다르다. 참 질문도 유용한 전제 정보를 없애면 분포가 크게 바뀐다.

참으로 수정한 쌍둥이는 중립 질문이 아니다. 추론 시 정답 사실을 제공한 **oracle 정보 조건**이며 자동 중립화의 수학적 상한은 아니다. 수정 질문 자체에 답하게 했을 때의 효과와 이중 decoding 효과도 분리해야 한다. 비용은 두 조건의 토큰별 forward뿐 아니라 온라인 중립화/수정의 생성·검증까지 포함한다.

### 내부 검증기 재순위 (G)

N개 서로 다른 답변을 생성해 내부 점수로 고른다. greedy 동일 조건 반복으로 같은 답변 N개를 만들지 않도록 sampling을 명시한다. 기존 D가 현재 모델과 후보 분포에서 유효한지 먼저 확인한다. 학습 없는 방법이라고 자동으로 부르지 않는다.

[FPCG](https://arxiv.org/abs/2606.11172)는 중간 추론에서 미래 행동을 예측하는 probe와 문장 후보 선택을 사용한다. 완성 답변을 판별하는 probe를 그대로 prefill gate로 옮기는 근거가 아니다. 재순위가 실패하면 후보 안에 정답이 없었는지, 있었는데 선택을 못 했는지 나눠 본다.

N=8 재순위에 못 이긴다고 steering의 이유가 사라지는 것은 아니다. 한 번 생성하는 방법과 비용·지연·정상 피해를 함께 비교한다. “G/B를 반드시 먼저 돌려야 한다”, “비용 없이 된다”는 제안은 채택하지 않는다.

## 6. 독립 명제·효과 예측·attention 후보의 조건

**독립 명제 probe(S5).** 질문에서 꺼낸 전제가 환자의 실제 주장인지 확인하고 그 명제의 내부 진위를 읽는다. 정답 전제 주석을 추론 입력에 주는 oracle와 모델 추출을 구분한다. [Contextual-Truth](https://arxiv.org/abs/2608.03035)는 관찰만 한 것이 아니라 steering 인과 실험도 있으며, 문맥 증거에 의한 진위는 의학 배경 지식의 진위와 다르다. 그 논문과 Two Axes를 조합했다고 새 게이트의 우위가 입증되는 것은 아니다.

**효과 예측(S6/S8).** 같은 fit 질문에서 Plain과 특정 개입을 비교해 rescue/harm을 정의한다. 거짓 전제 여부, Plain 성공, 개입 성공, 순이득은 다른 라벨이다. E1 D .82–.88을 개입 효용 성능으로 재사용하지 않는다. 기존 구제 AUROC .65도 상한이 아니다. text classifier도 같은 효용 라벨로 학습해 공정하게 비교한다. “고칠 수 있다”는 점수에 강도를 비례시키는 규칙은 별도 가설이며 확인된 단조관계가 아니다. [HACK](https://arxiv.org/abs/2510.24222)는 관련 지식/확실성 조건을 검토할 선행이며 우리 효용 라벨의 검증을 대신하지 않는다.

**전제 attention(F).** [PASTA](https://arxiv.org/abs/2311.02262)는 강조한 입력 구간으로 attention을 조절하는 가까운 선행이다. 전제를 더 보게 하면 검토도 강화될 수 있지만 거짓 정보를 더 따를 수도 있다. 구간 probe가 더 잘 읽힌다는 사실만으로 attention 부족이라는 기전을 주장하지 않는다. 시험한다면 증가/감소, 길이 맞춘 무작위 구간, gold 구간과 자동 구간을 분리한다.

## 7. 우선순위와 병렬 계획

| 우선순위 | 작업 | 시작 조건 | 결과로 정할 것 |
|---|---|---|---|
| 계속 진행 | Qwen baseline·같은 평가·출력 길이 확인 | 현재 run | 실제 남는 실패 유형 |
| 주력 후보 | C2→C4→C5/C6 | fit의 확인된 행동 쌍 | 자료 선별만으로 충분한가, 학습/보존 항이 필요한가 |
| 독립 소규모 후보 | T1/T2 최소 쌍 증폭 | 검증된 쌍·통제·분할 | 고정 추가와 다른 이득이 있는가 |
| 선택 후보 | S6 효과 예측 | 개입 전후 fit 평가 | 진위 탐지와 다른 선택 목표의 가치 |
| 보류 | G/B/F/head/SAE/M 전체 확장 | 해당 실패·자료·예산 근거 | 복잡도 증가가 필요한가 |

GPU 0의 현재 생성과 GPU 1의 준비된 자료 추출/소규모 생성은 병렬 가능하다. CPU probe와 예산이 고정된 Terra 판정도 병행할 수 있다. 그러나 라벨 전 C 학습, 쌍둥이 생성 전 T2는 순서를 건너뛸 수 없다. 다음 스크립트는 GPU별 worker·로그·출력 디렉터리·의존 작업·재개를 분리하는 것이 기본이다. 이 문서에서 새 실험을 시작하지 않았다.

## 8. 교수님께 설명할 현재 문장과 기여 조건

현재 설명:

> baseline에서 교정 지시의 효과와 정상 질문 피해가 관측됐지만, 판정기와 출력 길이의 영향을 먼저 분리해야 했습니다. 질문 probe의 우위와 기존 C의 교정 효과는 아직 확인하지 못했습니다. 이제 같은 모델·같은 질문의 확인된 행동 쌍으로 개입을 구성하고, 정확 교정과 틀린 반박·정상 보존을 분리한 학습이 필요한지 비교하려 합니다. 별도로 최소 쌍 부분공간을 양방향 증폭하는 작은 기전 실험을 검토하고 있습니다.

실험이 지지할 때만 가능한 기여:

1. **진단:** 기존 선택/개입의 어떤 실패가 자료·평가 문제를 통제한 뒤에도 남는지 밝힌다.
2. **설계:** 그 실패를 겨냥한 구체적 자료·학습·개입 규칙을 제안하고 동일 조건의 ablation으로 필요성을 보인다.
3. **효용:** 정확 교정과 정상 질문 보존을 함께 평가하고, 독립 평가·일반 의료 QA·전이에서 효과의 범위와 한계를 보고한다.

아직 새 알고리즘 최초 주장, “게이트 없이 보존 보장”, “실패해도 곧바로 기하학 원인 논문”은 할 수 없다. 참 전제 쌍둥이·다중 클래스·학습 벡터·부분공간 중 어느 단어 하나가 기여를 보장하지 않는다. 현재 baseline의 목적은 선행표를 채우는 일과 함께 **해결할 실패를 특정하는 일**이다.
