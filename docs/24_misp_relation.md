# 24. MISP-Bench와 우리 연구의 관계

2026-09-10. 최신 v2(2026-08-23)의 공개 본문·초록과 공식 데이터/코드를 확인한 논의 기록이다.
MISP 도입은 후보이며 현재 실행은 [23의 Gemma 파일럿](23_gemma_steering_pilot.md)이 우선이다.

## 무엇을 분해하는 논문인가

MISP-Bench: Decomposing User-Provided False Priors into Answer, Rationale, and Guard Effects는
같은 질문과 정답을 유지하면서 사용자가 제공하는 오답과 잘못된 근거를 나누어 투입한다.
Answer는 사용자의 오답 주장, rationale은 사용자가 제공한 설명, guard는 검증 등의 방어 지시다.
따라서 rationale은 모델 자신의 CoT가 아니고 guard는 내부 classifier/gate가 아니다.
모델의 CoT/direct 모드는 별도로 비교한다. 정답이 B인 문제에 “A라고 생각한다”, 오답 근거,
둘의 조합을 넣고 검증 지시를 추가하는 식이다.
[v2 본문 §3–5](https://www.medrxiv.org/content/10.64898/2026.05.07.26352627v2.full).

## 우리 주장에 제공하는 근거와 한계

v2는 감사 후 1,724문항(의료 객관식 1,430, 수학 294), 공개 모델 10개를 보고한다.
추론을 먼저 검증하라는 guard는 모델마다 효과가 달랐고 4/10에서는 악화됐다.
이는 검증 프롬프트만으로 일관된 보호를 기대하기 어렵다는 근거다.
모든 CoT의 실패나 내부 방법의 우월성을 입증한 결과로 쓰지 않는다.
[v2 초록](https://www.medrxiv.org/content/10.64898/2026.05.07.26352627v2).

| 구분 | MISP | 우리 계획 |
|---|---|---|
| 입력 문제 | 원 문제에 명시적인 오답·근거를 덧붙임 | 환자 질문 자체에 거짓 전제가 깔림 |
| 연구 질문 | 어떤 입력 요소가 오류를 만들고 guard가 회복시키는가 | 무엇을 선택해 어떻게 정확히 교정할 것인가 |
| 평가 | 최종 답 정확도, 오답 채택, 손실·회복 | 전제 교정 PCR/PCS, NFP 및 의료 QA 보존 |
| 방법론 관계 | 입력 조건 분해·프롬프트 방어 평가 | 선택 신호 및 교정 개입 설계·비교 |

오답을 따르지 않는 것과 배경화된 거짓 전제를 찾아 설명하며 고치는 것은 동일하지 않다.
MISP의 정확도를 Cancer-Myth PCR로 바꾸어 표기하거나 출판값과 우리 결과를 동일 평가로 합치지 않는다.
MISP가 우리 방법의 novelty를 보장하지도 않는다. 기존 gated steering의 구체적인 한계를
어떤 설계로 해결하는지는 별도 비교 결과가 필요하다.

## 후속 실험으로 가져오는 방법 — 아직 미구현

Cancer-Myth에서 설정을 고정한 뒤 MISP 의료 문항에 적용하면 입력 형식 전이를 평가할 수 있다.
오답 주장만/잘못된 근거만/둘 모두에서 정확도와 사용자 오답 채택률을 비교한다.
원 질문과 올바른 근거 조건도 같이 두어 단순한 사용자 무시·반박으로 개선된 것인지 확인한다.
이때는 오정보에 대한 견고성 평가이며 일반 의료 QA 성능 보존과 구분한다.
MISP로 다시 학습·문턱 조정하면 고정 전이라고 부르지 않는다.

공개 자료를 가져올 수 있지만 raw 2,494문항과 감사 후 1,724문항을 구분해야 한다.
원 데이터에는 14 prompt level이 있고 논문 본 평가의 13조건과 일치 여부를 확인해야 한다.
논문 수치에 행을 붙일 때 모델·감사 필터·프롬프트·CoT/direct·생성 및 반복 집계를 맞춘다.
[공식 데이터 카드](https://huggingface.co/datasets/yh0502/misp-bench/blob/main/README.md),
[공식 코드](https://github.com/anon-misp-2026/misp-bench).

현재 장기 Table 3 후보인 Cancer-Myth→CREPE를 이 문서로 대체하지 않는다.
MISP는 외부 평가의 추가 후보이며, 먼저 Gemma 한 모델의 Cancer-Myth baseline과 기본 C 방향의
실제 효과를 확인한 뒤 채택 여부를 결정한다.

## 교수님께 설명할 문장

“MISP-Bench는 의료 질문에 잘못된 답이나 근거가 주어지면 모델이 영향을 받으며,
이를 검증하라는 프롬프트의 효과도 모델마다 다름을 보였습니다. 우리는 거짓 전제가
포함된 질문을 선택해 개입함으로써 정확한 교정을 높이고 정상 질문의 성능을 보존할 수
있는지 연구하려 합니다. 현재는 Gemma 한 모델에서 baseline과 기본 steering부터 확인합니다.”
