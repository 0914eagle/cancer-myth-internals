# FPQ 라벨 재검토 후보 선별: 질문만 보는 검사 (2026-10-13)

**앞선 732문항 검사는 주석 필드 간 정합성 검사였으며, FPQ/NFP 라벨 자체의 검증은 아니었다. 이번에는 질문만 보고 개인 상황·의사 판단을 전한 사례와 별도의 사실 주장을 하는 사례를 구분했다.**

의사·전문의 관련 단어가 있는 FPQ 79개를 질문·교정 설명과 직접 대조했을 때, **15개는 라벨 재검토 우선 후보**로 분류했다. 이것은 임상적으로 정상이라고 확정한 15개 또는 전체 데이터 오류율의 추정치가 아니다.

## 검사 방법

1. 원장 732개(FPQ 583 / NFP 149)를 사용했다. 현재 실행 bundle 724개만 본 것이 아니다.
2. 기존 FPQ/NFP 라벨, ID 접두사, source_myth, 교정 설명을 모두 가리고 무작위 순서(seed 20261013)의 질문만 GPT-6 Sol에 주었다. 원 ID 대신 `item_0000` 등의 불투명 ID를 사용했다.
3. 판단 범위는 문장에 있는 전제와 추론이다. 의학적 진위나 환자의 실제 치료 적합성은 판정하지 않았다.
4. 고정 지시문으로 40개씩, 동시 2개 요청, 공통 GPT 4슬롯을 공유했다. 모든 결과는 ID 일치·중복 없음·근거 구절의 원문 일치를 검사했다.
5. 별도로 FPQ 질문에서 doctor/oncologist/physician/surgeon/neurologist/dermatologist/urologist/pediatrician이 등장하는 79개를 주 에이전트가 질문과 reference 전문으로 대조했다. 이 명단은 단어 일치로 정했으므로 모든 의사 보고를 포괄하지 않으며, 단순히 전문의 검색을 묻는 질문도 포함한다.
6. 직접 검토는 Codex 주 에이전트의 언어적 대조다. 독립적인 사람/임상 전문가 평가가 아니다. 앞선 검사와 이번 블라인드 검사는 모두 같은 GPT-6 Sol 모델을 요청했으므로 서로 독립된 평가자 합의로 해석하지 않는다.

FPQ 중 앞의 두 범주 합계 **153개**는 라벨 재검토의 넓은 후보군이다. **153개가 잘못된 FPQ라고 확정하지 않았다.** 참·거짓에 대한 임상 검증이 없고, 암묵적인 전제를 모델이 놓쳤을 수도 있다. 정상 NFP에도 참인 사실 주장이 들어갈 수 있으므로 이 표로 탐지 정확도나 오류율을 계산하지 않는다.

## 해석과 후속 범위

- 이 결과는 ‘주석 문장을 원본에서 잘못 가져옴’이 아니라 ‘질문을 FPQ로 부를 근거가 원문에 충분한가’에 대한 선별이다. 원본 대조 결과는 이전 문서의 0/732 내용 변경과 양립한다.
- 의사의 개인 판단을 사용자가 그대로 전한 질문과 일반적으로 틀린 의학 주장을 의사의 말로 전한 질문은 구분해야 한다. 의료 지식으로 확인되지 않은 개인 보고를 무조건 참으로 고정하는 규칙을 제안하는 것이 아니다.
- 현 단계에서 기존 라벨·문항·점수는 모두 유지했다. 원본 benchmark 성능과 사후 감사 결과를 섞어 새로운 주 결과로 바꾸지 않는다.
- 이번 분류만으로 FPQ–NFP trade-off가 라벨 문제 때문에 발생했다고 결론 내릴 수 없다. 우선 후보의 독립적인 라벨 검토와 동일 답변에 대한 채점 민감도 검사가 필요하다.
- A6000의 기존 46개 명단을 확보하지 못했으므로 그 명단의 재현 결과가 아니다.
