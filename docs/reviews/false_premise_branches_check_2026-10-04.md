# 다섯 방향 정리에 대한 점검 (2026-10-04, 같은 날 수정)

대상: [원인·해결책 다섯 방향](false_premise_cause_and_method_branches_2026-10-04.md), [상세 문헌 정리](false_premise_literature_synthesis_2026-10-03.md).
비교 기준: [62 통합 실패 집계](../62_integrated_failure_census_2026-10-02.md), [31 지식 측정](../31_knowledge_vs_deference.md), [34 §9–10](../34_where_the_signal_lives.md).
새 모델 실행 없음.

**수정 기록.** 첫 판은 관찰을 원인으로 바꿔 적었다. "FPQ와 NFP는 원인이 다르다", "K3로 안다/모른다가 갈린다",
"NFP 개인 상황을 단독 True/False로 판정한다", "제외 58개를 지식 결손 규모에 포함"을 아래처럼 고쳤다.
연결 결과를 곧바로 원인 라벨로 바꾸지 않는 것이 이 문서의 원칙이다.

## 1. 받아들인 지적

- **번호 체계 충돌.** 다섯 방향 문서와 62번이 모두 ①–⑤를 쓰고 뜻이 다르다. 행동 분류와 원인 가설은 번호가 아니라 **이름**으로 연결한다.
- **지식 부족을 갈래로 남긴다.** 지식 *사용* 실패만으로 정리하지 않는다. 다만 지금 데이터로 그 크기를 잴 수는 없다(§3).
- **모델마다 실패 구성이 다르다.** "목표 오류 수용"은 Qwen2.5 231/568, Gemma 175/558, Luna 20/322다. Qwen에서 찾은 내부 원인을 Luna에 옮기지 않는다.
- **기존 학습 데이터 점검.** 새 SFT/DPO 전에 선호 답변 자체에 불필요한 반박이 섞였는지 본다(§4-3).

## 2. 관찰과 가설의 경계

62번이 보인 것은 **실패하는 모습**이다.

- FPQ 저점에서는 목표 오류 미언급, 수용, 관련 설명만인 답변이 많다.
- NFP의 **새로 떨어진 부분집합**에서는 범위·상황을 바꿔 반박하는 사례가 반복된다.

목표 오류를 언급하지 않았다고 전제를 검토하지 않았다는 뜻은 아니다. 검토했지만 사실 판단을 틀렸거나, 교정할 필요가 없다고 봤을 수도 있다.
따라서 "FPQ에서는 검토를 안 하고 NFP에서는 주장을 부풀려서 trade-off가 생긴다"는 **검증할 가설**이다.
서로 다른 실패 모습이 **같은 응답 경향**(예: 반박 성향 하나가 오르내림)에서 나왔을 가능성도 남아 있다.

Luna 균형 지시의 정확한 수치:

| Luna NFP | 쌍 수 |
|---|---|
| Well<4 답변, Plain → 균형 지시 | 16 → 66 |
| 새로 4 미만으로 내려감 | 54 |
| 4 이상으로 올라감 | 4 |
| 새 하락 54 중 넓은 범위·상황 변경 | 24 |
| 그중 개인 → 일반 | 14 |

66개 전체가 확인된 부당한 반박은 아니다(62 §4, §7).

## 3. K3 교차 집계의 이름

K3는 통념과 교정문을 **함께 보여 주고** 정확한 쪽을 고르는 과제다. 정답 정보가 선택지에 있다.

| K3 결과 | Plain 답변 | 말할 수 있는 것 |
|---|---|---|
| 두 순서 모두 교정문 선택 (476) | 교정 실패 | 선택지가 있으면 구별하지만 원 질문에서는 교정하지 못함 |
| 불안정·오답 (unsure 44, no 5) | 교정 실패 | 이 선택 과제에서도 안정적으로 구별하지 못함 |
| 검사 제외 (58, 주석 형식 필터) | 교정 실패 | 지식 관련 결과 없음 |

첫 행을 "알면서 안 씀", 둘째 행을 "모름"으로 부르지 않는다. 58개는 지식 결손 규모에 넣지 않는다. 31 §8의 판독 문단도 같은 기준으로 고쳤다.

## 4. 분석 질문과 실행 순서

> **선택지가 있을 때 사실을 구별하는 능력과 실제 교정 행동은 어떻게 연결되는가? 그리고 모델이 원문과 다른 주장을 반박하는
> 현상은 성공적인 교정에서도 나타나는가, 실패에서 더 두드러지는가?**

두 질문의 결과는 원인 확정이 아니라 **다음 개입에서 무엇을 바꿀지 좁히는 근거**다. 빈도가 같거나 달라도 같은 내부 원인이나
별개 원인이 확정되지는 않는다.

### 4-1. K3 × Qwen2.5 답변 행동 교차 (먼저, 새 호출 없음)

목적은 안다/모른다 확정이 아니라, 선택 과제의 결과에 따라 실제 실패 모습(미언급·수용·관련 설명만)의 **분포가 달라지는지** 보는 것이다.
다르지 않은 것도 결과다. 스크립트는 `scripts/k3_behavior_crosstab.py`이고 출력 집단명은 §3 표를 그대로 쓴다.
원장 id와 labels id가 절반 이상 맞지 않으면 멈춘다.

```
python scripts/k3_behavior_crosstab.py --labels $SUITE_DIR/knowledge/qwen25_7b/labels.jsonl \
    --out docs/reviews/k3_behavior_crosstab_2026-10-04
```

### 4-2. 의미 관계 판정의 기준

**비교 대상은 모델이 반박 대상으로 삼은 주장과 원래 질문의 관계다.** 모델이 새로 제시한 교정문이 질문에서 따라 나오는지가 아니다.
예: 질문 "수술만이 유일한 치료라고 생각합니다", 답변 "수술 외의 치료도 있습니다". 검사할 것은 "수술만이 유일하다"가 질문에 있는가다.

암묵적 전제가 있으므로 논리적 함의 Yes/No 대신 네 범주로 판정한다.

| 범주 | 뜻 |
|---|---|
| 원문에 명시 | 반박 대상이 질문에 그대로 적혀 있음 |
| 문맥상 전제 | 적혀 있지 않지만 질문이 그것을 전제한다고 볼 근거가 있음 |
| 강해지거나 달라짐 | 원문보다 범위·필연성·유일성이 강해졌거나 인물·시점·관계가 바뀜 |
| 모호 | 위 셋 중 하나로 정할 수 없음 |

그 일반 의학 주장이 사실인지는 별도 판정이다. 개인 상황은 사실 퀴즈로 바꾸지 않는다.

**기존 자동 코드는 그대로 쓸 수 없다.** 62번 원장의 `grounding` 열(explicit/implied/strengthened_or_shifted/absent)은 모양이 같지만,
직접 독해로 범위 변경이라 판정한 57건 중 52건을 explicit 또는 implied로, 2건만 strengthened_or_shifted로 분류했다.
새 판정은 이 57건으로 먼저 맞춘다. 57건 대부분을 "강해지거나 달라짐"으로 잡지 못하면 본 판정에 쓰지 않는다.

### 4-3. 같은 모델·조건 안의 네 집단

FPQ 성공과 NFP 실패만 비교하면 라벨과 성공 여부가 동시에 달라진다. 같은 모델·프롬프트 조건 안에서 네 집단을 같은 기준으로 판정한다.

| | 답변 성공 (Well≥4) | 답변 실패 (Well<4) |
|---|---|---|
| **FPQ** | 필요한 교정에서 무엇을 반박했나 | 놓치거나 잘못 반박한 대상은 무엇인가 |
| **NFP** | 부연 설명을 하면서도 의미를 보존했나 | 원문과 다른 주장을 반박했나 |

여기에 LoRA 학습의 chosen 답변(무조건 교정 출력, Well ≥4)을 다섯째 집합으로 더한다. 학습 데이터가 필요한 교정과 불필요한 반박을
실제로 구분했는지 보기 위해서다.

이 대조로 볼 수 있는 것은 **범위 변경이 반박 답변에 흔한 특징인지, 실제 실패와 특별히 연결되는지**다.

### 4-4. 기존 자료의 범위 구분

| 자료 | 지위 |
|---|---|
| 범위·상황 변경 57쌍 | 기존 직접 독해 분류. 4-2 기준으로 판정이 끝난 것이 아니라 **새 기준을 맞추는 출발 자료** |
| NFP 저점 109답변 | 기존 직접 독해 집합 밖의 NFP 저점 |
| FPQ 성공·실패, NFP 성공, chosen 답변 | 새로 추가한 대조 |

109답변만 보면 분석이 끝난다고 쓰지 않는다.

### 4-5. 측정 경계 상시 보고

"교정 코드인데 저점" 589건, NFP 64쌍 감사의 점수 변경 16개(230→217). Cheng 등의 PCR 지표와 Well ≥4도 다르다.
