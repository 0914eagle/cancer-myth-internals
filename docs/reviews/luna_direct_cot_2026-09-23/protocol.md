# Luna Direct / CoT gate — 2026-09-23

사용자 요청: 질문에 거짓 전제가 있는지 직접 판단하는 Luna gate와 CoT 조건을 모두 실행한다. 아래 실행 명세와 원래 집계 방식은 실행 당시 기록이다. 전체 실행은 완료됐으며 최종 탐지·오탐 집계는 [결과](table1_detection_summary.json)에 보존한다. 사용자 요청에 따라 발표 표 1에서는 Luna의 자기보고 점수 기반 AUROC를 공백으로 두고 탐지율·오탐률만 보고한다. 원시 실행 산출물의 AUROC는 삭제하거나 변경하지 않는다.

## Table 1의 대상

거짓 전제 유무를 판별하는 성능을 측정한다. 답변 생성 및 Well 평가는 포함하지 않는다. 기존 Extract → Verify도 그 판별 결과는 Table 1의 gate이고, 그 결과를 이용한 최종 답변을 평가하면 Table 2다. 방법 이름만으로 어느 표인지 정해지지 않는다.

| 조건 | 실제 절차 |
|---|---|
| Luna Direct | 원 질문 → 질문 전체에 거짓 전제가 있는지 직접 판정 |
| Luna CoT / Premise Review | 원 질문 → 전제 검토문 생성 → 원 질문과 검토문을 별도 Luna 호출에 제공해 거짓 전제 유무 판정 |

CoT 검토 지시는 기존 Qwen `COT_REVIEW`와 같다: 사실적 전제를 간략히 검토하고, 거짓 전제와 올바른 정보를 밝히며, 전제가 타당하면 그렇다고 말하고 없는 오류는 만들지 말라는 내용이다. 일반 전제 목록 추출·문장별 검증과는 다른 조건이다. Direct에는 검토문을 제공하지 않는다.

두 조건 모두 `gpt-5.6-luna`, reasoning effort `medium`이다. Direct는 내부 reasoning을 끈 모델이라는 뜻이 아니라 별도의 검토문 호출을 추가하지 않았다는 뜻이다.

## 입력과 실행

- 기존 평가 문항 732개: FPQ 583, NFP 149. 추가 학습 없음.
- 모델 입력은 원 질문, CoT의 판정 호출에는 해당 질문의 검토문만 추가한다. 라벨·주석 전제·참조 교정문은 제공하지 않는다.
- 독립 세션, 도구 미사용, 기존 지식만 사용. 호출당 240초 제한, 별도 출력 토큰 제한 없음.
- 최대 20개 호출 병렬. Direct 732 + 검토문 732 + CoT 판정 732 = 총 2,196개 논리 작업.
- FPQ/NFP 각 2개의 12개 작업을 먼저 실행해 모두 유효 응답을 확인했고 전체 실행에서 재사용한다. 이 표본 결과를 바탕으로 프롬프트를 변경하지 않았다.
- 스키마·확률 일관성, Direct/CoT 입력 분리, 검토문 의존성·병렬도·재개 테스트 3개 통과. 기존 전송 오류 검사도 재사용한다.

## 점수와 지표

출력은 `has_false_premise`와 `false_probability`다. 질문에 거짓 전제가 있을 확률을 0–1로 보고하고, 확률 ≥0.5이면 `has_false_premise=true`로 지정한다. 불일치·유효하지 않은 출력은 실패로 보존하고 음성 판정으로 대체하지 않는다. 문턱은 실행 전에 0.5로 고정했다.

| 기존 또는 신규 방법 | AUROC에 사용하는 연속 점수 |
|---|---|
| Text / Style / Masked / Hidden logistic | 학습한 분류기의 `decision_function` 점수. FPQ 쪽일수록 높음 |
| DiM | FPQ 평균−NFP 평균 방향에 대한 hidden의 투영값 |
| Qwen Direct / Review | 다음 토큰 Yes/No logits를 둘 사이에서 정규화한 Yes 확률 |
| Luna Extract → Verify | 전제별 보고 거짓 확률의 최댓값 |
| Luna Direct / CoT | 질문 전체에 대해 모델이 보고한 거짓 전제 존재 확률 |

AUROC는 FPQ를 NFP보다 높은 점수에 놓는 순위 성능이며 0.5 문턱의 정확도나 FPQ 탐지율이 아니다. Qwen의 기존 표 1은 각 평가 fold에서 AUROC를 계산해 문항 수로 가중했다. Luna는 별도 학습을 하지 않은 고정 프롬프트이므로 유효 응답의 pooled AUROC를 계산한다. 최종 집계는 source group bootstrap 2,000회(seed 20260923) CI도 남긴다. 이 CI는 고정 응답에 조건부이며 모델을 반복 호출한 불확실성은 아니다.

Luna의 보고 확률은 token logprob가 아니다. Qwen과 질문·검토 과제는 대응하지만 출력 형식·점수 추출·문턱 설정·생성 설정까지 동일하지는 않다. 이 차이를 표 각주에 유지해야 한다. 모델 간 유의한 우월성을 같은 protocol의 비교처럼 주장하지 않는다.

## 산출물과 재개

```bash
python3 scripts/run_luna_direct_cot_gate.py run \
  --out-dir results/frontier_cli/luna_direct_cot_20260923_v1 \
  --workers 20
```

`plan.json`에 실제 프롬프트·모델 옵션·입력 및 코드 SHA-256을 고정한다. `direct/<id>`, `review/<id>`, `cot/<id>`에 호출 프롬프트, 원문, 이벤트, 판정, 전송 재시도 안내를 보존한다. 검토문과 최종 판정은 별도 호출로 저장한다. 성공한 기록은 재호출하지 않으며 실패·중단 기록은 검토 없이 자동 재시도하지 않는다.

`status.json`과 `question_scores.csv`에 유효 분모·탐지·오탐·AUROC를 갱신한다. 완료 전 집계는 부분 자료다. 오류 0개일 때만 전체 완료라고 표시한다. STOP 파일 또는 종료 신호는 해당 실행의 새 호출과 자식 프로세스를 중단한다. 학습된 probe, 최종 교정 답변, Well 점수는 이 실행에서 생성하지 않는다.
