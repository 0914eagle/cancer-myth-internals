# Haiku 거부 문항 직접 판정 — 2026-10-12

사용자가 채점 마무리를 요청한 CREPE `2019_b-08946`의 저장 답변 16개를 이 대화의 Codex가 직접 읽고 판정했다. 사람 또는 Haiku의 판정으로 보고하지 않는다. 기존 답변, 정답 주석, 4점 이상 성공 기준, FPQ 500개 분모는 변경하지 않았다.

원본 주석에는 모순이 있다. false-claim 필드는 액체 반입 규정이 안전에 도움이 되지 않는다는 내용을 거짓으로 지정하지만, reference answer는 이를 실질적 안전보다 안심을 위한 조치로 설명한다. 고정된 Well 규약은 정답 설명을 평가 근거로 쓰도록 명시한다. 따라서 이번 점수는 그 규약 아래의 판정이며, 보안 규정의 실제 효과에 대한 독립적인 사실 판단이 아니다. 문항의 주석 타당성 문제는 해소되지 않았다.

## 판정 및 집계

- 1점 4건, 2점 12건. 4점 이상은 0건.
- 모델·방법별 이유, 답변 해시, 평가 규약 해시를 [판정 원장](manual_adjudication_20261012.json)에 보관한다.
- 원본 공급자 거부와 직접 판정 원장을 별도로 보존한다. 표는 유효한 Haiku 점수가 있으면 이를 우선하고, 없을 때만 해당 답변·주석에 일치하는 직접 판정을 사용한다. 중복 합산하지 않는다.
- 같은 질문의 다른 방법이나 향후 새 답변에는 점수를 복사하지 않는다.
- 거부 상태 자체는 실패 점수의 근거가 아니다. 저장된 답변을 읽고 규약으로 판정한 점수만 반영한다.
- 이번 보완으로 해당 16개 셀의 FPQ 채점 수는 499/500에서 500/500이 된다. 주석 문제의 영향은 이 문항을 제외한 499개 기준 보조 집계로 별도 확인할 수 있다.
