## 2. 대화에서 바로잡은 해석

### 2.1 원 FPQ 주석과 새 수정 질문의 검증은 다르다

원 FPQ의 평가는 선행 벤치마크의 의사 검토 주석을 기본 정답으로 사용한다. 이 작업을 모든 의학적 사실의 재심사로 확대하지 않는다.
그러나 우리가 만든 수정 질문은 그 의사 검토를 자동으로 물려받지 않는다. 목표 전제 제거, 환자 사실·요청 보존, 남은 전제와
문맥 정합성을 따로 확인한다. 명백한 원문/참조 불일치 의심은 보류 사례로 기록하고 원 라벨을 조용히 변경하지 않는다.

대화의 '아버지가 신장 전체를 제거할 예정'이라는 축약 예시만으로 원 FPQ가 틀렸다고 판단할 수 없다. 개인의 수술 계획과
'모든 환자가 반드시 그 수술을 받아야 한다'는 일반 주장은 다르다. 일반 주장을 반박하는 참조만으로 개인 수술 계획을
'종양만 제거할 예정'으로 바꾸는 것은 통제 실패다. 원 질문 전체와 목표 주석을 대조해야 한다.

따라서 새 자료는 **목표 전제를 수정한 질문**으로 부른다. 모든 문장이 임상적으로 검증된 정상 질문이라는 뜻은 아니며,
원 NFP와 합쳐 같은 종류의 정답 자료처럼 취급하지 않는다. 수정이 불가능한 원문도 있을 수 있다.

### 2.2 조동사·출처 표현을 바꾸는 것의 의미

`always/must/never`가 F에, `may/might/not always`가 T에 몰리면 표면 단서만으로 분류할 수 있다. 내부 표상에도 어휘·문법 정보가
있으므로 hidden probe는 이 문제에서 자유롭지 않다. 그러나 양태의 차이 자체가 명제의 진위를 결정할 수도 있으므로
그 단서를 무조건 제거하거나 여기에 반응한다는 이유만으로 probe가 잘못됐다고 할 수도 없다.

`would`를 일률적으로 '그럴 수도 있다'와 동일시하지 않는다. 가능성 표현과 조건·가정 표현은 맥락에 따라 다르다.
35의 출처 표현 조립은 동일 명제를 유지하려는 작은 통제이며, 이것만으로 일반적인 진위 표상을 입증하지 않는다.

probe가 쓰는 단서를 확인할 후보 검사는 다음과 같다(아직 이번 대화에서 실행하지 않음).

- 조동사·부정어·길이만으로 라벨을 예측하는 분류기로 쉬운 단서가 얼마나 있는지 확인.
- 같은 표현 유형 안의 참/거짓 주장을 비교해 내용에 대한 판별이 남는지 확인.
- 의미를 유지한 의역에서 점수가 유지되는지 확인. 기존 의역 실험을 확인한 뒤 부족한 조건만 추가.
- 판독 정보에 대한 개입과 실제 모델 행동을 비교. probe의 이용 정보와 원 모델의 행동 이용 정보는 별개의 질문.

가중치 하나나 높은 AUROC만으로 '무엇을 학습했다'를 완전히 읽어낼 수는 없다. 관련 근거:
[control tasks](https://aclanthology.org/D19-1275/), [Amnesic Probing](https://aclanthology.org/2021.tacl-1.10/).

### 2.3 뒤의 요청 때문에 교정이 우선되지 않는가 — 미검증 가설

'노인에게만 생긴다'는 주장을 처리할 때 오류를 구분하지만 뒤의 '할머니를 어떻게 도울까'에 답하는 과정에서
교정이 우선되지 않을 수 있다는 가설을 논의했다. 오류 정보가 이용하기 어려워지는 경우와 정보는 남지만 교정 행동을 선택하지 않는
경우를 구분해야 한다. 주장이 거짓임을 아는 것과 지금 반박해야 한다고 판단하는 것도 같지 않다.

후보 대조는 같은 주장에 (a) 주장만, (b) 진위 확인 요청, (c) 도움 요청, (d) 도움+주장 확인 요청을 붙이고 각 조건의 F/T를 비교하는 것.
그러나 이는 아직 실행·확정된 새 실험이 아니다. 기존 신호 흐름·C3 결과가 이 가설을 입증하지는 않는다. 먼저 기존 결과와 자료를
확인하며, 같은 주장을 확보하지 않은 채 새 격자를 늘리지 않는다.

## 3. Two Axes와의 관계 — 두 축과 프롬프트 라우팅을 구분

원문: [Two Axes of LLM Abstention](https://arxiv.org/html/2607.08456v1).

- **§4 surface confound:** SelfAware BoW AUROC 0.87, hidden 0.97–0.99의 높은 분류 성능에 표면 단서가 섞일 수 있음을 이미 지적했다.
  이 두 수치만으로 내부 probe가 표면 단서에 의존하는 비율을 정확히 분해하지는 못한다.
- **§5–6 CREPE:** 마지막 프롬프트 토큰의 hidden state에 학습한 logistic probe로 전제 확인 프롬프트를 적용할 질문을 선택한다.
  DiM은 판별 비교에 포함되지만 §6 프롬프트 라우팅은 hidden probe로 기술된다. 거짓 전제 의심 점수 하나로 두 프롬프트를 선택한다.
- **§7 two axes:** 답변 가능성과 답변 정확성을 별도로 점수화하고 두 문턱을 모두 넘을 때만 답하는 선택적 기권 정책이다.
  §6 교정 정책이 두 개의 게이트를 동시에 통과한다는 뜻이 아니며, 탐지 방향과 교정 steering 방향의 구분도 아니다.
- Table 3의 74%(Llama), 76%(Qwen)는 거짓 전제를 **지적한 비율**이다. 정확한 교정률 또는 Cancer-Myth PCR로 바꾸어 쓰지 않는다.

우리의 현재 판별 비교와 프롬프트 라우팅은 선행 방법의 재현·확장 비중이 크다. 'Cancer-Myth에도 혼동 요인이 있다' 또는
'hidden으로 게이팅했다'만으로 강한 방법 신규성을 주장하지 않는다. 모델 수만 늘려도 데이터 의존성 문제는 해소되지 않는다.
분석 기여라면 정확한 실패 조건·설명이, 방법 기여라면 이를 줄이는 설계와 대조 결과가 추가로 필요하다. 현재 둘 다 완성됐다고 하지 않는다.

## 4. 이미 확인한 CREPE 전이와 아직 숫자를 못 확인한 행

다음은 **34 §2의 기존 기록을 옮긴 값**이며 이번에 재계산하지 않았다. Qwen 파이프라인, 마지막 프롬프트 토큰, CREPE 3,000개 표집.
within-CREPE는 5-fold, 전이는 CREPE 학습 자료로 모델/하이퍼파라미터를 정한 뒤 대상에 적용하는 별도 조건이다.
Two Axes 논문의 가중치를 가져온 것이 아니라 우리 코드로 같은 종류의 probe를 학습한 결과다.

| 학습 → 평가 | text | hidden logistic | DiM(mean) | 의미 |
|---|---:|---:|---:|---|
| CREPE → CREPE 내부 5-fold | 0.673 | 0.766 | 0.757 | CREPE 내 일반화 |
| CREPE → 원 FPQ vs 전제 수정 질문 (`twins`) | 0.531 | 0.510 | 0.528 | 의료 전제 수정 조건으로의 전이 |
| CREPE → 거짓 전제 의역 vs 전제 수정 질문 (`edited`) | 0.526 | 0.537 | 0.581 | 양쪽 구간이 생성된 대조 조건으로의 전이 |
| 전제 의역/수정 조건 → CREPE | 0.524 | 0.613 | 0.598 | 역방향 전이 |
| Cancer-Myth 원 FPQ/NFP → CREPE | 0.512 | 0.490 | 0.397 | 자연 집단 학습 후 전이 |
| **CREPE → Cancer-Myth 원 FPQ/NFP (`crepe->natural`)** | **미확인** | **미확인** | **미확인** | 코드에 있으나 위 문서 표에는 누락. 기존 산출물 먼저 확인 |

0.510과 0.537을 원 FPQ 대 NFP 분류 성능으로 인용하면 안 된다. DiM 0.581 같은 약한 전이도 있어 '모든 내부 신호가 완전히
chance'라고 묶지 않는다. 목표 수정 자료의 타당성 문제도 남아 있으므로 전이 실패의 원인을 진위 정보 부재로 확정하지 않는다.

**표현 정정:** 'hidden state probe가 의료에서 실패했다'는 너무 넓다. '현재 모델·층·위치·학습 조건의 probe가 시험한 전이 조건에서
충분한 판별력을 유지하지 못했다'가 맞다. Cancer-Myth 안에서도 원 집단 분류는 작동했으므로 'Cancer-Myth에서 전부 안 된다'도
부정확하다. 데이터가 다르면 같은 probe 방식이라도 학습 가중치·단서가 달라진다. 도메인 자체가 원인인지는 확인되지 않았다.

보고서 행이 없거나 일부 신호만 있으면 아래로 저장된 예측 개수·학습 선택·skip 이유와 집계값을 확인한다.
파일이 없으면 재실행하지 않고 missing을 출력한다.

```bash
python - <<'PY'
import json
import os
from collections import Counter
from pathlib import Path

d = Path(os.environ['CREPE_TRANSFER_DIR'])
condition = 'crepe->natural'
for name in ('plan.json', 'result.json'):
    p = d / name
    if not p.is_file():
        print('MISSING:', p)
        continue
    data = json.loads(p.read_text())
    if name == 'plan.json':
        print('PLAN:', json.dumps(data, ensure_ascii=False, indent=2))
        continue
    print('PREDICTION COUNTS:', dict(Counter(
        r['signal'] for r in data.get('predictions', [])
        if r.get('condition') == condition)))
    for key in ('selections', 'skipped'):
        rows = [r for r in data.get(key, []) if r.get('condition') == condition]
        if key == 'selections':
            rows = [{k: r.get(k) for k in ('signal', 'fold', 'best', 'train_n', 'eval_n')} for r in rows]
        print(key.upper()+':', json.dumps(rows, ensure_ascii=False, indent=2))
for p in sorted(d.glob('summary_bootstrap*.json')):
    data = json.loads(p.read_text())
    print(p.name, json.dumps(data.get(condition, {'status': 'condition absent'}), ensure_ascii=False, indent=2))
PY
```

확인할 내용은 다음과 같다.

- `text/hidden/mean`의 n, FPQ/NFP 수, AUROC와 CI, 선택 층/C, skip 이유를 확인한다.
- 학습과 층/C 선택이 CREPE 안에서만 이루어졌는지 plan/구현과 대조한다.
- 이 스크립트의 주된 결과는 AUROC다. 고정 문턱의 TPR/FPR나 최종 교정 효용까지 측정했다고 해석하지 않는다.
- 결과가 있으면 신규 실험으로 세지 않고 문서의 누락 행을 채운다. 없으면 누락 이유부터 확인한다.

## 6. 병행 비교: 텍스트 게이트 뒤에 같은 교정 도구

현재 Qwen/Well 조건에서 Plain, CoT, 항상 교정, 무작위 선택, 텍스트 선택, hidden 선택을 비교한다.
선택된 질문은 **동일한 무조건 교정 프롬프트** 답변을, 선택되지 않은 질문은 동일 Plain 답변을 사용한다.
외부 gate 뒤에 다시 Yes/No 자체 판정을 하는 self-gated FP를 붙이면 두 번의 선택이 섞이므로 기본 비교와 분리한다.

질문 ID·모델·프롬프트·생성 설정·평가 루브릭이 맞는 기존 답변과 점수가 있으면 선택에 따라 재조합할 수 있다.
이 경우 추가 생성·채점 없이 가능하다. 완비 여부는 확인 전이며, Gemma/Sol/Terra 점수를 현재 Qwen/Well 표에 섞지 않는다.
무작위 게이트는 동일 개입 수를 맞추고, 일반 의료 QA 보존은 별도로 측정해야 한다.

분류 AUROC뿐 아니라 calibration에서 고정한 문턱의 TPR/FPR, 최종 교정·정상 보존·rescue/harm을 본다.
평가 자료를 보며 문턱을 고르거나 이미 반복해서 본 dev를 새 독립 test처럼 쓰지 않는다. 비교에는 같은 문항과 같은 평가 기준을 쓴다.

이 단계는 '텍스트로 해결됐다'는 전제가 아니라 가장 단순한 선택이 얼마나 유용한지 확인하는 baseline 완성이다.
텍스트의 Cancer-Myth 내 우위가 CREPE의 probe 우위 때문에 무효가 되는 것은 아니며, 내부 방식을 쓰기 위해 텍스트를 배제하지 않는다.
반대로 텍스트가 여기서 잘된다고 의료 전반이나 범용 진위 판별로 확대하지 않는다.

## 7. 다음 결과를 어떻게 읽을 것인가

- **CREPE → natural이 높고 수정 조건에서는 낮음:** 원 집단 분류와 전제 변화 민감도가 다르다는 증거. 순수 진위 판별로 확정하지 않음.
- **양쪽에서 낮음:** 시험한 학습/모델/판독 조건의 전이 한계. 의료 전체나 모든 probe의 실패로 확대하지 않음.
- **텍스트 routing이 개선됨:** Cancer-Myth의 교정/보존 효용을 보고. 단순 구성만으로 새 방법론을 주장하지 않음.
- **내부 신호가 일부 조건에서 우세함:** 비교 가능한 조건에서 최종 교정 효과까지 확인. 별도 데이터에서 각각 학습한 성능을 전이라고 부르지 않음.

우선순위는 (1) 저장된 `crepe->natural` 확인, (2) 텍스트 선택 최종 비교 준비, (3) 통제 자료 점검이다.
새 회로 탐색·대규모 재생성·다중 모델 격자를 먼저 추가하지 않는다. 이번 커밋은 논의와 실행 순서 기록이며 실험 성공 보고가 아니다.
