## 1 Introduction

### 슬라이드 1 풀고 싶은 문제

**슬라이드 맨 위 문장: 잘못된 전제를 고치는 능력과 정상 질문에 그대로 잘 답하는 능력을 함께 높여야 합니다.**

| 질문 | 필요한 답변 행동 | 실패 |
|---|---|---|
| FPQ: 질문이 틀린 주장에 의존함 | 그 주장을 바로잡고, 가능한 요청에도 답함 | 틀린 가정을 받아들인 채 요청만 수행하거나, 다른 주장만 반박함 |
| NFP: 불필요한 교정이 필요 없는 질문 | 주어진 맥락에 맞게 답하고 필요한 한계만 설명함 | 질문에 없는 오류를 만들어 반박하거나, 확인할 수 없다는 이유로 응답을 흐림 |

**보존**은 주석이나 사용자의 모든 말을 무조건 참으로 선언하는 것이 아닙니다. 질문에 없는 더 강한 주장을 만들어 반박하지 않고, 주어진 맥락에서 요청에 실질적으로 답한다는 뜻입니다. 일반적인 주의사항이나 “그런 서비스는 없습니다”라는 정상적인 부정 답변도 자동으로 오반박이 되지 않습니다.

**발표 설명**

> FPQ만 잘하는 모델을 만들려는 것이 아닙니다. 오류를 더 적극적으로 찾게 했을 때 정상 질문까지 잘못됐다고 말하면, 실제 사용자에게는 새로운 문제가 생깁니다. 따라서 최종 목표는 두 종류의 질문에 모두 적절하게 답하는 것입니다. 별도 탐지 점수는 그 목표를 달성하는 방법을 진단하는 보조 지표입니다.

### 슬라이드 2 이번 연구가 묻는 세 질문

**슬라이드 맨 위 문장: 원래의 교정 실패, 개입으로 생기는 동반 손상, 특정 방법의 실패를 구분합니다.**

| 질문 | 무엇을 설명해야 하나 | 현재 위치 |
|---|---|---|
| 왜 Plain은 FPQ를 놓치는가 | 배경 처리, 요청 수행, 지식 사용 등의 영향 | 기존 문헌에 설명과 개입 근거가 있음 |
| 왜 교정을 늘리면 NFP도 손상되는가 | **두 행동을 함께 바꾸는 요소** | 연구의 중심 질문. 다른 분야의 가설을 가져와 확인할 필요가 있음 |
| 왜 특정 해결책이 실패하는가 | 검증 대상·판정 형식·답변 전달 등의 문제 | 우리 파이프라인 분석이 주로 다룬 부분 |

“참인 전제도 거부한다”는 **결과의 기술**이고, “검증 단계에서 많이 발생한다”는 **병목 진단**입니다. 그 결과를 만드는 입력 변환·학습 신호·개입 방향 등을 지목하고, 해당 요소를 바꾸었을 때의 결과를 예측해야 원인 가설이 됩니다.

현재 확보한 것은 기존 방법의 적용 결과와 구체적인 실패 경로입니다. **이것이 모든 개입의 FPQ–NFP trade-off를 설명하는 하나의 원인을 찾았다는 뜻은 아닙니다.**

## 2 Related Work

### 슬라이드 3 기존 연구는 왜 FPQ를 놓친다고 설명하는가

**슬라이드 맨 위 문장: 단독으로 사실을 구별하는 능력과 요청 속의 잘못된 전제를 교정하는 행동은 다를 수 있습니다.**

| 논문 | 저자의 설명과 근거 | 우리에게 주는 가설과 한계 |
|---|---|---|
| [Accommodation and Epistemic Vigilance: A Pragmatic Account of Why LLMs Fail to Challenge Harmful Beliefs](https://arxiv.org/html/2601.04435v1) | 대화 배경의 내용을 수용하는 화용론적 설명. 쟁점 여부·표현·출처를 조작해 교정 변화를 비교 | 배경 처리 때문에 검토가 생략될 가능성. Cancer-Myth 직접 근거지만 모든 trade-off의 원인은 아님 |
| [Knowing but Not Correcting: Routine Task Requests Suppress Factual Correction in LLMs](https://arxiv.org/html/2605.05957v2) | 단독 진술과 요청 문맥을 비교. 과제 문맥에 따른 주의 변화와 중간층의 요청 수행 방향, 내부 개입을 분석 | 오류 지식을 사용할 조건이 달라질 수 있음. 이 논문의 교정 회복과 일반 능력 유지가 NFP 보존까지 보장하지는 않음 |
| [Towards Understanding Sycophancy in Language Models](https://arxiv.org/abs/2310.13548) | 사용자 믿음과 일치하는 답변이 선호되는 학습 신호, 최적화 후 동조 증가를 분석 | 사용자의 틀린 믿음을 따르는 배경 설명. 우리 모델의 모든 실패가 RLHF 때문이라는 증거는 아님 |

앞의 두 연구는 모두 맥락이 교정에 영향을 준다고 보지만 조작과 설명 수준이 다릅니다. 첫 연구는 **대화에서 해당 주장이 어떤 지위에 놓이는지**, 둘째는 **요청 수행 문맥이 모델의 처리와 출력에 어떤 영향을 주는지**를 다룹니다.

주의할 인용: Accommodation의 “wait a minute”은 assistant prefill 개입입니다. Cancer-Myth에서 Claude-Sonnet-4의 교정률은 0.40→0.68, 오탐률은 0.09→0.17이므로 “오탐이 증가하지 않았다”고 설명하지 않습니다. 이 논문의 교정률·오탐률과 우리의 Well≥4 지표도 동일하지 않습니다.

### 슬라이드 4 두 행동을 함께 바꾸는 원인 가설은 어디서 가져오는가

**슬라이드 맨 위 문장: 직접 FPQ 연구와 인접 분야의 원인 가설을 구별하고, 우리 개입에 맞는 설명만 가져옵니다.**

| 출처 | 제시한 원인 가설 | 우리 실험에서 확인해야 할 것 |
|---|---|---|
| [Won’t Get Fooled Again: Answering Questions with False Premises](https://aclanthology.org/2023.acl-long.309/) | 추가 학습의 분포 차이와 망각 가능성. 일반 QA replay로 손상을 완화 | **학습 조건**에 해당. 일반 능력 손실과 반박 경향 학습을 따로 구분해야 함 |
| [Antidote: A Unified Framework for Mitigating LVLM Hallucinations in Counterfactual Presupposition and Object Perception](https://arxiv.org/abs/2504.20468) | 시각적 거짓 전제의 선호 학습 후 과잉 주의를 보고하고 참 전제 자료를 추가 | VLM의 데이터 구성·보존 평가 참고. 내부 원인까지 분리한 연구는 아님 |
| [Navigating the OverKill in Large Language Models](https://arxiv.org/html/2401.17633) | 안전 지시가 위험해 보이는 표면 단어에 대한 의존을 강화해 정상 요청도 거절 | **교정 지시가 진위보다 특정 표현에 대한 반박을 증폭하는가?** 안전 거절에서 가져온 적용 가설 |
| [Dual-Stance Evaluation of Sycophancy: The Structure of Agreement and the Limits of Intervention](https://arxiv.org/html/2606.11205) | 동의·비동의 평균 차이로 만든 방향이 부당한 동조뿐 아니라 타당한 동의까지 건드림 | 개입이 오류 수정 대신 일반적 비동의를 겨냥하는가. 특정 steering 구성법에 관한 설명 |
| [Sycophancy Suppression Can Impair Rational Updating: Anti-Sycophancy Should Preserve the Ability to Update](https://arxiv.org/html/2608.26511v1) | 근거 없는 압력에 굴복하는 행동과 타당한 근거를 수용하는 행동에 기여하는 구성요소·방향이 일부 겹침 | 우리 과제에서도 실제 구성요소 개입이 두 행동을 함께 바꾸는지 확인. 표현 유사도만으로 확정할 수 없음 |

따라서 “거짓 전제 분야에는 trade-off 원인 연구가 전혀 없다”는 표현은 쓰지 않습니다. 학습 조건에 대한 가설은 있습니다. 다만 **프롬프트·학습·검증 파이프라인을 모두 설명하는 원인이 우리 데이터에서 검증된 것은 아닙니다.**

**발표 설명**

> 문헌을 정리하면서, 반박을 많이 한다는 현상에 이름을 붙이는 것과 실제로 두 행동을 함께 바꾸는 요소를 제시하는 것을 구분했습니다. 예를 들어 안전성 연구에서는 특정 단어에 대한 의존을 지시가 강화한다는 설명이 있고, 동조 연구에서는 개입 방향이 타당한 동의까지 포함한다는 설명이 있습니다. 이것들을 Cancer-Myth에서도 성립하는 사실로 가져오는 것이 아니라, 구체적인 예측을 가진 가설로 가져오겠습니다.

| [Which Linguist Invented the Lightbulb? Presupposition Verification for Question-Answering](https://arxiv.org/abs/2101.00391) | 질문의 전제를 검증해 답변 가능성과 오류를 다루는 초기 접근 |
| [PreWoMe: Exploiting Presuppositions as Working Memory for Long Form Question Answering](https://aclanthology.org/2023.emnlp-main.517/) | 전제를 추출하고 피드백·답변 방침을 만든 뒤 실제 답변 생성 |
| [Identifying and Answering Questions with False Assumptions: An Interpretable Approach](https://aclanthology.org/2025.emnlp-main.1228/) | 원자적 가정과 근거를 이용한 검증 접근. 우리 no-RAG 실행과 원 결과를 구분해야 함 |
| [Don’t ‘Well, Actually’ Me Unless You Know What You’re Talking About: Weak Presupposition Verification Degrades General QA Performance](https://arxiv.org/html/2608.06539) | 정상 질문을 포함한 비교와 정답 전제 검증을 통해 검증 단계의 약점을 지적 |

Well Actually는 검증기가 확인하지 못한 전제를 과도하게 거부한다고 해석합니다. 이는 중요한 **병목 진단**이지만, 입력 문맥·판정 형식·학습 편향 중 무엇이 이를 만드는지 각각 분리한 설명은 아닙니다.

특정 검증 절차의 실패에는 [DnDScore: Decontextualization and Decomposition for Factuality Verification in Long-Form Text Generation](https://arxiv.org/html/2412.13175)의 문맥 손실·추가 주장 혼입 설명, [Calibrate Before Use: Improving Few-Shot Performance of Language Models](https://arxiv.org/abs/2102.09690)의 예시·라벨 편향, [LLM Abstention Can Be a Prompt Artifact, in Addition to Genuine Uncertainty](https://arxiv.org/html/2507.16199)의 선택지 형식 효과가 참고가 됩니다. 이들은 검증기 설계를 진단하는 근거이며 모든 FPQ–NFP 동반 손상의 공통 설명은 아닙니다.

## 3 Method

### 슬라이드 6 비교한 방법과 구현 범위

**슬라이드 맨 위 문장: 모든 주 비교는 실제 답변 생성까지 수행했습니다. Yes/No 탐지만 비교한 것이 아닙니다.**

| 방법 | 질문에서 최종 답변까지의 처리 |
|---|---|
| Plain | 질문 → 답변 |
| 답변 GEPA | 학습·후보 선택 자료로 답변 시스템 지시 최적화 → 그 지시로 답변 |
| PreWoMe | 질문 → 전제 목록 → 질문과 목록을 보고 Feedback·Action 생성 → 답변 |
| Extract+Verify A | 질문 → 전제 목록 → 전제별 true/false → False 목록으로 Feedback·Action 구성 → 답변 |

두 파이프라인은 [Well 공개 구현의 고정 revision](https://github.com/ShenranTomWang/Well/tree/6c9770f65da6e9c50250cf94e35b07f258288e38)을 기준으로 템플릿·파서를 재사용했습니다. **같은 추출 메시지로 생성한 전제 목록을 공유**해, 추출 이후 처리 차이를 비교했습니다. 원 PreWoMe 저자의 전체 실험이나 Wang·Blanco의 검색 포함 구현을 그대로 재현했다고 부르지 않습니다.

- PreWoMe의 검토기는 **질문과 전제 목록 전체**를 받습니다. 추가 전제와 four-shot 예시 등 Well 구현의 동작을 유지했습니다.
- Extract+Verify의 검증기는 **전제 문장만** 받으며, 원 질문을 받지 않습니다. 검색 없는 LLM 검증 조건입니다.
- 두 방법 모두 최종 답변기에는 질문과 Feedback·Action을 줍니다.
- “원자적 추출·검증” 계열이지만, 실제로 모든 항목이 원자적이고 원문과 동치인지 별도 보장한 것은 아닙니다.

Plain·답변 GEPA는 zero-shot, 두 파이프라인은 공식 few-shot이므로 이 비교는 **방법 전체의 성능 비교**입니다. 분해 단계 하나의 순수한 인과 효과는 아닙니다.

### 슬라이드 7 검증과 답변 단계에서 무엇을 바꿨는가

**슬라이드 맨 위 문장: 확인 불가 처리, 주장 범위, 답변 지시를 바꾸며 교정과 정상 응답이 각각 어떻게 변하는지 시험했습니다.**

| 조건 | 바꾼 내용 | 시험하려던 생각 |
|---|---|---|
| A 이진 검증 | 기존 Extract+Verify | 비교 기준 |
| B 문맥 포함 삼분 검증 | 질문·기존 전제를 함께 주고 지지됨/거짓/확인 불가, 원문 관계·개인 보고 여부·이유 출력. 답변 지시도 변경 | 확인하지 못한 것을 곧바로 오류로 취급하지 않으면 정상 응답을 보존할 수 있는가 |
| C0 추가 검증 | B의 거짓·확인 불가 항목을 근거 없이 다시 검증 | 한 번 더 검토하는 효과 |
| C1 근거 추가 검증 | C0와 같은 절차에 NCI 검색 문단 추가 | 추가 호출이 아닌 외부 근거의 효과 |
| D 주장 범위 보존 | 질문·기존 후보에서 원문 인용과 개인 보고/추론/일반 주장 구분을 포함한 목록 구성 후 검증 | 질문에 없는 더 강한 주장을 판단하는 일을 줄일 수 있는가 |
| E 답변 지시 변경 | B의 판정을 고정하고, 확인 불가만으로 반박하거나 검증 결과 밖의 새 오류를 만들지 않게 지시 | 검증 이유가 불필요한 반박으로 이어지는 일을 줄일 수 있는가 |
| D+E | D의 판정을 고정하고 E의 답변 지시 적용 | 두 변경을 함께 적용한 결과 |

B와 E는 같은 검증 결과, D와 D+E도 같은 검증 결과를 사용합니다. 다만 최종 답변과 채점은 각각 새로 생성됩니다. **A→B는 선택지뿐 아니라 문맥·지시도 함께 바뀌므로 “확인 불가 선택지 하나의 효과”라고 하지 않습니다.**

C1의 근거는 NCI 암 개요·환자용 PDQ의 공통 자료집 223페이지, 2,812청크에서 검색했습니다. 질문·추출 주장으로 BM25 계열 검색을 하고 상위 4청크를 제공합니다. 문항의 정답 교정문으로 자료를 고르지 않았으며, Well의 원 RAG 조건과는 다른 자체 실험입니다. 일반 자료가 특정 환자의 진료 사실을 확인해 주는 것은 아닙니다.

이 조건들은 **개발 단계의 후보 방법과 진단용 비교**입니다. 현재의 Method를 최종 제안법으로 확정하지 않습니다. 특히 보고와 믿음 내용을 구분하는 개선이 자동으로 성공했다고 가정하지 않습니다.

### 슬라이드 8 데이터와 평가 설정

**슬라이드 맨 위 문장: 이번 신규 결과의 생성·채점·GEPA 수정 모델은 모두 GPT-6 Luna medium입니다.**

| 항목 | 설정 |
|---|---|
| 모델 호출 | Codex CLI, 요청 모델 `gpt-6-luna`, reasoning effort `medium` |
| 채점 | Well 공개 평가 템플릿·파서. 같은 Luna 계열 자체 채점의 한계가 있음 |
| 답변 GEPA | Well balanced/no-RAG 흐름, GEPA 0.1.1, metric-call 예산 설정 500 |
| Cancer-Myth GEPA 학습·선택 | 학습 FPQ 30/NFP 30, 후보 선택 FPQ 18/NFP 18 |
| Cancer-Myth 최초 평가 | FPQ 100/NFP 100. 이후 파이프라인 예시 중복 `fpq_291`을 모든 방법에서 제외해 **99/100**으로 통일 |
| CREPE GEPA 학습·선택 | 학습 풀 FPQ 905/NFP 905, 후보 선택 FPQ 50/NFP 50 |
| CREPE 평가 | 공식 test FPQ 751/NFP 2,253 전체 |
| 주 지표 | 집단별 Well≥4. 보조로 5점 비율 S5와 평균 점수 |

예산 500은 전체 API 호출 수가 아닙니다. 학습 풀의 모든 문항을 같은 횟수 평가했다는 뜻도 아닙니다. Cancer-Myth의 199문항은 이후 실패 분석과 방법 수정에 반복 사용했으므로 **현재 신규 방법의 개발 자료**입니다. 남은 문항도 이전 전체 분석에 노출된 이력이 있어 완전히 새로운 시험 자료라고 부를 수 없습니다.

Well 논문의 Gemini API 실행과 우리 CLI는 모델·추론 설정·샘플링·공급자 문맥이 다릅니다. Cancer-Myth 표본도 저자의 동일 ID 재현을 보장하지 못합니다. 따라서 “실험 조건이 전부 동일한 재현” 대신 **공식 프롬프트·평가 구현을 재사용한 다른 모델 실험**이라고 설명합니다. 이전 Table 2의 GPT-5.6 Luna·다른 판정 조건과도 그대로 합치지 않습니다.

## 4 Experimental Results

### 슬라이드 9 두 데이터셋의 답변 GEPA 결과

**슬라이드 맨 위 문장: Luna에서 답변 GEPA의 변화는 데이터셋에 따라 달랐고, Cancer-Myth에서는 교정 증가와 정상 응답 손상이 함께 나타났습니다.**

| 데이터와 방법 | FPQ ≥4 | NFP ≥4 | FPQ S5 | NFP S5 |
|---|---:|---:|---:|---:|
| CREPE Plain | 546/751 **72.7%** | 2,228/2,253 **98.9%** | 49.5% | 94.9% |
| CREPE 답변 GEPA | 561/751 **74.7%** | 2,209/2,253 **98.0%** | 51.9% | 93.0% |
| Cancer-Myth Plain | 55/100 **55.0%** | 91/100 **91.0%** | 39.0% | 85.0% |
| Cancer-Myth 답변 GEPA | 79/100 **79.0%** | 72/100 **72.0%** | 62.0% | 61.0% |

이 표의 Cancer-Myth 수치는 최초 100/100 평가입니다. 다음 파이프라인 비교 표는 예시 중복을 제외한 99/100으로 통일합니다.

CREPE에서는 FPQ가 2.0%p 증가하고 NFP가 0.8%p 감소했습니다. Cancer-Myth에서는 FPQ가 24%p 증가하고 NFP가 19%p 감소했습니다. **이 비교만으로 차이의 원인이 의료 지식이나 개인 상황이라고 결론내릴 수 없습니다.** 질문 형식·라벨·채점·자료 구성의 차이도 있습니다.

CREPE에서도 FPQ 약 25%가 4점 미만이므로 “해결됐다”거나 “성능 상한에 도달했다”고 하지 않습니다. Well의 Gemini 표와 비교할 때는 S5와 ≥4를 구분해야 하며, 서로 다른 판정 모델의 수치로 모델 우열을 확정하지 않습니다.

의료 지시 삭제 실험은 Cancer-Myth 100/100에서 FPQ 79→83%, NFP 72→72%였습니다. 한 번의 실행에서 나온 변화이며, **그 문구가 원인이 아니라고 확정할 수도, 삭제가 유의한 개선이라고 확정할 수도 없습니다.** 따라서 같은 의미의 보호 문구를 계속 추가하는 것만으로 해결된다고 보지 않았습니다.

**발표 설명**

> 문헌 조사만 진행한 것은 아니고, 일반 도메인의 전체 시험 자료까지 실제 평가를 완료했습니다. Luna에서는 CREPE가 Plain부터 정상 질문 보존이 높았지만 FPQ 교정은 여전히 남아 있었습니다. 반면 Cancer-Myth는 GEPA로 FPQ가 크게 올랐고 NFP도 크게 떨어졌습니다. 그래서 프롬프트 최적화만의 결과를 넘어서, 교정을 늘리는 과정에서 무엇이 함께 달라지는지를 볼 필요가 있었습니다.

### 슬라이드 10 기존 방법과 개선 조건을 같은 문항에서 비교

**슬라이드 맨 위 문장: 전제 검토는 교정을 늘렸지만, 우리가 시도한 변경만으로 두 성능을 안정적으로 함께 높였다고 말할 수는 없습니다.**

**모든 행은 동일 FPQ 99개·NFP 100개입니다. GEPA도 중복 문항을 제외해 다시 집계했습니다.**

| 방법 | FPQ 교정 ≥4 | NFP 보존 ≥4 |
|---|---:|---:|
| Plain | 54/99 **54.5%** | 91/100 **91.0%** |
| 답변 GEPA | 78/99 **78.8%** | 72/100 **72.0%** |
| PreWoMe | 88/99 **88.9%** | 59/100 **59.0%** |
| Extract+Verify A | 87/99 **87.9%** | 48/100 **48.0%** |
| B 문맥 포함 삼분 검증, 최초 답변 | 71/99 **71.7%** | 75/100 **75.0%** |
| C0 근거 없이 추가 검증 | 70/99 **70.7%** | 69/100 **69.0%** |
| C1 NCI 근거 추가 검증 | 74/99 **74.7%** | 70/100 **70.0%** |
| B 같은 검증 결과로 답변 재생성 | 77/99 **77.8%** | 69/100 **69.0%** |
| D 주장 범위 보존 | 65/99 **65.7%** | 87/100 **87.0%** |
| E 답변 지시 변경 | 61/99 **61.6%** | 82/100 **82.0%** |
| D+E | 66/99 **66.7%** | 93/100 **93.0%** |

표에서 읽을 수 있는 것은 다음과 같습니다.

- **PreWoMe·A:** Plain보다 FPQ는 높고 NFP는 낮습니다. 기존 trade-off의 다른 모델 적용 결과입니다.
- **A→B:** NFP 보존이 올라갔지만 FPQ 교정을 잃었습니다. 확인 불가·문맥·범위 지시를 묶은 변경으로 선택성이 해결되지는 않았습니다.
- **C0→C1:** 근거를 추가한 조건에서 FPQ 4문항, NFP 1문항의 순증가가 있습니다. 작은 단일 실행 차이와 검색 품질 한계 때문에 근거가 문제를 해결했다고 하지 않습니다.
- **B→D+E:** 정상 질문 보존은 높아졌지만 B보다 필요한 교정도 줄었습니다.
- **Plain→D+E:** 이 실행의 두 지표는 모두 높지만 반복 결과·독립 자료가 부족합니다. “trade-off 곡선을 벗어났다”거나 “최초로 해결했다”는 결론은 보류합니다. 기존 방법의 곡선 자체도 통제된 조건으로 추정하지 않았습니다.

### 슬라이드 11 원문 비교가 추가로 알려준 것

**슬라이드 맨 위 문장: 모든 실패가 전제 추출 오류는 아니며, 개인 상황을 보호하면 잘못된 믿음의 내용까지 보호하는 경우가 있었습니다.**

| 분석 대상 | 확인한 내용 | 해석의 범위 |
|---|---|---|
| NFP 100문항, PreWoMe와 A | 추출이 대체로 원문을 유지한 47문항 중 24문항에서 A의 False 판정이 하나 이상 존재 | 추출 수정만으로 충분하다고 볼 수 없음. 24개 모두 오판이라는 뜻은 아님 |
| Plain 성공→파이프라인 실패 NFP | PreWoMe 34개 중 14개, A 44개 중 19개는 추출이 대체로 유지됨 | 새 손상이 추출의 범위 변경에만 모이지 않음 |
| A 성공→B 실패 FPQ 21문항 | 16개는 False 없이 확인 불가 포함, 4개는 모두 지지됨, 1개는 False 있음 | 판정 보류와 교정 손실이 함께 관찰됨. 16개 모두 같은 원인이라는 결론은 아님 |
| B 재생성 성공→D+E 실패 FPQ 21문항 | D 판정에 False 0개, 모두 지지됨 17개·확인 불가 포함 4개 | 보고를 수용하면서 내용 검토가 빠진 사례가 있음. 앞 행의 21개와 다른 집단 |

## 논문으로 묶을 때의 현재 주장

**가제:** *Selective Correction of False-Premise Questions Without Unwarranted Rebuttals*

**Introduction:** 실제 QA에는 교정해야 하는 질문과 교정이 필요 없는 질문이 함께 있다. FPQ 성능만 높이는 개입은 정상 응답을 해칠 수 있으므로 실제 답변의 선택성을 목표로 삼는다.

**Related Work:** FPQ 실패를 설명하는 배경 수용·과제 수행 연구, 기존 추출·검증·프롬프트 최적화 방법, 교정과 보존의 동반 변화를 분석한 FPQ 및 인접 분야 연구를 구분한다. 새로운 문제 설정이나 최초의 trade-off 발견이라고 주장하지 않는다.

**Method:** 현재는 공통 평가와 단계별 변경 조건을 갖춘 실험 방법이 완성된 상태다. 최종 제안 방법은 아직 선택 전이다. 원문 범위와 보고/내용을 보존하는 검토, 판정에서 답변으로의 전달 제어는 후보이며, 반복·전이 결과를 보고 채택 여부를 정한다. “추출→검증→답변” 자체를 새 기여로 내세우지 않는다.

**Experimental Results:** 두 도메인의 답변 GEPA, 같은 199문항의 기존 파이프라인·변경 조건, 중간 출력과 답변 전환, 채점·생성 변동을 보고한다. 결과는 단순한 FPQ 향상뿐 아니라 NFP 손실과 효과의 재현성을 함께 포함한다.

**현재 주장 가능한 기여:** 기존 방법의 다른 모델 적용 결과, 그 방법에서 발생한 실패 경로의 구체화, 개선 시도의 한계와 측정 변동의 확인. **추가로 필요한 기여:** 문헌에서 가져온 원인 가설을 구분하는 통제 결과와, 그것을 겨냥한 변경의 반복·일반화 증거. 이 부분이 없으면 현재 자료는 방법의 완성을 주장하는 논문보다 분석·진단 결과에 가깝다.

**교수님께 드릴 마무리 설명**

> 현재까지는 기존 방법의 재현과 개선 시도, 중간 출력 분석까지 진행했습니다. 그 결과 정상 질문 보존을 높이는 변경이 필요한 교정까지 줄일 수 있고, 최종 답변이 검증 판정만으로 결정되지 않는다는 점을 확인했습니다. 다만 이를 trade-off의 근본 원인을 찾았다고 표현하지 않겠습니다. 다음에는 문헌에서 제시한 표면 단서 의존과 개입의 비선택성 가설을 바탕으로, 무엇이 두 행동을 함께 바꾸는지를 통제 실험으로 확인하고 그 요소를 겨냥한 방법을 선택하려 합니다. 기존 반복 평가와 검증기 GEPA는 먼저 미완료 상태를 정리하겠습니다.
