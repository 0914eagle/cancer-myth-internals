# 08. 논문 서사 — 양식에 맞춰

양식(빌린 것): 도메인 요구 → 모델은 능력이 있다 → 그런데 기존 검증 방식은 문제 → 그러니 내부에서 → 내부 방법 중 왜 이것 → 기존 것을 그대로 못 쓰는 이유(데이터·구조·목적식) → 방법론 TL;DR·contribution → 정의.

각 단계는 **우리 근거**(이 프로젝트에서 확인했거나 세운 논리)와 **문헌 근거**로 나눈다. `※`는 기억에 의존, 원문 확인 필요.

---

## 1. 환자 질문에는 잘못된 믿음이 전제로 깔려 온다. 의사는 질문에 답하기 전에 그 전제부터 고친다. LLM은 겉 질문에만 답한다.

**주장.** 환자의 질문은 결정의 근거를 구하는 것이다. 그 근거가 거짓 전제 위에 있으면, 겉 질문에 대한 정확한 답이 틀린 결정을 낳는다. 질문에 답하는 능력과 전제를 고치는 능력은 다른 축이다.

**우리 근거.**
- Cancer-Myth Table 1: GPT-4o MedQA 70 / PCR 12, Gemini-2.5-Pro MedQA 92 / PCR 41. 일반 의료 QA 점수가 전제 교정을 예측하지 않는다.
- 장루 예시: "얼마나 걸리나"에 정확히 답하면서 "장루는 영구적"을 두면 환자는 그 전제로 결정한다.

**문헌 근거.**
- Cancer-Myth (ICLR 2026): 585문항, 의사 3명 검증, 프런티어 ≤43%.
- Well-Actually: 실제 사용자 질문(WildChat)의 ~13%가 거짓 전제.
- MedMisBench: 근거 없는 맨주장이 날조 근거보다 10~27%p 더 잘 먹힌다 — 환자의 무근거 믿음이 가장 위험한 형태.
- Qazi et al. 2025 (RCT): 결함 있는 LLM 출력이 의사 진단 정확도를 18%p 떨어뜨림.

## 2. 모델은 그 전제가 거짓임을 안다

**주장.** 문제는 지식 부족(H1)이 아니다.

**우리 근거.**
- Well-Actually Table 1: 전제를 꺼내 물으면 96~100% 거짓이라 답하는 모델이 질문 속에서는 1~3%만 고친다. 같은 모델, 같은 전제.
- 03의 H1 기각.

**문헌 근거.**
- Pandey (2604.19117): 동조하는 순간에도 "틀렸다" 신호가 같은 head에 있다. 12모델. 회로를 끄면 동조 28→81%, 사실 정확도 69→70.
- MedMisBench: 추론 trace에 오도 단서 81~98% 등장.
- Contextual-Truth (2608.03035): 맥락 속 명제 진위가 선형 표상, probe 74~89%.
- Two Axes (2607.08456): CREPE 자연 질문에서 hidden probe 0.69~0.78.

## 3. 출력 수준에서 고치려는 방법은 문제가 많다

**주장.** "의심을 켜라"고 시키든, "판정하라"고 시키든, 출력 채널을 통하는 순간 두 가지가 깨진다. 참 전제까지 의심하거나(오탐), 판정 자체가 편향된다.

**우리 근거.**
- **전역 의심 → NFP 붕괴.** Table 1: GEPA +56 / NFP −29, Monitor +79 / NFP −55. Well-Actually Table 8~10: FP Identification 프롬프트 FPQ 75 / TPQ **0**, 파인튜닝 FPQ 62 / TPQ **0**. 6개 방법군에서 일반화.
- **판정 시키면 편향 (H6).** Well-Actually: 참 전제의 58~93%를 거짓이라 함(negative bias). Two Axes: 질문 단위로 물으면 거의 전부 "멀쩡"(accommodation). 묻는 방식에 따라 반대로 쏠리고 어느 쪽이든 판별은 chance (0.43~0.67).
- **꺼내면 바뀐다 (H4).** Contextual-Truth: 거짓 명제를 생성 중 되뇌면 표상이 참 쪽으로 넘어가는 비율 58.7%, 암묵적일 때의 2.6배. 출력으로 검사하는 행위가 상태를 오염시킨다.
- **자연 분포에서는 어떤 출력 개입도 진다.** Well-Actually: FPQ ~13% 가중 시 Direct QA가 1등. TPQ를 1점이라도 깎으면 진다.

**문헌 근거.**
- FalseQA (ACL 2023): 거짓 전제만으로 학습하면 참 전제까지 거부 — 시소의 최초 보고.
- Two Axes §6: "거짓 가정이 있으면 지적하라" 항상 켜면 멀쩡한 질문 57~78% 오지적. "instruction은 threshold를 옮기지 지식을 옮기지 않는다."
- Dual-Stance (2606.11205): 무조건 steering은 동조와 사실 동의를 같이 깎는다 — 출력 밖에서도 "전역"이면 같은 시소.
- ※ CoT unfaithfulness 계열 (Turpin 2023, Lanham 2023, Chen/Anthropic 2025, Baker/OpenAI 2025): 말로 낸 추론이 계산을 반영하지 않는다. 우리 타깃 모델(Gemma-2-27B, Llama-3.1-8B)은 CoT를 내지도 않는다.

## 4. 그러니 내부 표상에서 읽어야 한다

**주장.** 신호는 출력 이전에 있고, 거기서 읽으면 (a) 판정 편향을 우회하고 (b) 생성 전이라 되뇌기 오염이 없고 (c) 어느 토큰에서 켜지는지 국소화되며 (d) 같은 출력을 내는 다른 원인(H2 vs H3)을 가를 수 있다.

**우리 근거.**
- 03의 읽는 위치: 전부 prefill. 전제 구간 마지막 토큰(A·B), 마지막 프롬프트 토큰(C).
- 2×2 분해: H2(못 봤다)와 H3(알지만 따라간다)는 **출력이 같다.** 내부에서 A와 C를 같이 읽어야만 갈린다. 이 분포를 아무도 안 냈다.

**문헌 근거.**
- Two Axes Table 2: 같은 forward pass에서 출력 0.49~0.58, 직접 질문 0.43~0.67, hidden probe 0.69~0.78. 신호 위치만 다르다.
- Detection Without Correction (2604.13068): probe는 position zero, 출력 토큰 전에 읽힌다.
- Pandey: RLHF는 행동만 줄이고 내부 신호는 남긴다(Llama-3.1→3.3). 읽을 것이 사라지지 않는다.
- Ferrando (ICLR 2025): "아는 entity" 방향이 refusal을 인과적으로 게이트 — 지식 신호가 태도를 조절하는 내부 경로가 실재.
- ※ MacDiarmid 2024: 출력에 안 보이는 의도를 residual probe가 잡음.

**정직하게 쓸 한계.** 탐지 ≠ 제어 (2606.24952, 2604.13068, 2607.00158). probe 방향으로 밀면 안 고쳐진다. → 읽는 방향과 미는 방향을 분리해야 한다. 5절의 이유.

## 5. 내부 방법이 많은데 왜 "진위로 게이트한 태도 개입"인가

**주장.** 내부 개입은 셋으로 나뉜다. (i) 무조건 방향 밀기, (ii) 게이트 밀기 — 게이트 신호와 개입이 같은 개념, (iii) verbalizer로 읽기만. 우리는 **게이트 신호(진위)와 개입 대상(태도)이 다른 개념**인 넷째다. 이유: 고쳐야 할 것은 지식이 아니라 태도이고(2절), 개입을 켤 조건은 태도가 아니라 진위여야 참 전제가 안전하다(3절).

**비교 대상.**

| 방법 | 게이트 | 개입 | 우리 문제에서의 한계 |
|---|---|---|---|
| CAA / ITI / RepE (무조건) | 없음 | 진실·정직·반동조 방향 | 전역 → Dual-Stance식 시소. NFP 붕괴 예측 |
| CAST / DSAS / GAPS | 개입 개념과 같은 방향의 정렬 | 같은 방향 | toxicity처럼 게이트=개입 개념. 우리 경우 "동조 방향 정렬"로 게이트하면 참 전제에서 동조하는 정상 응답도 잡힌다 |
| Tripathi (의료 게이트 ITI) | 압력·거짓 주장 **표면** 감지기 | head별 방향 | 배경 전제엔 압력 표지가 없다. NFP와 표면상 동일 |
| Two Axes (probe 게이트 **프롬프트**) | hidden probe | 프롬프트 | 게이트는 맞다. 개입이 프롬프트라 교정 47~61%만 정확 |
| Pandey (공유 head) | 없음 (제거 실험만) | head 절제 | 동조를 줄이는 방향과 참 전제 부작용 미측정 |
| SAE feature | feature 활성 | feature 조작 | 모델별 스위트 필요 (Gemma-3·Llama-70B 없음). feature 찾기가 별도 문제 |
| AO / NLA / probe (읽기만) | — | — | 진단 도구. 개입 없음. 우리는 **2×2 서술과 통제**에 쓴다 (04) |

**우리 조합.** A = 진위 probe (라벨: 의사 검증 FPQ vs TPQ/NFP) → 게이트. C = 태도 대조 방향 (라벨: PCR +1 vs −1 응답의 시작 활성값) → 개입. A=거짓 ∧ C=따라감일 때만 C를 민다. B(P의 자격·계획)는 AO/NLA로 서술해 2×2를 채운다.

**우리 근거 (조합이 non-obvious한 이유).**
- Pandey: 진위 방향과 동조 방향의 cos 0.4~0.8. 겹치지만 같지 않다. 겹치는 만큼은 "진위를 미는" 것이고, 다른 만큼이 우리가 미는 것이다. 실험 1에서 cos(A,C)를 층별로 재서 분해 정도를 밝힌다.
- Two Axes: probe 게이트만으로 오지적 57→14%. 게이트가 일을 한다. 남은 것은 게이트 뒤의 개입이 프롬프트보다 나은가.

## 6. 기존 것을 그대로 쓰면 안 되는 이유

### 6.1 데이터
- **통제군.** 기존 게이트 방법의 양성 통제는 표면부터 다른 정상 질문(Tripathi 600문항, 게이트 발화 2~4%)이거나 같은 분포 일반 질문(CREPE)이다. 우리 통제는 **NFP** — LLM이 이미 거짓 전제라고 헛짚은 질문만 150. 표면상 구분 불가. 게이트가 여기서 안 켜져야 한다.
- **라벨.** 기존 대조쌍은 합성 템플릿(TriviaQA "I believe … Am I correct?", EHR 압력 턴)이다. 우리 A 라벨은 의사 검증 전제(585 + TPQ 116), C 라벨은 실제 응답의 PCR 판정. 배경화된 자연 질문에서 뽑은 방향이 필요하다.
- **정렬.** 전제 구간이 질문 안 어디인지(`wrong_assumption` fuzzy match)가 필요하다. 기존 방법은 전부 마지막 토큰만 읽는다.

### 6.2 구조
- **게이트와 개입의 분리.** CAST·GAPS·Tripathi는 게이트 신호와 개입 방향이 같은 개념이라 한 파이프라인이다. 우리는 두 방향을 따로 뽑고, 게이트 통과 후에만 두 번째를 쓴다. 게이트 threshold는 NFP 오탐 예산으로 잡는다 (Two Axes의 certified budget 방식).
- **위치.** A는 전제 구간·질문 끝, C는 마지막 프롬프트 토큰·응답 첫 토큰. 다른 위치의 신호를 조합한다.
- **개입 단위.** residual 방향 addition / head별 방향(Tripathi) / 공유 head 증폭(Pandey) 셋을 같은 게이트 뒤에 두고 비교. 탐지≠제어 경고 때문에 하나에 걸지 않는다.

### 6.3 목적식
- **무엇을 최적화하나.** 기존은 목표 행동 하나(PCR↑, 압력 저항↑)를 올리고 부작용은 사후 측정한다. 우리는 **PCR↑ ∧ NFP ≈ Plain**을 동시 제약으로 둔다. 강도 α와 threshold τ는 NFP를 1점도 깎지 않는 범위 안에서 PCR 최대. Well-Actually의 현실 가중(FPQ 13%)이 이유 — NFP를 깎으면 자연 분포에서 진다.
- **verbalizer 목적식 (B층에 쓸 때).** NLA의 복원 보상은 분산 큰 방향(주제·형식)을 말하게 한다(04). 진위·태도는 분산 작은 방향이라 말할 유인이 없다. 그대로 쓰면 "P의 자격"을 못 읽는다. 사전 진단에서 AO가 통제 4종을 못 넘으면, 최소 대조쌍의 **차이**를 묘사하는 대조 복원으로 바꾼다 — 단 이건 실험 1 결과를 보고 결정.

## 방법론

**TL;DR.** 환자 질문 속 거짓 전제를 모델이 내부에서 거짓으로 표상하는지(A), 어떤 태도로 답하려 하는지(C)를 prefill에서 읽어 Cancer-Myth 585를 2×2로 분해한다. A가 거짓이고 C가 따라갈 때만 C 방향을 밀어 전제를 고친다. 통제군은 표면상 구분 불가능한 NFP 150이고, 이기는 조건은 Table 1에 "PCR↑, NFP ≈ Plain"인 첫 공개 모델 행이다.

**Contribution (초안).**
1. **진단.** 진위 × 태도 2×2 분포, 7 카테고리별. "왜 못 고치나"를 H2/H3로 답한다. 부산물: 진위·동조 방향의 cos — sycophancy steering 문헌이 이웃인지의 근거.
2. **방법.** 게이트 신호(진위)와 개입 대상(태도)을 분리한 조건부 개입. 무조건 CAA, 압력 게이트(Tripathi식), probe 게이트 프롬프트(Two Axes식)와 같은 문항에서 비교.
3. **결과.** Cancer-Myth Table 1 공개 모델 블록. PCR을 올리면서 NFP를 유지하는 첫 행.
4. **통제 벤치마크.** Cancer-Myth + NFP + TPQ를 텍스트만으로는 못 푸는 verbalizer·probe 통제 벤치마크로. 4종 통제 내장.

## 정의

- **False presupposition.** 질문이 성립하려면 참이어야 하지만 거짓인, 발화되지 않은 명제. 단언과 달리 검사 대상으로 제시되지 않는다. Cancer-Myth: 의사 3명이 거짓임과 반박의 정확성을 확인한 것.
- **PCR / PCS / NFP.** 01. PCR = 명확히 짚고 바로잡은 비율(사람과 100% 일치). NFP = 거짓 전제가 없는데 LLM이 있다고 헛짚었던 150문항에서 없는 전제를 언급하지 않은 비율.
- **A / B / C.** 03. A = P의 진위 표상. B = P의 자격(사실/믿음/주장)과 응답 계획. C = 응답 태도(따라감/바로잡음/비켜감).
- **Sycophancy (이 논문에서).** A=거짓 ∧ C=따라감. H3만. H2(P가 검사 대상으로 표상되지 않음)는 sycophancy가 아니라 화용론적 누락.
- **Gate.** A probe 점수가 τ를 넘을 때만 개입이 켜지는 조건. τ는 NFP·TPQ 오탐 예산으로 정한다.
- **Faithfulness.** 셋을 구분한다.
  1. *CoT faithfulness* (Lanham 2023): 말로 낸 추론이 답을 낳은 계산을 반영하는 정도. 3절.
  2. *Explanation faithfulness*: 최종 응답이 내부 판정 A와 일치하는 정도. A=거짓인데 응답이 P를 승인하면 unfaithful. **Cancer-Myth 실패의 정의이자 2×2의 H3 칸.**
  3. *Verbalizer faithfulness*: verbalizer의 묘사가 활성값을 반영하고 입력 텍스트·자기 지식에서 온 것이 아닌 정도. 조작화: AR 왕복 mse_nrm < 0.5 (NLA, 샘플별), 활성값 없이/무작위/모르는 모델 통제와의 차이 (집단별).
- **Detection ≠ control.** 어떤 방향이 행동을 예측한다는 것과 그 방향을 밀면 행동이 바뀐다는 것은 별개. 우리는 A로 읽고 C로 민다.
