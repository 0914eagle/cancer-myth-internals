# 20. 기존 방법의 기여, 의료 적용, 표의 역할

2026-09-10 갱신. Table 1–3, NFP/TPQ, baseline 선정, Two Axes·Gated Activation Steering의 기여와 적용 가능성에 대한 후속 논의를 반영한다. 실행 명세는 [13](13_task_spec.md), 주 방법은 [19](19_method_protocol.md), 교수님 발표 원고는 [18](18_professor_presentation_script.md)와 함께 읽는다. 문서의 계획을 실행·성공한 결과로 읽지 않는다.

## 1. 두 논문에서 무엇이 새롭나

**새로운 probe나 벡터 추출 공식과, 기존 부품을 결합한 방법·분석의 기여를 구분한다.** 기존 기법을 사용했다고 논문 전체의 기여가 없는 것은 아니다. 반대로 논문의 기여를 모든 부품의 최초 제안으로 확대하지 않는다.

| 연구 | 사용한 기존 부품 | 논문이 내세우는 중심 기여 | 우리에게 의미하는 것 |
|---|---|---|---|
| Two Axes | 마지막 프롬프트 hidden state의 L2 logistic probe, 평균 차 방향, 점수 문턱, 선택적 프롬프트 | 같은 문항의 정답 여부와 답변 가능성을 분리한 분석, 표면·출력 신호 통제, 두 위험을 구분하는 선택 정책과 통계적 검증 | probe로 거짓 전제를 탐지한다는 사실이나 내부 선택 후 프롬프트를 쓴다는 구조는 선행함 |
| Gated Activation Steering | ITI 계열 head 개입, head별 logistic probe, 대조 응답 평균 차 방향 | 환각·동조에 별도 gate와 방향·강도를 배정하고, head ablation과 보존 확인을 결합한 의료 제어 구성 | 의료 내부 gate, 조건별 방향, 정상 보존, 같은 질문의 대조 응답은 이미 사용됨 |

Two Axes는 내부 답변 가능성이 읽힌다는 발견 자체를 자신의 최초 기여로 주장하지 않는다. CREPE의 탐지 및 프롬프트 라우팅은 우리의 문제와 직접 겹친다. 이 부분의 개입은 activation steering이 아니다. [Two Axes §1–3, §5–7](https://arxiv.org/html/2607.08456v1)

Gated는 학습 중 **어느 head에 개입할지 고르는 probe**와 추론 중 **어떤 입력에 개입할지 고르는 trigger**를 구분한다. head probe로 후보를 순위화하고 ablation으로 추린 뒤, 해당 head에 대조 평균 차 방향을 적용한다. 환각·동조를 별도 제어하는 결합 구성이 중심이며 logistic·평균 차 자체가 새 공식은 아니다. [Gated §III–IV](https://arxiv.org/pdf/2608.23666#page=2)

이는 원문의 제안과 사용 부품을 구분한 해석이다. 이 문서만으로 각 결합 요소의 문헌상 최초성을 입증한 것은 아니다.

## 2. Cancer-Myth에 적용할 수 있는가

두 방법 모두 적용 가능한 직접 baseline이다. 적용에 필요한 작업을 그 방법의 실패 증거로 취급하지 않는다.

| 항목 | Two Axes식 적용 | Gated식 적용 |
|---|---|---|
| 가져올 구조 | FPQ probe → 선택된 질문에 교정 프롬프트 | 입력 gate → 선택된 질문의 head steering |
| 달라지는 학습 목표 | 일반 도메인 거짓 전제에서 의료 전제로 이동 | EHR의 비지지 주장·사용자 압력에서 질문의 의학적 전제 진위·교정으로 이동 |
| 필요한 작업 | 의료 fit에서 probe 학습, dev 문턱·프롬프트 조정, 같은 판정으로 평가 | 의료 gate 재학습, 교정/비교정 쌍으로 head·방향 재추출, 모델별 강도 조정 |
| 그대로 이전할 수 없는 것 | 원 도메인의 성능·문턱이 의료에서도 성립한다는 가정 | 다른 backbone의 head·벡터, EHR 비지지 라벨과 FPQ 라벨의 동일시 |
| 아직 확인할 것 | PCR/PCS·NFP와 일반 의료 QA 보존 | 동일한 의료 전제 지표와 일반 의료 QA 보존 |

**기록에 없다는 것과 의학적으로 거짓이라는 것은 다르다.** EHR·현재 질문으로 작동하는 환각 gate도 있으므로, Gated를 ‘멀티턴 전용이라 단일턴에 적용 불가’라고 설명하지 않는다. 원 artifacts의 전이와 같은 방법을 의료 데이터에 재학습하는 adaptation도 별개다. 전자만 실패했다고 후자를 배제할 수 없다. [Gated §III–IV](https://arxiv.org/pdf/2608.23666)

Two Axes의 정상 오지적 감소는 완전한 정상 보존과 다르며, 전제를 지적한 비율은 PCR과 같은 지표가 아니다. 그 논문은 교정 내용의 NLI 평가도 수행하므로 ‘교정 정확성을 전혀 보지 않았다’고 쓰지 않는다. [Two Axes §6](https://arxiv.org/html/2607.08456v1#S6)

Gated는 정상 보존 625문항/모델, 강도 선택 중 MedQuAD 20문항의 참조 유사도, 정당한 수정 요청 평가를 이미 수행했다. 우리 MedQA·PubMedQA·Medbullets ACC 프로토콜은 별도 검증이지만 **정상 QA 보존을 처음 고려한 기여는 아니다.** [Gated §IV-C, §V-B/E](https://arxiv.org/pdf/2608.23666#page=4)

## 3. Table 1은 기존 비교의 의료 확장이다

Table 1의 10행은 BoW, 직접 전제 질문, 학습된 출력 readout, Raw 답변 확신도, P(IK), P(True), 내부 평균 차 방향, 내부 logistic probe, 전제 추출+사실 확인, CoT monitor다. Two Axes의 도메인 내 비교 8종을 모두 포함하고 명시적 검증 비교 2종을 추가한다. 원 표의 SelfAware→CREPE 전이 조건은 별도 전이 실험이므로 부록의 SelfAware/CREPE→의료 평가로 구분한다. 원 숫자를 의료 성능으로 복사하지 않는다. 텍스트+hidden 결합도 부록이다.

**현재 별도의 새 탐지 알고리즘 ‘Ours’ 행은 없다.** 내부 logistic probe를 ‘우리 시스템에 채택한 게이트’라고 표시한다. 교정 방향 C를 결합해도 탐지기가 새로 생기지는 않는다. 전체 정책은 Table 2의 평가 대상 행이다.

평가는 Cancer-Myth의 같은 held-out 문항에서 재실행한다. 원 CREPE 숫자는 참고 자료이고 의료 결과와 동일한 시험의 순위처럼 섞지 않는다. AUROC와 dev에서 고정한 문턱의 test TPR·FPR을 보고한다. 모델·분할·정보 시점·비용 차이를 기록한다. BoW는 모든 텍스트 방법의 상한이 아니다.

CoT monitor는 `원 질문 → 전제 검토 글 생성 → 별도 판정기가 원 질문+검토 글을 읽어 점수화`한다. 출력 글이 실제 내부 사고의 완전한 기록이라는 가정은 하지 않는다. 확인한 직접 선행논문에 이 비교가 없다는 사실만으로 새로운 기여가 성립하지 않으며, ‘내부 선택이 필요한가’라는 가설을 검증하는 역할이다. monitor 모델·프롬프트·점수 추출·생성 예산은 test 전에 확정할 남은 명세다.

## 4. NFP와 TPQ: 같은 질문, 다른 루브릭

Cancer-Myth NFP 150개와 Well TPQ는 같은 정상 질문이다. Cancer의 NFP는 없는 거짓 전제를 지어내 지적하지 않은 비율이다. Well은 부당한 부정·의심·회피를 단계적 점수로 평가한다. 둘 다 답변 전체의 의학적 정확도는 아니다. [Cancer NFP 판정 코드](https://github.com/Bill1235813/cancer-myth/blob/main/validate_nfp.py) · [Well Appendix E](https://arxiv.org/html/2608.06539v1#A5)

Table 2의 정상 질문 주 지표는 공식 NFP 하나다. Table 3 후보는 Well 본문 Table 1의 근거 조건별 전제 참·거짓 정확도다. 최종 응답 S5는 부록이다. 전체 0–5 분포는 부록에 둔다. NFP와 TPQ는 같은 원 정상 질문에 다른 루브릭을 적용한 것이며 공개 TPQ 파일의 148개는 150개에서 정상 few-shot 2개를 뺀 집합이다. 실제 평가 분모와 ID를 따로 기록한다. S5를 PCR/NFP로 바꾸어 읽거나 두 정상 집합을 더하지 않는다. [공개 파일 점검](21_well_rag_reproducibility.md)

## 5. Table 2의 행을 고르는 기준

선정 기준은 문제를 직접 다룬 출력 방법, 가까운 조건부 개입 방법, 평가 대상 전체 정책이다. 같은 C·K의 선택 대조군은 부록 A1에 둔다. 결과가 좋을 것으로 예상되는 비교만 고른 목록이 아니다.

| 본 표의 방법 | 절차와 선정 이유 |
|---|---|
| Plain | 직접 응답. 교정 개선과 보존 손실의 기준 |
| FP Identification | 모델이 질문의 FP 유무를 먼저 판정하고 그 결과에 따라 교정/일반 답변 생성. 직접 판별의 기존 해법 |
| Extract + FactCheck | 전제 추출 → 각 전제 사실 확인 → 결과에 따라 답변 생성. 명시적 검증의 기존 해법 |
| GEPA (FPQ+TPQ) | 개발 FPQ/정상 질문 점수로 프롬프트를 최적화. 기반 LLM 가중치 학습이 아님 |
| 균형 전제 검토 CoT prompting | 모든 질문에 전제 검토·필요시 교정·정상 전제 존중을 지시하고 답변 생성. 우리가 구성하는 직접 prompting 대조군 |
| CAST (의료 adaptation) | 원 조건 벡터·유사도 문턱과 행동 벡터 방식에 의료 대조 데이터를 사용. 새 logistic gate와 혼동하지 않음 |
| Gated head steering (의료 adaptation) | Gated의 head 선택·개입 방식을 의료 전제 목표로 재학습. 가까운 직접 비교이며 구현 완료는 아님 |
| Hidden gate + FP prompt | 의료 probe가 고른 질문에만 교정 지시. Two Axes식 정책이며 선택 후 FP 판별을 다시 하지 않음 |
| Hidden gate + C steering | 같은 종류의 probe와 교정 응답 대조 residual 방향을 결합한 현재 평가 대상 정책 |

Unconditional C는 부록 Table A1의 U행으로 이동한다. R/T/Q/H의 C도 동일하게 고정한다. Table 2의 두 Hidden 행은 동일 gate를 공유하며, 그 밖의 baseline은 공통 개발 규칙으로 조정한다. CAST·Gated adaptation에는 원 방법에서 유지/변경한 부분과 미구현 부분을 공개하며, 구현되지 않은 행의 성능을 추정해 채우지 않는다. 해당 비교 없이 그 방법에 대한 우위를 주장하지 않는다.

**Table 2의 동일 선택 비교.** Hidden gate + FP prompt와 Hidden gate + C steering은 probe·문턱·문항별 gate mask를 정확히 공유한다. 현재 주 정책의 probe와 τ_policy·C를 내부 dev에서 선택한 뒤 FP prompt 행에도 그 gate를 적용한다. 프롬프트 버전은 dev에서 정하되 gate를 다시 고르지 않는다. 선택되지 않은 질문에는 같은 Plain 응답을 사용하고, 선택된 질문에서만 교정 연산을 바꾼다. 따라서 이 두 행은 같은 대상에서의 교정 방식 비교이며, 각 교정 방식에 독립적으로 최적화된 gate끼리의 비교가 아니다. 프롬프트에 맞춰 gate까지 별도 최적화한 Two Axes식 정책은 필요하면 부록에 구분해 보고한다. 이 두 행의 paired ΔPCR·ΔPCS·ΔNFP와 95% CI를 함께 해석하고 별도 Table 3에서 같은 결과를 반복하지 않는다.

## 6. 부록 A1의 개입률과 새 Table 3의 역할

`개입률 = 교정 분기를 실행한 질문 수 / 전체 평가 질문 수 × 100`이다. 답변이 실제로 바뀐 비율이나 교정 성공률이 아니다. 모니터는 모든 질문을 검사할 수 있지만 교정은 일부에만 적용된다.

설명용 예: FPQ 20개·정상 80개 중 FPQ 16개·정상 4개에 개입하면 개입률 20%, TPR 80%, FPR 5%다. 실제 실험 결과나 목표 비율이 아니다.

부록 Table A1은 같은 C·강도·층·위치에서 R/T/Q/H의 개입 수 K를 맞춰 선택 효과를 비교한다. U는 전체에 개입한다. 개입률은 성능 지표가 아니라 통제 확인 열이다. 동일 대상의 prompt/C 비교는 Table 2의 두 Hidden 행에 통합했으므로 별도 Table 3(b)로 반복하지 않는다. A1의 상위 K는 Table 2의 개별 질문 고정 문턱과 다른 배치 진단이다.

**현재 위치와 확정 범위.** 가져올 선행표는 Well-Actually Table 1로 확정한다. 이 표는 교수님 발표의 기존 연구 근거로 사용할 수 있다. 아래의 우리 Table 3 및 추가 probe 행은 사실 확인 진단을 독립 연구 질문으로 채택할 경우의 후보이며 본 실험으로 확정한 것은 아니다. 기존 결과를 인용하는 것만으로 우리 실험 결과표가 되지 않는다. 현재 질문 gate의 검증이 목적이면 Table 1의 질문 단위 탐지 비교에 RAG 기반 전제 추출·검증을 추가하는 방안도 가능하며, gold 전제를 받는 원 Table 1의 숫자와 직접 섞지 않는다.

Well Table 1은 gold 전제의 사실 확인 정확도이고 Table 8은 최종 응답 점수다. RAG가 포함됐다는 이유로 두 표를 바꾸어 가져오지 않는다. 코드·TPQ 문서의 공개 여부 감사는 유지하며 사실 확인 실행 경로는 [21](21_well_rag_reproducibility.md)에 수정했다.

## 7. 우리 방법을 정한 근거와 기여 범위

| 선택 | 근거 | 주장할 수 없는 것 |
|---|---|---|
| 마지막 프롬프트 표상 | 답변 전 판단이 가능하고 기존 readout과 비교 가능 | 최적 위치를 발견했다 |
| 표준화+L2 logistic | 적은 데이터에서 시작하는 단순한 기존 분류기 | 새 내부 탐지 알고리즘이다 |
| gate와 C 분리 | 판별 목표와 행동 제어 목표를 나누는 기존 조건부 설계 | 분리 최초다 |
| 같은 질문의 교정/비교정 응답 | 질문 차이의 교란을 줄이고 현 paired pipeline 사용 가능 | 순수 교정 방향이나 새로운 대조 학습법이다 |
| 첫 32토큰·층 후보·강도 grid·dev FPR 5% | 실행 가능한 초기 탐색·운영 조건 | 선행연구가 최적성을 입증한 값이다 |

현재 기여 후보는 **의료 전제에서의 판별·선택 분석, 동일 대상의 교정 연산 비교, 가까운 기존 방법 대비 교정과 성능 보존의 실증**이다. Table 1의 재현이나 데이터 변경만으로 독립적인 강한 알고리즘 기여를 주장하지 않는다. 가설을 먼저 세우고 검증하되, 기존 방법이 실패한다는 사실을 미리 만들어 동기로 삼지 않는다.

### 교수님께 전달할 문장

> 탐지 비교는 Two Axes의 기존 표를 의료 질문에서 재평가하고 명시적 전제 검증·CoT 비교를 추가하겠습니다. 최종 교정 표에는 기존 prompting, Two Axes식 정책, 의료 전제로 재학습한 CAST·Gated 방식과 현재 정책을 함께 넣겠습니다. 선형 probe나 steering 벡터 추출 자체의 최초 제안이 아니라, 어떤 선택과 개입이 정확한 교정과 정상 성능 보존에 기여하는지 검증하는 계획입니다. 추가 방법론 기여를 주장하려면 구체적 변경과 그 변경의 효과를 별도로 보여야 합니다.
