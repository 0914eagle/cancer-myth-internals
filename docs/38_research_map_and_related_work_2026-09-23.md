# 연구 정리: 확인한 현상, 남은 가설, 다음 검증, 관련 연구

2026-09-23. [발표 원고 37](37_advisor_presentation_2026-09-23.md)의 실험들을 연구 질문별로 다시 묶은 문서다. **새 모델 추론·학습·채점은 실행하지 않았다.** 수치는 발표 원고의 동결 자료를 기준으로 하며, 기존 CSV의 추가 교차 집계 하나를 별도로 보존했다. 문헌 조사는 아래 연결한 1차 자료를 대상으로 한 관련 연구 조사이며, 전체 문헌의 체계적 전수 조사는 아니다.

## 1. 고정할 목표와 현재 위치

목표는 **질문 하나에서 거짓 전제를 탐지하고, 필요한 질문에만 교정을 적용해 정상 질문을 보존하는 것**이다. 판별기는 질문에서 자동으로 계산할 수 있는 정보만 사용해야 한다. 데이터셋 주석·정답 라벨·사람이 지정한 전제 위치가 있어야 작동하는 조건은 진단용이다.

최종 평가 틀은 바뀌지 않는다.

| 논문 표 | 답할 질문 |
|---|---|
| 1. 탐지 | FPQ/NFP를 얼마나 잘 구분하는가? AUROC와 정해진 오탐 수준의 탐지율은? |
| 2. 최종 답변 | 그 결정으로 교정 답변과 Plain을 선택하면 FPQ 교정과 NFP 보존이 어떻게 변하는가? |
| 3. 전이 | Cancer-Myth에서 정한 방법을 다른 데이터에서 재조정 없이 적용해도 작동하는가? |

현재는 baseline과 여러 진단을 확보했지만, **그 진단을 모두 설명하는 원인이나 기존 방법을 넘어서는 새 gate를 확정한 단계는 아니다.** 진단 실험은 세 표를 대체하는 것이 아니라, 어떤 방법을 만들지와 그 방법의 주장을 뒷받침해야 한다.

설명이 흔들렸던 이유는 다음 세 결과를 같은 의미로 말했기 때문이다.

| 구분 | 실제 측정 | 이것만으로 확정할 수 없는 것 |
|---|---|---|
| 내부 표현의 판독 | probe가 정답 FPQ/NFP 라벨을 예측 | 모델이 전제의 거짓을 의미적으로 판단했다는 것 |
| 명시적 판단 행동 | Yes/No, True/False, A/B 과제에 응답 | 별도 지시가 없는 Plain 생성에서도 같은 판단을 했다는 것 |
| 최종 교정 행동 | 자유 답변의 Well 점수 | 실패 원인이 지식 부재인지, 전제 파악인지, 응답 성향인지 |

이 구분은 측정의 구분이다. 모델 내부가 반드시 세 개의 순차 모듈로 구성돼 있다는 주장은 아니다.

## 2. 무엇을 했고 무엇을 얻었는가

### 2.1 문제와 baseline: 선택적 교정의 필요성을 확인했다

아래는 Well **0–5점 중 4점 이상**의 비율이다. NFP ≥4는 평가 기준상 답변 보존이며, 질문의 모든 문장이 의학적으로 참이라는 별도 인증은 아니다.

| 모델 | Plain FPQ / NFP | 교정 조건 FPQ / NFP |
|---|---:|---:|
| Qwen2.5-7B-Instruct | 2.4% / 100.0% | 무조건 교정 56.9% / 21.5% |
| Sonnet | 60.7% / 67.1% | 균형 지시 77.5% / 38.9% |
| Luna | 44.8% / 89.3% | 균형 지시 74.6% / 55.7% |

얻은 것은 **현재 모델·프롬프트·채점 조건에서 교정 증가와 정상 질문 손실이 함께 나타난다**는 결과다. 모든 모델·프롬프트에서 해결 불가능하다는 결론은 아니다. Qwen의 균형 지시 행은 아직 없으므로, 새 gate를 평가할 때 추가할 중요한 baseline이다. 분모·모델 실행 설정·판정 조건은 [37 §2](37_advisor_presentation_2026-09-23.md#2-baseline-재현평가--프론티어-모델에서도-기존-상충을-확인했습니다)에 있다.

### 2.2 탐지·전이·내부 분석: 분류 신호는 있지만 그 의미와 활용은 미확정이다

| 완료한 확인 | 대표 결과 | 얻은 것 | 아직 모르는 것 |
|---|---|---|---|
| 원 FPQ/NFP 분류 | Text AUROC 0.755, hidden 0.693; style 0.687, masked 0.702 | 두 집단은 일부 구분 가능하고 표면 단서도 기여할 수 있음 | hidden이 읽는 신호 중 전제의 진위가 얼마나 차지하는가 |
| 기존 판별기에 전제 수정 질문 적용 | 원 FPQ/AI 수정 질문에서 hidden 0.507; 거짓 의역/수정 질문에서 0.525 | 원 집단 분류 성능이 이 대조에 그대로 이어지지 않음 | 수정 자료의 품질 한계를 제거해도 같은가 |
| 수정 구간에서 별도 probe 학습 | 원 FPQ/수정 구간 0.972; 거짓 의역/수정 구간 0.966 | 해당 구간의 두 입력 조건은 잘 구분됨 | 진위, 부정 표현, 단정성, 편집 흔적 중 무엇을 읽는가 |
| 구간 probe로 원 질문 전체 토큰 검사 | S_max 0.502, 상위 5개 평균 0.469; 별도 질문 평균 probe 0.758 | 높은 구간 분류 성능이 자동 위치 탐색 gate로 이어지지 않음 | 위치·학습 대비·집계 방식 중 무엇이 실패에 기여했는가 |
| §9 구간 patching | L13 개입의 L28 판독 이동 중앙값 약 0.30; 평균 P(Yes)는 0.10→0.09 | 개입에 따른 표현 변화와 Yes/No 출력 변화를 함께 측정함 | 그 개입이 진위 정보를 선택적으로 바꿨는가, 자유 답변 교정을 개선하는가 |
| 데이터 간 전이 | CREPE 내 hidden 0.766; CREPE→Cancer-Myth 0.459; 반대 0.490 | 현재 probe의 전이가 약함 | 실패 원인이 문체·주제·과제·라벨 구성 중 무엇인가 |

각 행은 동일 프로토콜의 직접 경쟁 결과가 아니다. 원문 단위 분할, 탐색적 층 선택, 대조 자료 분모 등의 세부 사항은 [37 §4–9](37_advisor_presentation_2026-09-23.md)와 [동결 표](reviews/advisor_presentation_2026-09-23/README.md)를 따른다. 특히 AI 수정 질문은 독립적인 임상 전문가 검증이 완료된 참 대조로 취급하지 않는다. [35번 감사 기록](35_truth_form_audit_and_next_steps.md)에서도 의미 보존 문제를 확인했다.

**이미 한 일을 다시 제안하지 않기 위한 확인:** 원래 hidden gate의 입력은 별도 Yes/No 지시가 없는 **Plain 질문의 prefill 마지막 토큰**이다. [코드의 `features`](../src/baseline_generation.py)는 질문을 인코딩하고 마지막 토큰 표현을 추출한다. 저장된 routing CSV에서 hidden gate가 선택한 FPQ 126개 중 **119개는 Plain Well <4**, 7개는 ≥4였다. [재집계와 문항 ID](reviews/research_map_2026-09-23/hidden_plain_overlap.json).

따라서 **“Plain 내부에서 분류 가능한데 답변은 교정에 실패한다”는 관찰 자체는 이미 있다.** 새로 할 일은 그 존재를 다시 확인하는 것이 아니다. 그 신호가 진위를 읽는지, 모델의 교정에 실제로 이용될 수 있는지를 검증해야 한다. Well <4는 충분한 교정에 실패했다는 뜻이며, 119개 모두가 아무 반박 없이 순응했다는 뜻은 아니다.

또한 §9의 마지막 위치 전용 probe는 **원 FPQ/수정 질문 라벨로 학습**했다. 모델의 Yes/No 정답을 학습한 probe가 아니다. §9는 명시적 판단 프롬프트에서의 개입이며, Plain 자유 답변에 대한 교정 효용 시험도 아니다.

### 2.3 명시적 판단·추출 진단: 판단 조건을 바꾸면 성능이 달라진다

| 완료한 확인 | 결과 | 얻은 것 | 남은 검증 |
|---|---|---|---|
| 통념 문장과 교정문 중 올바른 설명 선택 | 양방향 선택지 순서 모두 성공 526/580 = 90.7% | 제공된 두 설명을 비교해 고르는 능력은 높음 | 정답 후보 없이 원 질문에서 오류를 스스로 찾는 능력과는 별개 |
| 위 526개와 원 질문 직접 탐지 연결 | 직접 탐지 성공 41, 실패 485 | 설명 선택 성공과 원 질문 오류 탐지는 일치하지 않음 | 입력 정보와 과제 형식이 함께 달라져 어느 요소가 원인인지 미확정 |
| 직접 Yes/No → 검토 후 Yes/No | FPQ 7.4%→31.7%, NFP 오탐 11.4%→17.4% | 검토로 탐지 결과가 바뀌지만 오탐도 증가 | 같은 오탐률에서도 개선되는가 |
| Qwen 추출 → 주석 전제, 공통 723개 | FPQ 18.7%→89.6%, NFP 오탐 13.7%→47.3%; AUROC 0.5433→0.8737 | 검증 대상을 바꾸면 순위 성능과 고정 문턱의 판단이 크게 달라짐 | 주석의 의미 변화, verifier 오류, 문턱 문제 각각의 기여 |
| Qwen 추출 → Sonnet 보완, 공통 725개 | FPQ 18.7%→34.5%, NFP 오탐 13.5%→16.2%; AUROC 0.5421→0.6278 | 라벨 없이 목록을 보완하는 자동 절차도 탐지를 바꿈 | 진위 변화에 반응하는지, 기존 답변에 연결한 효용이 있는지 |

여기서 verifier는 모두 Qwen이다. Sonnet은 질문과 기존 추출 목록을 보고 목록을 보완했고, 질문 라벨이나 참조 교정문은 받지 않았다. 주석 조건도 Qwen에게 “이 질문은 NFP이니 참으로 답하라”를 준 것이 아니다. **원 질문과 검증할 전제 문장**을 주었다.

질문 점수는 `1 − min P(True)`이고, 전제 하나라도 `P(True)<0.5`이면 gate를 켰다. 따라서 탐지율 증가만으로 개선이라고 할 수 없다. 목록의 의미와 범위, 전제별 판정, 문항별 집계와 임계값을 나눠 봐야 한다. **AUROC 0.8737과 오탐 47.3%는 모순이 아니다.** 순위가 잘 맞아도 특정 문턱의 오탐은 높을 수 있다. 그러나 문턱만 바꾸면 문제가 해결된다는 뜻도 아니다.

NFP 질문 라벨과 후속 Well TPQ 전제 주석은 같은 검수 과정의 산출물로 합쳐 취급하지 않는다. 주석 제공 성공을 “추출 성공”, 주석 조건 오탐을 곧바로 “NFP 라벨 오류”라고 부르지 않는다. 원 질문 맥락은 verifier에 남아 있으므로, “맥락을 아예 제거해서 실패했다”도 실행과 다르다.

### 2.4 실제 방법으로 연결한 결과와 아직 연결하지 않은 결과

| 고정된 기존 답변을 선택하는 정책 | FPQ Well ≥4 | NFP Well ≥4 |
|---|---:|---:|
| Plain | 2.4% | 100.0% |
| Text gate → 무조건 교정/Plain | 19.8% | 94.6% |
| Hidden gate → 무조건 교정/Plain | 15.5% | 96.0% |
| Label oracle → 무조건 교정/Plain | 57.0% | 100.0% |

공통 FPQ 582/NFP 149개다. Oracle은 이 고정 교정 도구와 기존 답변을 사용한 참고점이며, 가능한 모든 교정 방법의 상한이 아니다. **Sonnet 보완 gate의 34.5% 탐지를 이 표의 최종 교정 성공률과 혼동하지 않는다.** 그 gate로 저장된 답변을 선택한 표 2 행은 아직 이 동결 발표 자료에 없다. 기존 Extract + Verify의 최종 답변 baseline과도 프롬프트·선택 구조가 다르다.

SFT도 실행했다. 쌍둥이·균형·FP-only 학습의 FPQ ≥4 / NFP S5는 각각 35.5/16.1, 29.1/38.3, 52.1/1.3%였다. 현재 설정에서 정상 질문 보존은 부족했다. 다만 이 학습에는 원 NFP 학습 예제가 없고 생성된 수정 질문·답변을 썼으므로, 모든 학습 기반 해결법을 배제할 근거는 아니다. [37 §11의 입력·출력 구성](37_advisor_presentation_2026-09-23.md#11-sft도-탐색했지만-선택적-교정-방법으로-확정하지-않았습니다).

## 3. 비슷한 문제에서 다른 연구는 무엇을 했는가

### 3.1 관련 지식이 있어도 거짓 전제 질문에 순응하는 경우

[FalseQA: Won’t Get Fooled Again (ACL 2023)](https://aclanthology.org/2023.acl-long.309.pdf)는 거짓 전제 질문에 잘못 답하면서, 전제를 직접 물으면 판단할 수 있는 사례를 제시했다. 사람이 작성한 FPQ와 대응 TPQ를 사용해 탐지·설명 생성 학습을 했고, 정상 QA 데이터를 함께 복습하는 설정도 평가했다.

우리에게 주는 방향은 **지식 질문과 원 질문의 수행 차이를 구분하고, 학습할 때 정상 질문까지 함께 보존해야 한다**는 것이다. 이미 한 A/B 실험은 이 계열의 근거지만 정답 교정문까지 선택지로 준 더 강한 도움 조건이다. FalseQA 결과나 우리의 A/B 결과만으로 Plain 내부의 판단이 억제됐다고 결론낼 수 없다. FalseQA를 설계용으로 사용한다면 그 부분을 이후 미사용 전이 test라고 부르지 않아야 한다.

[Well Actually](https://arxiv.org/html/2608.06539v1)는 추출·검증·답변 구조와 주석 전제 조건의 fact-checking을 이미 다룬다. §3.2에서는 Qwen이 거짓 전제를 잘 거부하는 것과 정상 전제를 참으로 인정하는 것 사이의 큰 차이도 보고한다. **추출→검증 구조나 “주석을 주면 FP 탐지가 높지만 정상 전제도 거부한다”는 관찰만으로 새 기여를 주장할 수 없다.** 우리의 문항 단위 gate 비율과 논문의 전제 단위 정확도는 직접 비교하지 않는다.

### 3.2 내부에서 정오답 정보가 읽혀도 실제 출력은 틀리는 경우

[LLMs Know More Than They Show (arXiv v2, 2024; ICLR 2025 발표)](https://arxiv.org/html/2410.02707v2)는 정오답 관련 정보가 특정 답변 토큰에 더 잘 나타나고, probe의 과제 간 전이가 제한됨을 보고했다. 여러 후보 답변을 생성한 뒤 내부 probe로 선택하면, 모델이 자주 틀리는 질문에서도 개선되는 경우를 보였다.

이것은 사용자가 제안한 **“읽을 수 있는 정보와 출력 행동이 다를 수 있다”**는 문제의 직접적인 선행 사례다. 그러나 주된 강한 신호는 **생성된 답변의 토큰**에서 읽는다. 우리의 목표인 **최종 답변 전 질문 gate**에서 같은 신호가 이용 가능하다는 보장은 없다. 답변 생성 후에만 얻는 신호를 쓰게 된다면, 그것은 비용과 평가를 별도로 잡아야 하는 답변 검증·재선택 방법이다.

### 3.3 사용자의 믿음에 맞추는 성향과 사실 판단이 충돌하는 경우

[Towards Understanding Sycophancy in Language Models](https://arxiv.org/html/2310.13548v2)는 사용자 관점에 맞춘 응답과 사실성 사이의 충돌을 조사하고, 사람 및 선호 모델의 평가가 일부 조건에서 그 성향을 선호할 수 있음을 보였다.

우리의 “요청에 응답하려는 성향이 교정을 방해한다”는 가설을 고려할 근거는 있다. 그러나 그 논문이 Qwen의 Cancer-Myth 실패 원인을 증명하지는 않는다. 확인하려면 목표 주장과 진위를 유지한 채 **사용자 동의 압력**을 바꾸는 행동 대조가 필요하고, 그것도 먼저 행동 수준의 원인이다. 내부에서 이미 완성된 진위 판단이 덮였다는 강한 주장에는 추가 근거가 필요하다.

### 3.4 내부 방향을 찾아 실제 출력을 바꾼 경우

[Inference-Time Intervention (NeurIPS 2023)](https://arxiv.org/html/2306.03341v2)는 attention head의 진실성 관련 방향을 이용해 출력을 개입했다. TruthfulQA의 Alpaca 조건에서 **True×Informative**를 32.5%에서 65.1%로 높인 결과를 보고했지만, 개입 강도에 따른 유용성 손실도 다뤘다. 이 수치는 거짓 전제 탐지 AUROC가 아니다.

[Contrastive Activation Addition (ACL 2024)](https://aclanthology.org/2024.acl-long.828/)은 대비되는 행동 예시의 평균 활성 차이를 추론 중 더해 Llama 2 Chat의 객관식·자유 응답 행동을 조절했다.

우리도 방향·head·patching 탐색을 했으므로 **내부를 조작해 보자 자체는 새로운 다음 실험이 아니다.** 여기서 가져올 기준은 목표 행동 개선과 부작용을 함께 평가하는 것이다. 거짓 질문의 교정만 늘고 참 질문도 더 반박한다면, 진위에 따른 선택적 활용보다 반박 성향의 이동으로 설명될 수 있다.

### 3.5 높은 probe 성능이 정말 원하는 정보를 뜻하는지 검사한 연구

[Discovering Latent Knowledge in Language Models Without Supervision (ICLR 2023)](https://arxiv.org/abs/2212.03827)는 상반되는 답변의 표현에 논리적 일관성을 적용해 지식을 읽는 CCS를 제안했다. 반면 [Challenges with Unsupervised LLM Knowledge Discovery](https://arxiv.org/abs/2312.10029)는 그러한 목적함수를 진위와 무관한 특징도 만족시킬 수 있음을 지적했다. 따라서 일관성이나 분류 성능만으로 ‘진위 방향’이라고 명명하지 않는다.

[Designing and Interpreting Probes with Control Tasks (EMNLP 2019)](https://aclanthology.org/D19-1275/)는 probe의 성능과 통제 과제를 함께 보도록 했다. [Amnesic Probing (TACL 2021)](https://aclanthology.org/2021.tacl-1.10/)은 표현에서 정보를 제거하고 행동 변화를 보는 접근으로 **읽을 수 있음과 실제 사용**을 구분했다. 우리에게는 의미가 검증된 대조, 어휘 대조, 무작위 방향과 같은 개입 통제가 중요하다는 방법론적 참고다. 제거·개입 자체가 다른 정보도 손상시킬 수 있어 결과를 곧바로 단일 원인으로 해석하지 않는다.

## 4. 지금 열려 있는 설명은 무엇인가

아래는 경쟁하거나 함께 작동할 수 있는 **가설**이다. 확정된 실패 원인 목록이 아니다.

| 가설 | 현재 근거 | 아직 필요한 판별 |
|---|---|---|
| 질문에서 검증할 내용을 제대로 포착하지 못한다 | 전제 목록 교체에 따라 탐지와 AUROC가 달라짐 | 빠진 실제 전제 보완 덕분인지, 없는 주장·일반화를 새로 넣은 효과인지 원문 대조 |
| 내용을 포착해도 verifier가 거짓·알 수 없음·개인 정황을 혼동한다 | 주석 조건에서도 NFP 오탐이 큼 | 추출문이 원문에 충실한 사례만 따로 봐도 오판이 남는지 |
| 판단 과제가 관련 계산을 새로 유도한다 | 직접 질문·검토·A/B 사이의 수행 차이 | 입력 정보 차이를 통제한 뒤에도 과제별 차이가 남는지 |
| Plain에도 진위 관련 정보가 있지만 교정에 충분히 활용되지 않는다 | Plain hidden의 분류와 최종 답변 사이 불일치; 관련 선행 연구 | 그 신호가 실제 진위에 선택적인지, 그 신호에 개입하면 정상 질문 보존과 교정이 함께 개선되는지 |
| 점수 집계·문턱이 운영 성능을 악화시킨다 | 동일 0.5 문턱을 서로 다른 전제 입력에 적용 | 개발 자료에서 정한 동일 오탐 수준으로 별도 평가해도 차이가 남는지 |

“개인 정황은 검증하지 않는다”는 규칙은 아직 해결책이 아니다. 개인 서술에도 거짓 일반화가 포함될 수 있고, 일반적인 문장도 질문의 핵심 전제가 아닐 수 있다. 먼저 실제 오류 사례에 그 설명이 얼마나 적용되는지 확인해야 한다.

## 5. 무엇을 더 검증할 것인가: 결과가 다음 결정을 바꾸는 순서

### 5.1 우선 기존 결과에서 두 가지를 끝낸다

**첫째, 후보 gate의 최종 효용을 계산한다.** Sonnet 보완 gate의 저장된 결정을 이용해 공통 문항에서 기존 무조건 교정 답변 또는 Plain을 선택한다. Text·hidden·동일 개입 수의 무작위 선택·label oracle을 같은 분모로 비교한다. 모델 호출 없이 계산할 수 있다. 모든 문항에 두 답변과 유효 점수가 있는지 먼저 검사하고, 교집합과 제외 ID를 보고한다.

이 계산으로 “탐지 34.5%가 실제 교정 증가로 이어지는가, NFP 손실은 얼마인가”를 답한다. 이겨도 최종 test 우월성이 확정되는 것은 아니고, 져도 추출 개선 전체가 불가능하다는 뜻은 아니다. **현재 후보를 더 개발할 실용적 근거**를 판단한다.

**둘째, 추출·주석·verifier의 오류를 같은 문항에서 연결한다.** Qwen/Sonnet/주석의 전제와 원 질문, 전제별 P(True), 질문 gate 결정을 나란히 놓는다. 우선 NFP에서 새로 오탐이 된 문항과 FPQ에서 새로 탐지된 문항을 확인하고, 손실·유지 사례도 대조로 포함한다.

표시할 항목은 원문에 없는 주장 추가, 개인 정황의 일반화, 실제 전제 누락, 요청을 단정으로 변환, 충실한 전제에 대한 verifier 오판, 판정 불가다. AI 검토는 초안 분류로 표시하고, 의학적 진위나 애매한 전제 귀속을 확정하는 표본에는 독립적인 사람 검증이 필요하다. 전체 원인 비율을 주장하려면 표본 선택과 분모를 명시해야 한다.

같은 오탐률 비교도 필요하다. 이미 전체 결과를 본 자료를 새 독립 test처럼 다루지 않고, 문턱 선택 자료와 평가 자료를 분리한다. 작은 NFP 표본에서는 비율뿐 아니라 변화 문항 수와 paired 불확실성을 보고한다. 특정 %p 아래는 무조건 검정 불가능하다는 고정 규칙을 두지 않는다.

### 5.2 내부 가설은 ‘진위에 대한 선택성’부터 확인한다

다시 모든 층·토큰을 훑기 전에, 기존 대조 자료에서 **목표 전제만 바뀌었는지 확인할 수 있는 작은 대조 집합**을 만든다. 원문의 환자 정황·요청·나머지 전제를 보존하고, 참/거짓 각각에 의미를 유지한 의역을 포함한다. 의학적 참·거짓과 의미 보존을 독립적으로 검증하지 못한 문항은 핵심 결론에서 제외한다. 전부 검증한 것처럼 AI 감사 결과를 확대하지 않는다.

먼저 기존 probe를 고정해 적용한다. 목표 전제의 진위가 바뀔 때는 점수가 변하고, 진위를 유지한 의역에서는 안정적인지 본다. 주제·길이·부정 표현만으로 되는 text 대조와 원문 단위 분할도 유지한다. 새로운 층·방향을 고른다면 선택용 자료와 최종 평가 자료를 나눈다.

- 선택성이 확인되지 않으면: 이 probe로 ‘이미 알고 있었는데 억제됐다’를 주장하지 않는다. 해당 내부 신호의 해석을 보류한다.
- 선택성이 확인되고 Plain이 실패하면: 진위 관련 판독과 교정 행동의 불일치라는 근거가 강해진다. 아직 특정 억제 회로가 증명된 것은 아니다.
- 그다음에만: 같은 자유 답변 생성에서 후보 신호 개입과 무작위·무개입 대조를 비교한다. FPQ 교정뿐 아니라 참 대조와 원 NFP의 불필요한 반박도 함께 평가한다. §9의 Yes/No 변화만으로 이 검증을 대체하지 않는다.

### 5.3 검증 결과에 따라 방법 형태를 선택한다

| 다음 검증의 결과 | 개발할 근거가 생기는 방향 | 반드시 추가로 확인할 것 |
|---|---|---|
| 원문에 충실한 전제 선택이 오탐을 줄이면서 탐지를 유지 | 추출·선택·검증 gate | 단순 Extract+Verify보다 나은 이유, 비용, 실제 교정 |
| 충실한 추출에도 진위 판정이 계속 실패 | verifier 개선, 불확실성 처리, 필요시 근거 사용 | 단순히 판단 보류가 늘어난 것인지, 탐지 손실과 비용 |
| 답변 전에 진위에 선택적인 hidden 신호를 얻음 | 내부 gate 또는 그 신호의 활용 | 문체 대조, 고정 문턱, 정상 질문 보존, 전이 |
| 신호 개입이 선택적 교정을 실제 개선 | 내부 개입 기반 교정; gate와 별개 부품일 수도 있음 | 전역적인 반박 성향 변화와 구분, 자유 답변 평가 |
| 신호가 답변 생성 후에만 유용 | 답변 검증·재선택 | 답변 전 gate와 다른 계산 비용·방법 범위 |
| 검증된 학습 대조와 정상 질문을 함께 넣어 개선 | 감독 학습 기반 gate/응답 모델 | 기존 SFT와 데이터 구성 차이, 과적합·전이 |

어느 방향도 현재 유일한 길이라고 단정하지 않는다. 다만 동시에 모두 구현하지 않는다. **저장 결과의 효용·오류 분석을 먼저 끝내고, 결과가 지지하는 방법을 좁힌다.** 내부 가설에 대한 관심은 유지하되, 이미 한 위치 탐색과 불일치 관찰의 반복으로 진행하지 않는다.

방법을 정한 뒤 Cancer-Myth에서 선택한 프롬프트·probe·문턱을 고정해 CREPE/FalseQA에 적용한다. 전이 데이터의 라벨을 보고 다시 맞춘 결과는 무조정 전이와 분리한다. 각 데이터셋의 정상 질문 및 전제 유형 차이는 분석하되, 전이 실패의 원인을 자료 구성 하나로 미리 확정하지 않는다.

## 6. 발표에서 연결할 설명

> 저희는 먼저 Cancer-Myth에서 교정 지시가 거짓 전제 교정을 높이지만 정상 질문을 손상시키는 상충을 재현했습니다. 기존 text와 hidden gate를 연결하면 일부 개선됐지만 많은 오류 질문을 놓쳤고, 다른 데이터로의 전이도 약했습니다.
>
> 그래서 판별 신호가 무엇을 읽는지 분석했습니다. 원 질문 집단을 구분하는 것과 같은 질문의 전제 변화를 구분하는 것은 달랐고, 특정 구간의 높은 성능도 자동 gate로 바로 이어지지 않았습니다. 내부 개입도 시도했지만, 이를 진위 판단의 활용이나 자유 답변 교정 개선으로 확정할 근거는 아직 부족합니다.
>
> 별도의 행동 진단에서는 설명을 비교해 고르는 것, 원 질문의 오류를 직접 찾는 것, 분리된 전제를 검증하는 것의 성능이 달랐습니다. 검증할 전제를 바꾸면 탐지는 개선됐지만 오탐도 늘었습니다. 따라서 현재 결론은 ‘모델이 전혀 모른다’나 ‘이미 아는데 억제된다’가 아니라, 판단에 필요한 조건과 실제 응답 사이에 차이가 있고 그 원인을 더 분리해야 한다는 것입니다.
>
> 다음은 저장된 후보 gate의 최종 교정 효용과 오탐 원인을 먼저 확인하는 것입니다. 내부 방향은 진위만 바꾼 검증된 대조에 실제로 반응하는지 확인한 뒤 선택적 개입으로 연결하겠습니다. 그 결과에 따라 방법을 좁히고, 처음 정한 탐지·최종 답변·전이의 세 표로 평가하겠습니다.
