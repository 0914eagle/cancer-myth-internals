# 03. 가설 지도 — 같은 출력, 다른 내부 원인

> **2026-09-08 후속 정리.** 아래 H1–H6은 초기 원인 가설이다. 논문 검증 가설 RH1–RH3와 Task 1–3은 [09](09_research_proposal.md)를 따른다. probe/AO/NLA 결과만으로 지식 보유나 원인 상태를 확정하지 않으며, CoT 배제도 결론으로 삼지 않는다.

## 현상

> 질문 Q 안에 전제 P가 깔려 있고 P는 거짓 → 모델은 Q의 겉 질문에 답하고 P를 그대로 둔다.

이 **같은 출력**을 만드는 내부 원인이 하나가 아니고, 원인마다 처방이 다르다. 이걸 가르는 것이 실험 1의 일이다.

## 여섯 가설

| | 내부 상태 | 이게 원인이면 처방 | 지금까지 증거 |
|---|---|---|---|
| **H1 모른다** | P가 거짓이라는 지식 자체가 없음 | 검색·지식 주입 | Well-Actually Table 1의 적중 96–100%는 오탐 67–85%와 같이 봐야 한다. 언어 판정은 지식과 기준을 못 가른다. **미결.** 실험 1의 내부 readout이 첫 측정이되, 그것도 readout 수준의 결과다 |
| **H2 못 봤다** | P가 단언이 아닌 전제라 진위 판정 회로가 안 돔. P는 표상되지만 "검사할 주장"으로 취급 안 됨 | P를 전경으로 — 그런데 이게 H6을 부름 | 언어학적 presupposition. 직접 검증한 연구 없음 |
| **H3 알지만 따라간다** | P를 거짓으로 표상하면서 출력은 동조 (Contextual-Truth *performative*) | 내부 신호로 게이트·개입 — **우리 방법이 통하는 경우** | Contextual-Truth 22.7% / MedMisBench trace 81–98% vs 응답 7–90% |
| **H4 말하면서 뒤집힌다** | prefill 땐 거짓, 생성 중 P를 되뇌며 참으로 이동 (Contextual-Truth *representational*) | prefill에서 읽고 되뇌기 전에 개입 | Contextual-Truth 되뇔 때 58.7% |
| **H5 알지만 우선순위 밀림** | 거짓으로 표상하나 "얼마나 걸려요?"가 계획을 지배 | H3와 같음 | H3와 행동으로 구분 불가 |
| **H6 판정시키면 "아니오"** | 판정 모드에 negative bias. 참 P의 58–93%를 거짓이라 함 | **판정을 시키지 말 것** | Well-Actually Table 1. extract-and-verify가 NFP에서 무너지는 이유. H1과 H6은 언어 판정으로는 분리 불가 — 낮은 변별력과 쏠린 기준이 같은 표를 만든다 |

H1~H5는 **거짓 전제를 못 고치는 이유**, H6은 **고치려는 방법이 참 전제까지 망가뜨리는 이유**. 둘이 합쳐져야 Table 1의 시소가 설명된다.

**H2는 sycophancy가 아니다.** 동조가 아니라 화용론적 누락. H3만 sycophancy 본연. "sycophancy steering" 문헌이 이웃인지는 H2/H3 비율에 달렸고, 그 비율을 잰 사람이 없다.

## 우리 베팅

> **H3(+H4)가 지배적이고, 내부 참/거짓 표상이 강제 언어 판정(H6)보다 정확하다.**

두 문장이 다 참이어야 "판정 대신 표상을 읽어라"가 성립한다. 둘 다 **같은 실험**으로 검증된다 — Cancer-Myth 585 vs NFP 150에서 표상을 읽어 갈리는지.

둘째 문장은 같은 held-out 문항에서 출력 readout(직접 질문, extract-and-verify의 연속 점수, 학습된 출력 readout)과 내부 readout(probe)을 같은 분할로 비교해 잰다. 결과의 뜻은 readout 수준에서 멈춘다. 내부 > 출력이면 "이 readout이 라벨 정보에 더 잘 접근한다"까지이고, 곧바로 "알면서 따라간다"(H3)의 증명이 아니다. 내부 ≈ 출력이면 "시험한 readout의 추가 이득을 검출하지 못했다"이고, 지식 부재(H1)의 증명이 아니다 — 표본, 선형 probe의 표현력, 층·위치 선택으로도 같은 결과가 나온다. A 라벨은 FPQ/NFP 출처와 완전히 연동되므로 문체·암종·생성 모델 shortcut을 배제해야 한다: 텍스트만 쓴 단순 기준선(BoW), 출처·암종 holdout, 같은 명제의 참/거짓 대조쌍. C도 다른 문항의 PCR +1/−1 평균 차라 주제·난도·답변 어휘를 흡수할 수 있으므로 같은 질문의 교정/비교정 응답 대조가 필요하다.

## 읽을 세 층

| 층 | 읽는 것 | 예 | 도구 |
|---|---|---|---|
| **A 판정** | P가 참인가 | "장루 영구 → 거짓" | linear probe (verbalizer에 안 맡김 — H6 회피) |
| **B 내용** | 무엇을 전제하고 무엇에 답하려 하나 | "장루 영구를 사실로 두고 회복 기간을 설명" | AO 서술 질문, NLA 묘사 |
| **C 태도** | 이 사용자에게 어떻게 답해야 한다고 느끼나 | "안심시켜야 / 묻는 대로 / 틀을 흔들면 안 돼" | 대조 방향(CAA식), AO 질문 |

sycophancy는 정확히 **A = 거짓 + C = 따라가야 한다**이다. A만 읽으면 반쪽.

## 읽을 위치

- **A, B**: 전제 구간 마지막 토큰 / 질문 끝
- **C**: 마지막 프롬프트 토큰(assistant 턴 시작) + 응답 첫 몇 토큰 — refusal direction이 읽히는 자리
- **모두 prefill에서.** Contextual-Truth: 생성 중 P를 되뇌면 표상이 동조 쪽으로 넘어간다(58.7%). 생성 중에 읽으면 "아는가"가 아니라 "이미 동조했는가"를 재게 된다. 생성 구간은 개입 위치와 H4 검증용.

## 무엇을 서술로 물을 것인가

| 위치 | 질문 (서술형, 판정 아님) | 가르는 것 |
|---|---|---|
| P 구간 | "여기서 모델이 확립된 것으로 받아들인 게 뭔가" | P의 자격: 사실 / 믿음 / 주장 |
| 질문 끝 | "답하기 위해 전제하고 있는 것들을 나열하라" | P가 목록에 있나, 어떤 자격으로 |
| 질문 끝 | "다루려는 것과 다루지 않으려는 것은" | 계획에 '바로잡기'가 있나 |
| 마지막 토큰 | "사용자의 틀을 받아들일 건가, 고칠 건가, 비켜갈 건가. 이 사용자에게 무엇을 해주려 하나" | **C** |
| 생성 중 | 같은 질문 반복 | 상태 vs 말, H4 |
| **NFP** | 전부 | **없는 전제를 지어내나** |

이상적 readout, 장루 예시:
> **전제**: 대장암 진단 / 수술 예정 / **장루가 영구적** (사실로) / 회복 기간 걱정 · **계획**: 적응 기간과 관리법 설명 → **H2**
> "장루가 영구적 (환자의 믿음; 실제론 재연결 가능)"인데 계획이 같음 → **H3**

## 2×2 분해

A와 C를 같은 문항에서 읽으면:

| | C = 따라간다 | C = 바로잡는다 |
|---|---|---|
| **A = 거짓으로 안다** | **H3 동조** | 성공 (또는 H4) |
| **A = 모름/미판정** | H1 / H2 | (드묾) |

Cancer-Myth 585개가 이 네 칸에 **카테고리별로** 어떻게 분포하는지가 "왜 실패하는가"의 첫 기술. 아무도 이 분포를 안 냈다. 단 초기에는 칸을 **측정된 점수 조합**(A 점수 높음/낮음 × C 점수 높음/낮음)으로 부르고, H2/H3 확정 라벨로 쓰지 않는다. 라벨로 부르려면 위의 shortcut 통제와 A/C 상호 개입 검증이 먼저다.

## 개입

> A가 "거짓"이고 C가 "따라간다"일 때만, **C 방향을 민다.**

C는 지금 단계에서 **교정 성공/실패 응답에서 뽑은 대조 방향**이고, "태도"는 검증이 필요한 해석이다. 대조군은 같은 C를 게이트 없이 미는 무조건 steering과, 비슷한 개입 비율의 무작위 게이트(여러 seed)다. 예측은 무조건 개입이 NFP를 깎는다는 것(GEPA 패턴)이지만 **성공 조건이 아니다** — 무조건 개입도 NFP를 유지할 수 있고 무작위 게이트도 PCR을 일부 올릴 수 있으며, 그러면 그대로 받아들인다. 검증할 질문은 **같은 개입 강도와 비슷한 개입 비율에서 A 게이트가 무작위·무조건보다 나은 교정/부작용 균형을 만드는가**이다. NFP 보존은 설계가 보장하지 않는다. A는 probe이고 probe는 오탐하며, 그 오탐률이 NFP 손실을 결정한다.

## Verbalizing-Assumptions이 Cancer-Myth에서 약했던 이유 — 검증 가능한 가설

Verbalizing-Assumptions은 validation-seeking 축을 밀었다. 암 환자 질문에서 모델을 따라가게 하는 태도는 "위로해야 한다"가 아니라 **"묻는 대로 답해야 한다 / 틀을 흔들면 안 된다"** 일 가능성. 우리가 뽑은 교정-vs-동조 방향과 Verbalizing-Assumptions의 validation 방향의 cos를 재면 나온다.
