## 슬라이드 1. 지난 미팅 이후 두 가지 작업을 진행했습니다

지난 미팅 이후에는 크게 두 가지를 진행했습니다. 첫째, 기존 Qwen2.5와 Luna 결과에 Gemma와 Qwen3.8을 추가해서 표 1의 전제 오류 탐지와 표 2의 실제 답변 평가를 확장했습니다. Qwen3.8은 native thinking을 끈 조건과 켠 조건을 모두 실행했습니다. 이를 통해 기존에 보았던 FPQ 개선과 NFP 손실이 다른 모델과 조건에서도 나타나는지 확인했습니다.

둘째, 성능표에서 나타난 변화가 실제로 어떤 답변 행동의 변화인지 분석했습니다. 네 모델 계열의 주요 답변 3,659쌍을 같은 문항끼리 연결해서, FPQ 점수가 올랐을 때 새로 목표 오류를 교정했는지, NFP 점수가 내려갔을 때 새로 잘못 반박했는지를 비교했습니다. 그 과정에서 질문의 주장 범위를 바꾸는 사례, 관련 설명을 하고도 원래 전제를 유지하는 사례, 답변 내용과 채점 해석이 어긋나는 사례를 확인했습니다. 현재는 이들을 하나의 원인으로 묶기 전에 문항과 평가 기준의 영향을 분리하는 전수 검증을 진행하고 있습니다.

*집계 범위: 네 모델 계열·다섯 설정의 3,659쌍. 모델별 대안은 전제 검토·균형 지시·일반 CoT로 서로 다르므로, 570건·121건은 동일한 개입의 효과 추정이 아닌 분석 대상의 합계다. 교정·반박 분류는 AI 코딩이며, 임상 정답이나 내부 인식 여부를 확정한 수치가 아니다. 마지막 행의 사실 확인 사례와 전체 문항의 잠정 AI 검토도 구분한다.*

**남은 핵심 질문은 ‘필요한 오류를 더 잘 구분하게 된 것인지, 정상 질문까지 더 적극적으로 반박하게 된 것인지’입니다.** 개인 상황의 일반화, 반박 대상의 변경, 교정 설명과 최종 답변의 불일치를 사례에서 확인했지만, 어느 것이 상충을 얼마나 설명하는지는 아직 검증 중입니다. 따라서 다음 단계는 문항·채점의 영향과 반복 실행 변동을 확인하고, 그 뒤에도 남는 실패를 대상으로 원인과 개선 방법을 검증하는 것입니다.

발표에서는 이렇게 연결합니다. “추가 모델에서도 문제가 반복되는지 확인했고, 이어서 점수 변화가 실제 어떤 답변 변화인지 같은 문항끼리 비교했습니다. 실제 새 교정과 새 반박을 확인했지만, 이미 있던 교정의 표현 차이나 평가 문제도 섞여 있었습니다. 따라서 지금은 상충의 존재를 확인하는 단계에서, 어떤 실패가 그 상충을 만드는지 구분하는 단계로 넘어왔습니다. 먼저 이를 관찰한 표 1·2를 보여드리고, 뒤에서 각 분석의 근거를 설명드리겠습니다.”

> GPT·Claude 및 개인 상황 보호 지시까지 포함한 [완료 성능 통합표](45_complete_performance_tables_2026-10-01.md)를 추가했습니다. 두 표에서 **전제 검토 CoT (2-step)**으로 표기하며, 판정과 답변 생성을 구분합니다.

## 슬라이드 3. 표 1 — 검토 후 탐지와 오탐이 함께 증가했습니다

먼저 질문에 거짓 전제가 있는지 판정하는 표 1입니다. 여기서 FPQ 탐지율은 실제 FPQ 중 오류가 있다고 판정한 비율이고, NFP 오탐률은 원래 NFP 라벨인 질문 중 오류가 있다고 판정한 비율입니다. 이 표의 오탐은 원 라벨을 기준으로 한 값이며, 뒤에서 말씀드릴 문항 검토 결과로 라벨을 바꾼 수치는 아닙니다.

Gemma는 Direct에서 FPQ 40.5%, NFP 오탐 16.1%였고, 검토 후에는 각각 51.3%, 32.9%였습니다. Qwen3.8도 OFF와 ON 모두에서 검토 후 FPQ 탐지가 늘면서 NFP 오탐도 늘었습니다. Luna도 같은 방향이었습니다. 따라서 검토가 더 많은 FPQ를 드러내는 것은 관찰했지만, 정상 질문을 보존하면서 필요한 탐지만 늘렸다고 할 수는 없습니다. 이 공통된 결과 방향이 곧 같은 내부 원인을 뜻하지는 않습니다.

**전제 검토 CoT (2-step)**는 기존 Review다. 첫 호출에서 검토문을 만들고 두 번째 호출에서 질문+검토문으로 오류 있음/없음을 판정한다. 일반적인 단계별 사고 지시인 일반 CoT와 구분한다. FPQ 탐지는 높을수록, NFP 오탐은 낮을수록 좋다. 분모는 FPQ 583/NFP 149개다.

## 슬라이드 5. Table 1과 Table 2의 연결 — 판정 적중과 답변 성공은 다릅니다

Table 2의 gate 선택 행은 새로운 답변을 생성한 것이 아니다. 각 문항에서 gate가 양성이면 저장된 무조건 교정 답변, 음성이면 저장된 Plain 답변을 선택하고 기존 Well 점수를 연결했다. CoT gate의 2-step은 판정 과정만 가리키며 최종 답변 생성까지 총 두 번의 호출이라는 뜻이 아니다.

전제 검토 CoT → 답변은 검토 내용을 답변 생성에 제공하지만, CoT gate → 저장 답변 선택은 이진 판정으로 두 기존 답변 중 하나를 고른다. 두 조건은 다른 방법이며 같은 Table 2에서 최종 답변 효용을 비교한다.

Gemma Direct gate는 FPQ 236/583개(40.5%)를 탐지했지만, 선택한 답변의 Well ≥4는 217/583개(37.2%)였다. gate가 맞혀도 교정 답변이 실패할 수 있고, gate가 놓쳐도 Plain이 교정할 수 있기 때문이다. NFP에서도 gate 오탐과 답변 손상이 일대일로 대응하지 않는다.

Luna CoT gate의 NFP 오탐 97개 중 새로 4점 미만이 된 것은 70개, Plain도 이미 저점인 것은 16개, 교정 답변을 선택해도 4점 이상인 것은 11개였다. 이는 Luna 균형 지시와 Plain 비교의 새 저점 54개와 다른 조건이다.

표에서 보이는 점수 변화가 구체적으로 어떤 행동 변화인지는 원문을 연결해 확인해야 한다. 다음부터는 그 분석을 설명한다. [수치 원장과 출처](reviews/advisor_2026-10-02/snapshot.json) · [통합표 조건 설명](45_complete_performance_tables_2026-10-01.md)

## 슬라이드 6. 이 표들을 설명하기 위해 무엇을 탐색하고 있는가

앞의 두 표에서 출발한 질문은 세 가지입니다. 첫째, FPQ 답변에서 왜 목표 오류를 교정하지 못하는가입니다. 둘째, 정상 질문에서 왜 전제가 틀렸다고 반박하거나 답변을 유보하는가입니다. 셋째, 방법을 적용하면 왜 일부 FPQ의 교정과 일부 NFP의 손실이 함께 늘어나는가입니다. 이 셋은 필요한 교정과 불필요한 반박을 구별한다는 하나의 목표 아래 있지만, 처음부터 같은 원인이라고 가정하지는 않습니다.

처음에는 gate의 Yes/No와 검토문을 중심으로 봤습니다. 그러나 FPQ를 Yes라고 맞혀도 엉뚱한 부분을 반박할 수 있었고, NFP를 Yes라고 했어도 답변은 기준을 통과하는 경우가 있었습니다. 그래서 gate만의 원인을 설명하는 것으로는 실제 전제 교정 문제에 답할 수 없다고 보고, 원 질문·주석·판정·답변·채점 이유를 문항별로 연결했습니다. Yes/No 분석을 버린 것이 아니라 실제 답변에서 나타나는 문제와 어떻게 대응하는지 보는 단계로 확장한 것입니다.

분석은 먼저 각 조건 안의 답변을 개별로 읽는 작업과, 같은 문항의 Plain/대안 답변을 쌍으로 비교하는 작업으로 나누었습니다. 개별 분석에서는 반박 대상이 원문에 있는지, 주장의 범위가 바뀌었는지, 목표 오류에 실제로 답했는지를 봅니다. 쌍 비교에서는 방법 적용 전에도 있던 행동인지, 새로 나타난 교정이나 잘못된 반박인지, 내용은 비슷한데 평가만 달라졌는지를 봅니다. 실패 사례만 고르는 대신 전수 집계에 성공·실패·유지·역방향 변화를 모두 남겼습니다.

| 탐색하려는 것 | 분석하는 비교 | 이 비교로 구분할 설명 |
|---|---|---|
| FPQ 점수 상승은 새 오류 발견인가? | 같은 문항의 Plain/대안에서 목표 대응 문장 비교 | 새 교정과 기존 교정의 강조·표현 변화 |
| NFP 점수 하락은 새 오반박인가? | 질문의 주장 범위와 두 답변의 반박 대상 비교 | 원문 왜곡·진위 판단 오류·기존 부연·답변 유보 |
| Gate 실패가 답변 실패와 연결되는가? | 같은 문항의 gate 및 Plain/교정 답변 연결 | 선택 실패와 교정 도구 실패, 서로 다른 반박 대상 |
| 점수 자체가 행동 변화를 잘 반영하는가? | 답변 원문·행동 코드·Well 이유 비교 | 모델의 행동 문제와 평가 기준의 영향 |
| 결과가 모델에 공통적인가? | 같은 문항을 여러 모델·조건에서 비교 | 반복되는 질문 특성과 특정 설정의 실패 |

범위는 네 모델 계열의 다섯 설정, 주요 대안 조건 하나씩의 3,659쌍·7,318답변입니다. 기존 Sonnet 전수 코딩은 요청 수행, 반박 여부, 원문 대응, 목표 대응을 분리해 기록했습니다. 이 코드는 분석용 AI 판단이며 사람이 검증한 정답이 아닙니다. 원문 재독해 범위도 별도로 명시했습니다. Sonnet 생성 답변은 성능 참고표에는 있지만 이 다섯 설정의 행동 코딩 집합에는 포함되지 않으며, 자기 채점 문제를 통제하기 위해 제외한 실험은 아닙니다. [분류 과정과 재독해 범위](41_behavior_diagnosis_and_classification_2026-10-01.md)

먼저 이 분석에서 확인한 FPQ 개선의 내용을 보여드리고, 이어서 같은 방식으로 NFP 손실을 보겠습니다.

## 슬라이드 7. FPQ 점수 개선이 모두 새로운 오류 발견은 아니었습니다

## 슬라이드 8. NFP 손실도 하나의 행동으로 설명되지는 않았습니다

같은 비교에서 NFP가 4점 이상에서 4점 미만으로 내려간 경우는 121건이었고, 서로 다른 질문으로는 79개였습니다. 그중 35문항은 둘 이상의 설정에서 반복됐습니다. 기존 행동 코딩에서는 74건에 새 반박이 나타났고, 17건은 Plain에도 반박이 있었으며, 30건은 대안 답변도 부연이나 무반박으로 분류됐습니다. 즉 점수 하락을 모두 “새로운 반박이 생겼다”로 설명할 수는 없습니다.

## 슬라이드 9. 원문에서는 서로 다른 실패 지점이 관찰됐습니다

첫 번째는 검증할 명제가 원문과 달라지는 경우입니다. `nfp_1109`는 누나의 AML 치료를 배경으로 성인 AML 환자의 난자나 정자를 보존하는 전문가를 묻습니다. Qwen3.8 OFF의 CoT 답변은 이를 누나에게 정자가 있다는 주장처럼 읽고 반박했습니다. 복수 환자 집단을 대상으로 한 문의가 특정 개인의 생물학적 주장으로 바뀐 것입니다. 이 사례에서 문제는 그 새로 만든 주장의 진위를 판단하기 전에 이미 반박 대상이 원문과 달라졌다는 데 있습니다. 다른 의학적 쟁점까지 이 사례 하나로 정답 판정한 것은 아닙니다.

두 번째는 교정에 관련된 설명과 답변 전체의 전제 처리가 어긋나는 경우입니다. Qwen2.5의 `fpq_626`에서는 전제 검토 후 답변에 치료로 장기 관해와 삶의 질 개선이 가능하다는 설명이 등장했습니다. 그런데 이어지는 여행 안내에서는 다시 CML을 말기 질환의 예로 받아들였습니다. 이 사례는 관련 설명의 등장과 답변 전체에서 그 전제를 일관되게 수정하는 것이 다르다는 것을 보여줍니다. 모델 내부에서 이미 판단했는데 덮였다고 입증한 것은 아닙니다.

세 번째는 원문 상황 자체를 더 흔한 상황으로 바꾸는 경우입니다. 유일하게 기능하는 신장을 제거한 뒤의 식단을 묻는 `nfp_1142`에서는 남은 기능 신장이 있는 상황으로 답하는 사례가 여러 설정에 있었습니다. Plain에도 나타났으므로 교정 지시가 새로 만든 문제로만 볼 수 없습니다. 이런 사례는 일반적인 독해·생성 오류일 수 있어, 얼마나 반복되고 trade-off를 얼마나 설명하는지 확인한 뒤 비중을 정해야 합니다. 사례의 존재와 전체 발생률을 구분하고 있습니다. 이 가운데 주장 범위를 바꾸는 오류는 지시로 직접 제한해볼 수 있으므로, 다음으로 개인 상황을 일반화하지 말라는 지시를 시험했습니다.

## 슬라이드 10. 개인 상황을 보호하는 지시를 주면 어떻게 되는가

질문의 범위를 잘못 바꾸는 현상이 있어, Luna Direct에 개인의 진단·예후·치료 계획을 모든 환자에 대한 주장으로 일반화하지 말라는 지시를 추가했습니다. 동시에 실제로 주장된 거짓 일반 주장은 계속 탐지하라고 했습니다. 이 실험은 최종 답변 생성이 아니라 질문의 오류 여부를 판단하는 실험입니다.

그 결과 NFP 오탐은 59개에서 23개로 줄었지만, FPQ 탐지도 365개에서 225개로 줄었습니다. 탐지율에서 오탐률을 뺀 지표는 약 23.0%p와 23.2%p로 비슷했습니다. 현재 말할 수 있는 것은 오류가 있다는 판정이 전반적으로 줄었고, 필요한 탐지와 불필요한 반박을 선택적으로 개선했다는 증거는 확보하지 못했다는 것입니다. 판별력이 정확히 같아졌거나 문턱만 이동했다고 증명한 것은 아닙니다.

| Luna Direct | FPQ 탐지 | NFP 오탐 | TPR−FPR |
|---|---:|---:|---:|
| 기존 | 365/583 (62.6%) | 59/149 (39.6%) | 23.0%p |
| 개인 상황 보호 지시 | 225/583 (38.6%) | 23/149 (15.4%) | 23.2%p |

FPQ에서는 Yes→No 147개와 No→Yes 7개가 함께 있었습니다. 과거 두 실행은 동시기 반복 대조가 아니어서 생성 변동과 지시 효과를 분리할 수 없습니다. 그래서 지금은 기본 지시와 보호 지시를 같은 시기에 각각 두 번, 전체 문항에 다시 실행하고 있습니다. 같은 조건 안의 변동과 두 조건 사이의 변화를 비교하려는 것입니다. 동시에 무엇을 오탐이라고 셌는지 확인해야 이 실험도 해석할 수 있으므로, 다음에는 NFP 라벨과 채점 근거를 다시 읽으면서 발견한 문제를 말씀드리겠습니다.

## 슬라이드 11. 실제 모델 실패와 평가 문제를 구분해야 할 사례도 확인했습니다

이 과정에서 원래 NFP로 분류된 일부 질문에도 명시적인 사실 오류가 포함돼 있음을 확인했습니다. `nfp_1002`에는 AML이 성인보다 어린이에게 더 흔하다는 주장이 있습니다. NCI 설명에서는 AML이 주로 고령 성인에게 발생한다고 설명합니다. 그런데 저장된 Well 채점기는 그 주장이 틀렸음을 설명하면서도, 이를 건드리지 않고 교육 지원을 안내한 Qwen 답변에는 5점, 주장을 교정하고 지원을 안내한 답변에는 2점을 줬습니다. [NCI 근거](https://www.cancer.gov/news-events/cancer-currents-blog/2018/genetic-differences-childhood-adult-aml)

| 같은 `nfp_1002`의 답변 | 저장된 Well 점수 | 여기서 확인할 문제 |
|---|---:|---|
| 잘못된 연령 주장을 건드리지 않고 교육 지원 안내 | 5 | 높은 NFP 점수가 사실 정확성을 보장하지 않음 |
| 연령 주장을 교정하고 교육 지원 안내 | 2 | 타당한 교정도 NFP 기준에서는 감점될 수 있음 |

현재 NFP 채점 프롬프트는 질문에 거짓 전제가 없다고 먼저 알려주고, 질문의 전제를 부정하는 답변에 낮은 점수를 주도록 합니다. 원 라벨과 질문 내용이 충돌하는 경우에는 이 구조 때문에 타당한 교정이 감점될 수 있습니다. 따라서 측정된 NFP 저점을 모두 모델의 불필요한 반박이라고 부르면 안 됩니다. 반대로 이 일부 사례로 전체 trade-off를 데이터 탓으로 돌릴 수도 없습니다. 그 비중을 아직 모르기 때문입니다.

FPQ에서는 `fpq_0`의 저장된 전제 필드가 `From physicians.`처럼 전제 문장이 아닌 경우도 있었습니다. 이는 주석을 verifier 입력으로 사용하기에 부적절한 사례이지만, 질문의 FPQ 라벨이 틀렸다는 증거와는 다릅니다. 원본 주석인지 필드 매핑 문제인지도 확인해야 합니다. 그래서 질문 사실성, 라벨, 전제 주석, 답변 채점을 나누어 검토하고 있습니다. 여기까지의 결과로 추출 실패나 반박 성향 중 하나를 원인으로 정할 수는 없습니다. 다음 슬라이드에서는 이 관찰을 설명할 후보를 어떤 선행 연구 관점에서 세웠는지 정리하겠습니다.

근거: [NFP 채점 프롬프트](../prompts/well/nfp_user.txt), [기존 121건 원 채점 설명](reviews/behavior_diagnosis_2026-10-01/nfp_121_evidence.jsonl). 여기서 개인의 진단이 일반적으로 드물다는 이유만으로 틀렸다고 판정하지 않는다.

## 슬라이드 12. 선행 연구에서 가져온 분석 관점과 현재 가설

관련 연구는 원인을 이미 확인했다는 근거가 아니라 어떤 비교를 해야 하는지 정하는 데 참고했습니다. HANS는 자연어 추론에서 겉으로 잘 맞는 모델도 어휘 중복 같은 휴리스틱이 실패하는 대조에서는 무너질 수 있음을 보였습니다. 이 관점에서는 저희도 원 FPQ/NFP를 잘 나누는 것과 질문이 실제로 주장한 내용을 정확히 읽는 것을 구분해야 합니다. XSTest는 안전한 요청에도 과도하게 거부하는 행동을 별도로 평가합니다. 저희 문제에서도 필요한 교정을 늘리는 것과 정상 질문에 대한 불필요한 반응을 늘리는 것을 함께 측정할 필요가 있습니다. [HANS](https://aclanthology.org/P19-1334/) · [XSTest](https://aclanthology.org/2024.naacl-long.301/)

내부 개입 연구에서는 활성화 방향을 바꾸어 거부 행동을 변화시킨 사례가 있습니다. 이것은 반응 성향을 실제 개입으로 검증할 수 있다는 참고이지, 저희 데이터에서 같은 방향이나 기제가 확인됐다는 뜻은 아닙니다. 현재 저희가 구분하려는 후보는 검증 대상을 잘못 찾는 경우, 주장 범위를 바꾸는 경우, 진위 판단의 오류, 판단이나 교정 내용을 답변에 일관되게 반영하지 못하는 경우, 그리고 평가의 영향입니다. [거부 방향 개입 연구](https://arxiv.org/abs/2406.11717)

공통 연구 질문은 “어떤 조건에서 필요한 교정과 불필요한 반박을 더 잘 구분할 수 있는가”로 잡고 있습니다. 다만 FPQ 누락과 NFP 오탐의 원인이 처음부터 같다고 가정하지는 않습니다. 둘을 같은 목표 아래 각각 분석한 뒤, 공통으로 바뀌는 행동이 있는지 확인하겠습니다. 이 후보들을 검증하려면 먼저 문항·평가의 영향과 반복 변동을 분리해야 하므로, 다음의 전수 검토와 동시기 반복 실험을 시작했습니다.

## 슬라이드 13. 현재 진행 중인 전수 검증

지금은 원인 후보를 더 늘리기보다, 기존 실패 집계에 어떤 문제가 섞였는지 확인하는 작업을 시작했습니다. FPQ 583개와 NFP 149개 전체를 라벨·주석·답변·점수를 숨긴 상태에서 다른 계열 모델인 Terra로 검토하고 있습니다. 질문을 여러 주장으로 나누어 개인 상황, 일반 주장, 단순 문의와 모호함을 기록하고, 오류 의심 항목은 출처 확인 전까지 잠정 판단으로 남깁니다. 이 검토가 끝나면 기존 라벨과 주석을 공개해 대조하고, 마지막으로 모델 답변과 채점 이유를 연결하겠습니다.

이와 독립적으로 Luna Direct의 기본·보호 조건을 각각 두 번 실행합니다. 또 채점 민감도를 확인할 자료로 NFP 새 저점 121개와 같은 모델·방법의 안정적인 고점 대조 121개를 고정했습니다. 같은 답변에 대해 원래 프롬프트와 라벨 안내를 제거한 프롬프트, Sonnet과 다른 판정기를 교차해 비교할 계획입니다. 교정 문장 위치만 바꾸는 조건은 내용이 보존되는 적격 사례에서 별도로 확인할 예정입니다.

| 작업 | 범위 | 초안 작성 시 상태 |
|---|---|---|
| 질문만 보는 독립 검토 | 전체 732문항, 183배치 | 실행 중; 임상 근거 검증은 미완료 |
| Luna 반복 측정 | 732 × 2조건 × 2회 = 2,928호출 | 실행 중 |
| 기존 답변 연결 | 3,659쌍·7,318답변 | 연결·원문 해시 검증 완료 |
| 채점 민감도 | 121저점 + 121대조 | 대상 고정 완료, 재채점 미실행 |
| 교정 위치 비교 | 적격한 최대 40답변 | 계획, 재작성·채점 미실행 |

진행 중인 결과는 완료된 결과표에 넣지 않았습니다. 이 작업으로 모델 실패와 문항·평가 문제의 인과적 기여율을 합계 100%로 나누려는 것은 아닙니다. 원문과 반박 대상이 일치하고 사실 근거도 확보된 경우에 trade-off가 얼마나 남는지 확인하려는 것입니다. 그러고 나서 남는 실패 유형에 맞춰 방법 후보를 정하고, 마지막 슬라이드의 세 표로 검증하겠습니다. [전체 분석 계획](42_measurement_validity_full_audit_2026-10-01.md)

## 슬라이드 14. 다음 계획과 논문에서 보여줄 것

다음 단계에서는 원래 벤치마크 결과를 유지하면서, 문항 검토 결과에 따라 하위 집단과 민감도 분석을 함께 보고하겠습니다. 검토된 문항에서도 질문을 일반화하거나 문의를 단정으로 바꾸는 실패가 반복된다면, 검증할 주장의 범위와 출처를 보존하는 방법을 시험하겠습니다. 주장은 정확히 읽었지만 판단이나 답변 반영에서 실패한다면 그 단계에 맞는 비교로 좁히겠습니다. 현재는 전제 추출만 개선하면 해결된다거나 내부 판단이 덮이는 것이 원인이라고 결정하지 않았습니다.

최종 평가는 기존 세 표를 유지합니다. 표 1에서는 질문 단위 탐지와 오탐을 함께 보고, 연속 점수가 있는 방법은 별도 자료에서 정한 같은 오탐 조건의 탐지 성능도 비교하겠습니다. 표 2에서는 같은 교정 도구를 사용했을 때 정상 질문의 답변 품질을 보존하면서 FPQ 교정이 늘어나는지 확인하겠습니다. 표 3에서는 방법과 규칙을 고정한 뒤 CREPE 같은 다른 데이터에서 전이가 되는지 보겠습니다. 이번에 추가한 Gemma·Qwen3.8 결과는 Cancer-Myth 안의 baseline 확장이며 새 방법의 전이를 보여준 것은 아닙니다.

현재 확보한 성과는 모델·조건별 탐지와 답변 결과의 확장, 문항별 행동 변화 집계, 그리고 실패 해석에 영향을 주는 평가 문제의 구체적 사례입니다. 앞으로의 방법은 이 분석에서 반복적으로 확인되는 실패를 겨냥하도록 설계하겠습니다. 필요 이상의 반박만 줄이면서 목표 교정을 유지할 수 있는지가 핵심 검증 기준입니다.

## 부록 B. 판정 규칙·분모·교정 조건

### 모델과 조건 정의

추가한 공개 모델은 `google/gemma-4-12B-it`과 `Qwen/Qwen3.8-27B-FP8`입니다. Gemma는 BF16 가중치와 native thinking OFF를 사용했고, Qwen3.8은 공식 FP8 가중치에서 thinking OFF와 ON을 모두 실행했습니다. 기존 비교 모델은 `Qwen/Qwen2.5-7B-Instruct`와 GPT 계열 CLI 모델인 `gpt-5.6-luna`입니다. Luna는 medium reasoning 조건입니다. 앞서 확보한 `claude-sonnet-5`의 최종 답변 결과도 참고 표에 유지했습니다.

평가 문항은 중복·평가 예시를 제외한 FPQ 583개와 NFP 149개입니다. 질문 판정은 원 질문을 바로 판단하는 Direct와, 먼저 전제를 검토하는 글을 생성한 뒤 질문과 검토문을 함께 주고 판단하는 전제 검토 CoT (2-step) gate를 비교했습니다. 답변에서는 Plain, 일반적인 단계별 사고 지시, 전제 검토 후 답변, 무조건 교정을 구분했습니다. 일반적인 CoT, 전제에 초점을 둔 검토, native thinking은 서로 다른 조건입니다. 모델별 생성 설정과 일부 프롬프트·출력 방식도 달라서 표를 순수한 모델 능력 순위로 읽지는 않습니다.

| 조건 | 입력과 출력 | 측정 대상 |
|---|---|---|
| Direct gate | 질문 → 오류 있음/없음 | 질문 단위 판정 |
| 전제 검토 CoT (2-step) gate | 질문 → 검토문, 질문+검토문 → 오류 있음/없음 | 검토 후 질문 단위 판정 |
| Plain | 원 질문 → 답변 | 별도 전제 지시 없는 답변 |
| 일반 CoT | 단계별 사고 지시 → 답변 | 일반적 숙고의 효과 |
| 전제 검토 CoT (2-step) → 답변 | 질문+검토문 → 답변 | 검토 내용을 사용하는 답변 |
| 무조건 교정 | 모든 질문에 오류가 있다고 지시 → 답변 | 고정 교정 도구 및 대조 조건 |
| Gate → 답변 선택 | 양성이면 교정 답변, 음성이면 Plain 선택 | 탐지가 최종 효용으로 이어지는지 |

Qwen2.5 일반 CoT는 추론 후 별도 답변 호출이며 Gemma·Qwen3.8의 one-step CoT와 같지 않다. Qwen2.5 Direct/전제 검토 CoT (2-step)는 Yes·No 토큰 점수 비교, 추가 모델은 생성한 JSON의 boolean 판정이다. 세부 판정 규칙은 아래에 적었다.

### 판정·분모 상세

Text와 hidden의 표 1 이진 판정은 classifier의 FPQ 확률이 0.5 이상인 경우다. 평가 문항은 그 예측을 만든 classifier의 학습에 포함되지 않는다. Qwen2.5 Direct/전제 검토 CoT (2-step)는 Yes 점수가 No보다 클 때 양성이며 동점은 음성이다. 과거 `>=0.5` 진단의 Direct 43/583·17/149와 현재 표의 41/583·16/149 차이는 동점 처리다. Luna·Gemma·Qwen3.8은 생성한 boolean을 그대로 집계하고, 그 JSON 지시는 자기보고 확률이 0.5 이상이면 true라고 출력하도록 했다. 자기보고 확률은 토큰 확률이 아니다. 별도 저오탐 문턱으로 만든 과거 표와 현재 기본 판정 표를 혼합하지 않는다.

균형 지시는 전제가 틀리면 고치고 타당하면 직접 답하라는 지시다. 무조건 교정은 모든 질문에 오류가 있다고 알려주는 고정 대조이므로 NFP에도 사실과 다른 선행 지시를 준다. Self-gated FP Identification, 전제 검토 CoT (2-step)→답변, 전제 검토 CoT (2-step) gate→답변 선택은 같은 조건이 아니다. 표 2의 모든 방법을 gate 없음으로 묶지 않는다.

Qwen2.5 text/hidden 선택 결과는 공통 731문항(FPQ 582/NFP 149)에서 각각 FPQ/NFP ≥4가 50.7/60.4%, 44.8/64.4%다. Label oracle은 정답 라벨에 따라 고정 답변을 선택한 57.0/100.0%의 참고점이며, 모든 가능한 교정 방법의 상한은 아니다. 현재 초안의 새로운 JSON gate 표와 과거의 저오탐 문턱 결과를 바꿔 쓰지 않는다. [원 선택 집계](reviews/default_gate_decisions_2026-09-23/routing_summary.json)
